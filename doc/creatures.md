# 生物骰面與結算規則

規格入口：[spec.md](spec.md)。本文件管理生物骰面的效果、關係判定、追加攻擊與回合結算順序。生物涵蓋動物與植物，效果中的加值、倍率及護盾量由 `src/configs` 的對應設定統一管理。

## 1. 骰面與關係

每個骰面由生物種類與基礎攻擊值組成，生物種類決定標籤與效果。骰子的所有面共同參與構築；同骰配置、骰面鄰接與鄰骰支援效果依文案讀取指定範圍的有效骰面。一次性貼紙附著期間，以覆蓋後的生物與數值參與所有關係判定。

「本輪擲出的生物」指正常骰子在 Control 完成後鎖定的骰面結果。「同骰」涵蓋該骰子的所有面；「相鄰骰面」指同一顆骰子上共用一條邊的兩個面；「相鄰骰子」指並排位置中直接位於左側或右側的骰子。兩端的骰子各有一個鄰骰。

以「本輪擲出」為條件的生物數量、種類與配對，以鎖定的正常骰面結果為判定對象；同骰配置與鄰接支援則讀取文案指定的有效骰面。追加攻擊骰承載來源生物的外觀與一筆攻擊，其效果範圍為該筆攻擊及明確指定追加攻擊骰的加成。

## 2. 生物效果

### 🦍 猩猩｜家族

Tag：動物、草食、群居。

效果：擲出猩猩時，同骰每有一個其他猩猩面，這隻猩猩的攻擊值獲得一次加值。

### 🐺 狼｜結伴

Tag：動物、肉食、群居、捕食者。

效果：本輪擲出至少兩隻狼時，每隻狼各獲得一次固定攻擊加值。

### 🐇 兔子｜繁衍

Tag：動物、草食、獵物、群居。

效果：同骰至少有三個兔子面時，擲出兔子會產生一顆與自身基礎值相同的透光追加攻擊骰。追加攻擊在繁衍階段成立，並在攻擊階段完成撞擊；原兔子被捕食後，這筆追加攻擊仍完整保留。

### 🦊 狐狸｜捕食

Tag：動物、肉食、捕食者。

效果：擲出狐狸時，捕食本輪一隻基礎值最高且仍可捕食的獵物，依獵物基礎值與捕食倍率取得攻擊加成。被捕食獵物的本輪正常攻擊轉為已消耗，原骰子保留至下一回合正常擲骰。

### 🐅 老虎｜獨居

Tag：動物、肉食、捕食者。

效果：擲出老虎時，若本骰只有這一個老虎面，本次攻擊獲得強化。

### 🐻 熊｜儲糧

Tag：動物。

效果：本骰有熊面且本輪鎖定食物面時，食物照常結算，並以基礎值存入本骰儲糧。每顆骰子共用一份儲糧，持續保留較高的一份；擲出熊時，將儲糧加入本次攻擊並清空。儲糧跨回合保留，戰鬥開始與結束時歸零。

### 🐜 螞蟻｜搬運

Tag：動物、昆蟲、群居。

效果：本輪連續相鄰的螞蟻合力攻擊，合計各自的基礎值，每一個相鄰連接再增加固定傷害。每段隊列由最右側螞蟻承載合力攻擊，其餘成員留在原位完成搬運回饋。

### 🐝 蜜蜂｜採蜜

Tag：動物、昆蟲、授粉者。

效果：擲出蜜蜂時，取得同骰相鄰花面中最高一面的基礎值，加到本次攻擊。

### 🐦 蜂鳥｜訪花

Tag：動物、鳥類、授粉者。

效果：擲出蜂鳥時，讀取左右鄰骰的所有花面，取得其中最高一面的基礎值，加到本次攻擊。

### 🦋 蝴蝶｜授粉

Tag：動物、昆蟲、授粉者。

效果：本輪擲出的蝴蝶與花一對一配對，讓配對花追加一次基礎攻擊。每隻蝴蝶與每朵花每輪最多配對一次，依花的基礎值由高至低完成配對。

### 🦅 禿鷹｜食腐

Tag：動物、肉食、鳥類、食腐者。

效果：本輪任一生物成功捕食時，擲出的每隻禿鷹各追加一次基礎攻擊；每隻禿鷹每輪最多觸發一次。

### 🦌 鹿｜逃逸

Tag：動物、草食、獵物。

效果：鹿被 Control 重骰時，將鹿的基礎值記為本輪護盾，於鎖定結果後取得。每顆骰子每輪最多觸發一次。

### 🐘 大象｜護群

Tag：動物、草食、群居。

效果：擲出大象時，本輪每有一隻其他草食動物擲出，大象就提供一次固定護盾。

### 🌼 花｜花蜜

Tag：植物、花。

效果：以較高的基礎值造成傷害，並以花的身分參與蜜蜂採蜜、蜂鳥訪花與蝴蝶授粉。

### 🌿 草｜草原

Tag：植物、食物。

效果：擲出草時，本輪每有一種不同草食動物擲出，草的攻擊值就獲得一次加值。

### 🍌 香蕉｜果實

Tag：植物、果實、食物。

效果：以基礎值造成傷害，並以食物的身分供同骰的熊儲糧。

### 🌳 樹｜樹蔭

Tag：植物、棲地。

效果：本骰有樹面時，左右鄰骰擲出的鳥類各提供一次樹蔭護盾。同一隻鳥每輪最多獲得一次樹蔭效果。

## 3. 結算順序

傷害預覽與正式結算共用「支援與繁衍 → 捕食 → 食腐 → 攻擊」的規則順序。Control 階段依目前結果推算攻擊、護盾、儲糧變化與觸發關係；玩家鎖定結果後，正式套用本輪狀態變化一次。預覽期間持續使用已提交的戰鬥狀態作為推算起點。

1. **支援與繁衍：** 依鎖定的正常骰面結果、整顆骰子的有效面與相鄰關係判定效果，計算攻擊支援、群體加值、護盾、螞蟻合力攻擊及熊的儲糧變化，並登記繁衍與授粉的追加攻擊。裝備 Pattern 依自身條件判定，全局修正依指定對象與運算規則納入計算。
2. **捕食：** 具捕食效果的生物依骰子排列由左至右處理，從仍可捕食的正常獵物結果選取目標；基礎值相同時優先選取排列較左的獵物。每隻獵物每輪最多供一次捕食，被捕食後保留先前已成立的支援與追加攻擊，並將其正常攻擊標記為已消耗。
3. **食腐：** 依本輪成功捕食事件觸發禿鷹效果，登記對應的追加攻擊，完成最後攻擊清單與傷害總額。
4. **攻擊：** 正常骰子完成數字成長後，生物與裝備產生的追加攻擊以透光骰子進場，接著由攻擊清單中的正常骰子與透光追加骰依序撞向敵人。被捕食的正常骰子留在原位顯示本輪已被捕食，下回合恢復正常擲骰。

捕食目標限定為正常骰子擲出的有效獵物結果。繁衍、授粉與食腐產生的追加骰，均依登記的基礎攻擊與適用加成完成一次攻擊；生物能力由正常骰面及其指定的配置或 Control 事件觸發。追加骰使用共同的透光骰演出，繁衍來源被捕食後仍照常進場與撞擊。

結算演出依生物關係呈現數字成長、繁衍、捕食與食腐回饋，並以最後攻擊清單決定撞擊順序。骰子的並排位置提供關係判定與同階段的處理順序，數值計算與畫面回饋共同呈現同一份結算結果。
