# 戰鬥演出效能

本文件說明[遊戲規格第 20 節](spec.md#20-戰鬥結算與演出)的演出實作。優化保留傷害計算、技能順序、數字中斷接續與撞擊完成後扣血的規則。

## 更新責任

主畫面、地圖、裝備列與彈窗透過 Zustand selector 訂閱各自使用的欄位，多欄位選取使用淺比較。震動容器獨立訂閱震動強度，敵人卡片直接訂閱敵人狀態，讓撞擊更新集中於對應元件。骰盤管理槽位、互動及攻擊目標，正常骰與追加骰分別訂閱自己的數字顯示，檢視中的骰子透過 portal 將當下角色與數字呈現於右側資訊區，擲骰換面與數字更新維持在單顆骰子內；生命與護盾由狀態欄訂閱。演出期間已穩定的資料保留參考，技能事件與同幀數字變化合併送出。

[畫面縮放](viewport-layout.md)的 Context 在場地尺寸、倍率、布局模式及浮動掛載點相同時保留資料參考，將 Context 更新限定於這些輸入變更。骰子圖層的掛載與飛行座標監聽分別管理；掛載依攻擊狀態及掛載點切換，視窗縮放沿用目前 DOM 節點並更新飛行座標。飛行期間依場地尺寸、倍率及捲動重新定位，結束或卸載時清理相關監聽。

單顆正常骰的擲骰動畫由局部 hook 控制，以動畫幀的時間戳計算經過時間，直接更新位移、旋轉與縮放。骰面切換及落定才更新 React 內容，落定通知沿用初擲完成與重骰連鎖的既有流程。骰盤槽位維持固定座標，視窗尺寸變更只調整配置及動畫尺寸比例。靜止、完成及卸載時停止該骰動畫。

技能文字依各骰子目前顯示的事件保留獨立位置，依完整單行內容的實際寬度調整左右貼邊位置，依實際框高與動畫位移預留垂直空間。`SkillFeedback` 持有錨點並執行量測 hook，在自身錨點與子層提示 DOM 的 ref 都掛載完成後，於 layout effect 讀取尺寸及設定位置；`SkillNameLayer` 負責呈現提示並接收圖層 ref。位置量測集中於事件增減、內容尺寸或視窗變更，捲動時沿用已量測的提示尺寸並更新定位，靜止時沿用結果，卸載時解除尺寸與捲動監聽；淡入與上飄由 CSS 動畫執行。文字旁圖示透過共用 CSS 與字級同步縮放。

技能輪播使用實際經過時間處理已到期事件與數值，連續技能從前一輪播在該時間點的顯示值接續。最終值沿用正式計算結果。攻擊保留有限 CSS 過渡完成的等待機制，持續漂浮與裝飾動畫由自己的生命週期管理。

## 繪製與音效

主力魚眼維持既有位移效果，強度相同時保留目前值；變化完成後停止更新。透光追加骰以半透明色面、靜態高光、內陰影及六面立體投影維持外觀，合成時使用局部位移與縮放。角色分層圖片與魚眼位移貼圖於主選單預先解碼。

音效環境在玩家點擊開始遊戲時初始化，播放時沿用相同 AudioContext。撞擊噪音資料建立一次並重用，各次聲源保留獨立的音量與播放時序，結束後中斷聲源、增益及濾波節點連線。輪播音效間隔由 `src/configs/battleConfig.ts` 管理，與畫面更新頻率分開計時。

## 驗證方式

以型別檢查、正式網頁建置及既有核心邏輯測試確認整合。人工比較開場初擲、單骰連續重骰、七骰技能結算、主力魚眼、追加骰連續撞擊、重開 Run 與視窗縮放，觀察掉幀、數值落定、扣血時間及動畫清理。Mac 與 Windows 分別以正式建置及桌面封裝確認，效能改善幅度以實機幀時間量測為準。
