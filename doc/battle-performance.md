# 戰鬥演出效能

本文件說明[遊戲規格第 20 節](spec.md#20-戰鬥結算與演出)的演出實作。優化保留傷害計算、技能順序、數字中斷接續與撞擊完成後扣血的規則。

## 更新責任

主畫面、地圖、裝備列與彈窗透過 Zustand selector 訂閱各自使用的欄位，多欄位選取使用淺比較。敵人角色與意圖元件直接訂閱各自使用的狀態，讓撞擊更新集中於對應元件；back 使用靜態 DOM 圖層，[前景動態系統](foreground-motion.md)直接訂閱玩家逐次命中，ground 與 stone 使用 transform，草與懸掛素材使用共用 WebGL 網格，靜止時停止更新；怪物圖片承載局部受擊演出，骰盤承載下沉、震動、撞擊圓環與傷害數字，受擊亮框由完整遊戲場地的獨立圖層承載。骰盤管理槽位、互動及攻擊目標，正常骰與追加骰分別訂閱自己的數字顯示，檢視中的骰子透過 portal 將當下角色與數字呈現於右側資訊區，擲骰換面與數字更新維持在單顆骰子內；生命與護盾由狀態欄訂閱。演出期間已穩定的資料保留參考，技能事件與同幀數字變化合併送出。

[畫面縮放](viewport-layout.md)的 Context 在場地尺寸、倍率、布局模式及浮動掛載點相同時保留資料參考，將 Context 更新限定於這些輸入變更。骰子圖層的掛載與飛行座標監聽分別管理；掛載依攻擊狀態及掛載點切換，視窗縮放沿用目前 DOM 節點並更新飛行座標。飛行期間依場地尺寸、倍率及捲動重新定位，結束或卸載時清理相關監聽。

單顆正常骰的擲骰動畫由局部 hook 控制，以動畫幀的時間戳計算經過時間，直接更新位移、旋轉與縮放。骰面切換及落定才更新 React 內容，落定通知沿用初擲完成與重骰連鎖的既有流程。骰盤槽位維持固定座標，視窗尺寸變更只調整配置及動畫尺寸比例。靜止、完成及卸載時停止該骰動畫。

技能文字依各骰子目前顯示的事件保留獨立位置，依完整單行內容的實際寬度調整左右貼邊位置，依實際框高與動畫位移預留垂直空間。`SkillFeedback` 持有錨點並執行量測 hook，在自身錨點與子層提示 DOM 的 ref 都掛載完成後，於 layout effect 讀取尺寸及設定位置；`SkillNameLayer` 負責呈現提示並接收圖層 ref。位置量測集中於事件增減、內容尺寸或視窗變更，捲動時沿用已量測的提示尺寸並更新定位，靜止時沿用結果，卸載時解除尺寸與捲動監聽；淡入與上飄由 CSS 動畫執行。文字旁圖示透過共用 CSS 與字級同步縮放。

技能輪播使用實際經過時間處理已到期事件與數值，連續技能從前一輪播在該時間點的顯示值接續。最終值沿用正式計算結果。攻擊保留有限 CSS 過渡完成的等待機制，持續漂浮與裝飾動畫由自己的生命週期管理。

骰面攻擊數字的動畫字級隨既有輪播幀更新，落定後依結果值維持字級，連續技能讀取目前可見字級接續；每個目標獨立持有動畫，其他目標開始時持續播放，結算等待存續動畫完成。敵人命中浮字由獨立 `DamagePopLayer` 掛載至共用浮動圖層，每筆依量測字寬、膨脹及上飄範圍占用位置；位置在出生時保存，視窗尺寸變更時重新配置。各筆 Web Animations 動畫沿出生時間獨立播放，新增浮字保留現有動畫進度，結束或卸載時釋放動畫。傷害浮字生命週期與字級設定集中於 `src/configs/numberFeedbackConfig.ts`。

展開圖技能小窗開啟時才訂閱預覽所需的骰池、回合與裝備資料，並以輸入參考記憶計算結果。配置計數與戰鬥共用，Control 階段沿用純結算計算；滑鼠移動與數字動畫維持原有更新範圍。

## 繪製與音效

受擊亮框掛載至 game-stage 的共用浮動圖層，以固定的內側發光覆蓋完整遊戲畫面邊緣，外圍滿版背景保持原樣。圖層直接訂閱逐次命中，使用 Web Animations 只更新 opacity；連擊從當下亮度追加至上限再淡出，同幀命中亦逐次接收，recoil 沿用目前動畫。生命受損使用紅色，純護盾吸收使用藍色，零傷害保持靜止。顏色、發光寬度、亮度、重擊倍率、淡出時間與圖層順序集中於 `src/configs/playerImpactConfig.ts`，撞擊圓環沿用相同配色。減少動態效果降低亮度，切換場景、隱藏分頁及卸載時清理動畫與訂閱。

主力魚眼維持既有位移效果，強度相同時保留目前值；變化完成後停止更新。透光追加骰以半透明色面、靜態高光、內陰影及六面立體投影維持外觀，合成時使用局部位移與縮放。角色分層圖片與魚眼位移貼圖於主選單預先解碼。

音效環境在玩家點擊開始遊戲時初始化，播放時沿用相同 AudioContext。撞擊噪音資料建立一次並重用，各次聲源保留獨立的音量與播放時序，結束後中斷聲源、增益及濾波節點連線。輪播音效間隔由 `src/configs/battleConfig.ts` 管理，與畫面更新頻率分開計時。

## 驗證方式

以型別檢查、正式網頁建置及既有核心邏輯測試確認整合。人工比較開場初擲、單骰連續重骰、六骰技能結算與複數敵人依序行動、主力魚眼、追加骰連續撞擊、重開 Run 與視窗縮放，觀察掉幀、數值落定、扣血時間及動畫清理。Mac 與 Windows 分別以正式建置及桌面封裝確認，效能改善幅度以實機幀時間量測為準。

敵人圖片的攻擊位移與受擊變形使用分開的節點，前者使用蓄力、衝刺、碰撞微彈與返回四段有限動畫，後者直接訂閱逐次命中並用 Web Animations 接續姿勢，沿 config 的交替衰減序列呈現先上後下的短促震動，命中第一拍輕微壓縮後立即恢復比例，保持頭頂資訊與意圖框穩定。透明閃亮遮罩只動畫 opacity，變形只動畫 transform；完成或卸載時釋放動畫。圖片、圖片遮罩與戰前縮圖共用資源表，檔名集中於外觀 config。

敵人出手由遊戲畫面提供動畫完成等待器，只等待敵人本體當段有限動畫，衝刺結束後才提交扣血、音效、紅框及前景衝擊。無畫面的結算呼叫沿 config 時長推進。速度殘影複用原始圖片，速度線使用靜態漸層形狀，只動畫 transform 與 opacity；僅出手期間掛載，減少動態效果時收起。各段延續前段終點，切換場景或卸載中止舊演出。
