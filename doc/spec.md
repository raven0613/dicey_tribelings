# Dice Sticker Roguelite — Current Spec

> 版本：2026-09-05
>
> 定位：單人骰子構築 Roguelite
>
> 核心：養骰子、改骰面、追組合、有限 Control、快速結算

本文件為遊戲規格入口。[生物骰面與結算規則](creatures.md) 管理生物種類、效果、骰面關係、追加攻擊與結算順序；[裝備與構築](equipment.md) 管理裝備效果、槽位、取得流程與效果呈現；[怪物與關卡設計](monsters-and-regions.md) 管理區域路線、怪物、Intent、骰子里程碑與戰鬥成長目標，並提供對應 config 的修改入口。

# 1. 遊戲定位

玩家沿著地圖逐格前進，經歷一般戰鬥、寶箱、商店、菁英與 Boss。每場戰鬥一次擲出整個骰池，玩家使用有限的 Control 修正少數結果，再由生物骰面之間的支援、繁衍、捕食、食腐與裝備完成自動結算。

骰子本身是 Build 主體。玩家透過固定進度取得更多骰子，使用永久貼紙持續改造骰面，並以裝備改變生物連鎖、操骰方式與資源價值。一次性貼紙則提供戰前準備與單場爆發，讓玩家能為困難戰鬥投入有限資源。

# 2. 核心體驗

每回合的主要決策是判斷目前結果是否值得消耗 Control。玩家能直接看懂每顆骰子的生物、數字與已成立的關係，並從數字成長與連鎖結算中感受到 Build 的成果。每顆骰子的所有面都具有構築用途，玩家透過同骰配置、骰面鄰接、鄰骰支援與本輪組合建立生物之間的關係。

每個 Run 同時提供兩條清楚的成長軸。固定里程碑擴大骰池規模，高數值永久貼紙提高單顆骰子的輸出上限。兩條成長軸共同支撐「骰子越來越多，每顆骰子也越養越強」的體驗。

# 3. 核心循環

一個完整節點循環如下：

1. 玩家前進至下一個地圖節點。
2. 節點觸發一般戰鬥、寶箱、商店、菁英或 Boss。
3. 戰鬥節點先進入戰前準備，玩家配置一次性貼紙並確認開戰。
4. 玩家擲出所有骰子；骰子落定後，系統預覽生物與裝備效果，玩家查看結果並決定是否使用 Control。
5. 玩家鎖定結果，系統套用裝備對骰面結果與關係規則的改寫，依生物結算順序完成傷害、護盾與攻擊清單。
6. 骰子的數字快速成長至最終值，透光追加攻擊骰進場，攻擊清單中的骰子再逐顆撞向敵人。
7. 敵人存活時執行行動，接著開始下一回合；敵人被擊敗時進入獎勵流程。
8. 玩家處理永久貼紙、一次性貼紙、貼紙包或裝備，然後前往下一個節點。

# 4. 地圖與關卡進度

正式版以六區完成一個 Run，Demo 涵蓋前三區。玩家逐節點前進，透過固定里程碑取得新骰，並在戰鬥與補給間調整構築。區域分工、骰池進度與終章路線見[怪物與關卡設計](monsters-and-regions.md#2-六區進度與骰子里程碑)。

# 5. 骰子與骰面

骰子可以採用 d4、d6、d8、d10、d12 等面數，也可以具有不同的初始數值分布、生物配置與外觀主題。開局骰數與新增進度由[骰子里程碑](monsters-and-regions.md#2-六區進度與骰子里程碑)統一管理。

骰子的面數代表可擲出的骰面數量，骰面攻擊值採用獨立數值，因此任何骰面都能成長至高於骰子面數。每個骰面由生物種類與基礎攻擊值組成，例如兔子4、狐狸3、蜂鳥7與老虎10；生物種類決定標籤與效果，數字提供基礎傷害與效果取值。

骰子的所有有效面共同參與構築。能力依文案讀取本次擲出的結果、同骰其他面、幾何相鄰面或左右鄰骰；骰子落定後依並排位置呈現鄰接關係。生物名單、效果與關係範圍見[生物骰面與結算規則](creatures.md)。

# 6. 骰面數值成長

永久貼紙隨區域進度提供更高品質的骰面，一次性貼紙提供單場強化，裝備與生物效果放大構築成果。新骰與各來源獎勵的成長關係、校準目標及設定入口見[骰池與獎勵成長](monsters-and-regions.md#3-骰池與獎勵成長)。

# 7. 永久貼紙

永久貼紙是長期骰面構築的主要來源。玩家取得永久貼紙後立即選擇一顆骰子與一個骰面，貼紙會永久覆蓋該面的生物種類與基礎攻擊值；玩家也可以放棄本次貼紙，放棄的貼紙立即銷毀。

永久貼紙採即時處理制，最終結果只有貼上或銷毀兩種。一般戰鬥獎勵、貼紙包與其他獎勵來源都使用相同流程，永久貼紙處理完成後才繼續後續獎勵或節點流程。

例如一顆初始 d6 可以從：

`草1 / 草1 / 花2 / 花2 / 兔子3 / 兔子4`

逐步改造成：

`兔子8 / 兔子5 / 兔子10 / 熊3 / 草7 / 香蕉12`

# 8. 一次性貼紙與消耗品欄

一次性貼紙是單場戰鬥消耗品，取得後存入獨立消耗品欄。消耗品欄固定為 3 格，並與裝備槽分開管理；每張貼紙是獨立物件，相同種類可以同時持有多張。

取得新一次性貼紙時，玩家可以將貼紙收進空槽，也可以放棄新貼紙。三格皆滿時，玩家可以選擇一張既有貼紙進行取代，也可以放棄新貼紙；每張新貼紙各自完成一次選擇，被取代或被放棄的貼紙立即銷毀。貼紙包一次開出多張一次性貼紙時，系統依序處理每一張。

商店購買一次性貼紙時，金幣會在玩家確認收納或取代後扣除。玩家取消購買時保留原有金幣與消耗品欄內容。

# 9. 戰前準備與一次性貼紙配置

每個戰鬥節點先進入戰前準備階段。玩家可以查看敵人、目前骰池與消耗品欄，並自由選擇零張至目前持有數量的一次性貼紙；消耗品欄最多持有三張，因此單場最多配置三張。

每張一次性貼紙覆蓋一個指定骰面，每個骰面同時承載一張一次性貼紙。玩家可以在確認開戰前調整或撤回配置；確認開戰後，已配置貼紙從消耗品欄移除並附著於指定骰面，整場戰鬥的配置隨即鎖定，接著開始第一次擲骰。

一次性貼紙在整場戰鬥的每個回合持續生效。擲出結果、同骰配置與鄰骰支援都使用貼紙上的生物種類與基礎攻擊值，並依該生物的標籤與效果判定關係。戰鬥結束後，所有一次性貼紙從骰面移除並銷毀，被覆蓋的永久骰面完整恢復；留在消耗品欄中的貼紙則保留至後續節點。

# 10. 貼紙包

貼紙包是高價值即時獎勵，內容可同時包含永久貼紙與一次性貼紙。每種貼紙包的張數、內容池、稀有度與混合規則由貼紙包設定檔管理。

玩家選擇貼紙包後立即開包，系統先展示完整內容，再逐張完成處理。永久貼紙依序進入立即貼附或銷毀流程；一次性貼紙依序進入收納、滿格取代或銷毀流程。所有內容處理完成後，開包流程結束並回到原本的獎勵或節點流程。

# 11. 一般戰鬥獎勵

一般怪物提供穩定的永久骰面成長。戰鬥勝利後顯示三個永久貼紙選項，玩家選擇其中一張進行立即處理，也可以略過整組貼紙獎勵。

每次一般戰鬥結算有 5% 機率將其中一個永久貼紙選項替換成貼紙包，形成 Jackpot。這個機率以每次獎勵畫面為判定單位，並由獎勵設定檔管理；一般怪物的金幣獎勵也由相同類型的數值設定統一管理。

# 12. 寶箱獎勵

寶箱提供三個高價值候選項目，玩家選擇其中一項。每個候選位置各自先依權重決定獎勵類型，再從對應獎勵池抽出具體品項；三個候選皆為不同品項。

寶箱類型的基準權重如下：

- 裝備：65%。
- 貼紙包：35%。

三個候選位置採用相同權重獨立判定，因此寶箱可能提供三件裝備、三個貼紙包或兩種類型的混合結果。權重由獎勵設定檔管理，寶箱同時可以提供設定檔指定的固定金幣獎勵。

玩家選擇貼紙包後立即進入開包流程；選擇裝備後，依[裝備槽與效果呈現](equipment.md#1-裝備槽與效果呈現)完成收納或替換及落槽演出，再結束寶箱獎勵流程。

# 13. 菁英與 Boss 獎勵

菁英提供高價值構築獎勵，區域 Boss 推進階段，版本終點的 Boss 完成 Run。各區獎勵角色、Demo 與正式版終點見[怪物與關卡設計](monsters-and-regions.md#2-六區進度與骰子里程碑)。

# 14. 裝備與裝備槽

裝備透過生物連鎖改寫、Control 操作、戰術效果與 Run 資源運用形成構築，與骰面配置共同決定玩家的作戰及成長方式。十八件裝備的效果、槽位與取得流程統一記錄於[裝備與構築](equipment.md)。

# 15. 商店

普通商店販售裝備、回血、一次性貼紙與其他 Build 調整資源。骰子新增維持關卡里程碑制，永久貼紙成長維持戰鬥獎勵與貼紙包制，使商店專注於補給、戰術準備與裝備調整。

玩家購買一次性貼紙時，依消耗品欄規則確認收納或取代；購買裝備時，依[裝備槽規則](equipment.md#1-裝備槽與效果呈現)確認收納或替換。交易在確認後扣除金幣，取消操作會回到商店並保留交易前狀態。

# 16. 基礎戰鬥流程

每回合開始時，玩家一次擲出所有骰子。遊戲邏輯先決定每顆骰子的結果，演出系統再播放拋物線、旋轉、碰撞與落地微彈，並在約 0.6～1 秒內讓所有骰子穩定落地。骰子停止後會旋轉至清楚呈現預定結果的角度，系統接著顯示生物與裝備效果預覽並進入 Control 階段。

玩家完成 Control 操作後鎖定結果。傷害預覽與正式結算共同使用裝備改寫後的骰面結果與關係規則，依[生物結算順序](creatures.md#3-結算順序)完成支援與繁衍、捕食、食腐及攻擊，並在對應步驟計入裝備效果。預覽推算本輪結果，鎖定後正式套用一次儲糧等狀態變化，再依最終攻擊清單播放數字成長與攻擊演出。敵人存活時保留剩餘生命與護盾，執行當前意圖及對應裝備效果後開始下一回合；玩家的剩餘護盾與 Control 延續至下一回合。任一方生命歸零時結束戰鬥。

# 17. Control 系統

每場戰鬥開始時，玩家取得基礎 3 點 Control，並計入裝備提供的起始加成。基礎操作為消耗 1 點 Control，選擇 1 顆骰子重新擲一次；Control 在整場戰鬥中共用，每場開戰時重新計算起始值。

Control 讓玩家修正骰面結果，並透過裝備提供的換位操作調整骰子排列。每次操作後，系統依目前結果與位置重新預覽支援關係、捕食對象、追加攻擊、護盾及最終傷害；裝備操作與效果見[Control、戰術與戰鬥資源](equipment.md#3-control戰術與戰鬥資源)。

# 18. 生物效果與追加攻擊

生物效果以同骰配置、鄰接關係、本輪組合與跨回合儲糧改變骰池結果。猩猩與老虎利用同骰的生物面數，蜜蜂與蜂鳥讀取花面，熊儲存食物數值，螞蟻依連續相鄰隊列合力攻擊；完整能力由[生物效果](creatures.md#2-生物效果)統一管理。

繁衍、授粉、食腐與裝備可以產生追加攻擊。每筆追加攻擊以透光骰子承載指定傷害，在正常骰子數字結算後進場並參與撞擊。本輪擲出的生物數量、配對與捕食以正常骰子的有效結果判定；追加攻擊依其來源與明確指定追加骰的規則取得加成。

高基礎值骰面提供直接輸出，功能骰面透過支援、追加攻擊、防禦與操骰效果提高構築價值。永久貼紙同時改變單面的攻擊品質及整顆骰子的關係配置，形成貼附與替換時的取捨。

# 19. 防禦與回血

防禦能力以「基礎攻擊＋生物關係提供生存效果」為主要形式，例如大象依本輪其他草食動物提供護盾，鹿透過 Control 重骰留下護盾，樹為鄰骰鳥類提供庇護。護盾依生物效果與裝備規則計算，讓玩家以部分輸出配置換取穩定性。

回血效果採用較低出現率，並搭配每場觸發次數、回血上限、擊殺條件或其他限制。回血規則提供生存選擇，同時維持戰鬥向前推進的節奏。

# 20. 戰鬥結算與演出

結算開始後，骰子的數字依生物與裝備的計算步驟快速變化至最終值，攻擊加成與護盾轉換各自呈現對應的數值變化。單位數結果維持單位數顯示，雙位數結果則清楚呈現對應位數。玩家可以從數字變化直接理解 Build 如何放大原始骰面，例如 `3 → 5 → 8 → 12`。

正常骰子完成數字結算後，生物與裝備產生的追加攻擊以透光骰子在來源骰旁進場，並完成自身數字結算。接著由最終攻擊清單中的正常骰子與透光追加骰依序撞向敵人。繁衍來源被捕食後，其已成立的追加攻擊仍照常進場與撞擊；被捕食的正常骰子留在原位顯示本輪已被捕食，螞蟻隊列由末端骰子承載合力攻擊。敵人在攻擊序列中途被擊敗時，清單內的剩餘攻擊仍完成演出，收尾節奏同步加快。

一次性貼紙在整場戰鬥中保持附著狀態，骰面檢視、關係預覽與擲出結果皆呈現其有效生物種類與基礎攻擊值。戰鬥結束時播放貼紙移除回饋並恢復原本骰面。

一般結算從鎖定結果到攻擊完成以約 1.5～3 秒為目標，大型 Combo 或 Boss 爆發可以短暫延長。骰子數量增加後，單顆攻擊間隔同步縮短，使後期火力表現更密集並維持快速節奏。

# 21. 敵人回合

玩家攻擊完成後，存活敵人依一行 Intent 判定並執行行動，再開始新一輪擲骰。Intent 文案、條件、結算順序與各怪物招式見[Intent 共通規則](monsters-and-regions.md#4-intent-共通規則)。玩家生命歸零時結束 Run，敵人生命歸零時進入勝利流程。

# 22. Build 方向

高數字 Build 集中取得高基礎值永久貼紙；同骰 Build 利用猩猩的集中配置、兔子的繁衍門檻與老虎的獨居條件，決定每顆骰子的面數分配。棲地與鄰接 Build 透過蜜蜂、蜂鳥、樹與螞蟻，連接骰面幾何與骰子排列。

群體與多樣性 Build 調整狼、草食動物及植物的比例；捕食與食腐 Build 以獵物的正常攻擊換取捕食加成，並讓禿鷹接續追加攻擊。儲糧 Build 透過食物與熊安排跨回合的準備與爆發，生存 Build 透過護群、逃逸、庇護與回血來源提高容錯。

裝備構築與上述生物方向交叉搭配，改變連鎖規則、Control 運用及金錢、補給、獎勵與空槽的價值。具體效果見[裝備與構築](equipment.md)。

# 23. 介面與資訊規則

戰鬥畫面持續顯示玩家生命、護盾、金幣、Control、地圖進度、骰池數量、裝備槽與三格消耗品欄。裝備槽與消耗品欄採用獨立區域，讓永久被動與單場資源保持清楚區別。

戰前準備會顯示一次性貼紙的目標骰子、目標骰面、覆蓋前內容與覆蓋後內容。骰面檢視呈現整顆骰子的生物配置、有效數值與相鄰面，戰鬥預覽呈現生物連動、捕食對象、追加攻擊、儲糧及總傷害。永久貼紙、一次性貼紙、貼紙包與裝備替換都提供明確的確認與放棄操作；需要連續處理多張貼紙時，介面會顯示剩餘數量與目前處理項目。

# 24. 數值設定來源

所有可調整的遊戲數值集中放在 `src/configs`，由對應設定檔作為唯一來源。服務與介面讀取設定值並呈現結果，使機率、槽位、價格、里程碑與數值曲線保持一致。

本次規格要求至少集中管理以下參數：

- 一般戰鬥貼紙包 Jackpot：5%。
- 寶箱裝備權重：65%。
- 寶箱貼紙包權重：35%。
- 寶箱候選數量：3。
- 消耗品欄容量：3。
- 裝備槽容量、效果加值、轉換比例、操作成本、機率與成長參數，依[裝備規格](equipment.md)集中管理。
- 每場基礎 Control：3。
- 各貼紙包的張數、內容池與混合規則。
- 生物骰面的基礎值、效果加值、倍率、護盾量與觸發門檻。

怪物、地圖、骰子里程碑與區域成長的對應設定檔見[設定檔與修改入口](monsters-and-regions.md#12-設定檔與修改入口)。

Demo 沿用正式版前三區的構築與成長曲線，在階段 Boss 後收束體驗；正式版延伸至六區終章。區域內容、怪物名單與骰池規模統一記錄於[怪物與關卡設計](monsters-and-regions.md)。貼紙與裝備的內容量依各階段的構築選擇及驗證結果調整。

# 26. 核心驗證問題

核心系統透過實際遊玩回答以下問題；敵人強度、戰鬥回合、Intent 理解與骰池擴張另依[數值校準與驗證](monsters-and-regions.md#11-數值校準與驗證)檢查。

1. 玩家能否在第一次戰前準備中理解一次性貼紙會持續整場並於戰後消失？
2. 三格消耗品欄是否能形成保存、使用、取代與放棄之間的有效取捨？
3. 玩家是否願意在菁英或 Boss 前投入多張一次性貼紙？
4. 高基礎值輸出面與依靠生物關係的功能面是否都具有實際選擇價值？
5. 基礎 3 點 Control 與裝備加成是否能支撐重骰、換位及保留資源的取捨？
6. 裝備、永久貼紙與一次性貼紙是否各自具有清楚角色？
7. 寶箱的 65% 裝備與 35% 貼紙包權重是否形成足夠的獎勵變化？
8. 一般戰鬥的 5% 貼紙包 Jackpot 是否稀有且值得期待？
9. 寶箱裝備的移動、落槽與滿槽替換回饋是否讓玩家清楚理解目標槽位與最終結果？
10. 玩家能否理解裝備的生效條件，並在重骰或換位後辨認預覽中的效果變化？
11. 後期大量骰子是否仍能快速讀懂並在主要結算時間內完成攻擊？

# 27. 核心總結

本作的核心是把少量初始骰子一路養成具有高數字、生物關係、跨骰連鎖與裝備協同的強力骰池。固定進度里程碑帶來更多骰子，永久貼紙帶來單面長期成長，一次性貼紙帶來戰前規劃與單場爆發，裝備透過連鎖改寫、操骰方式與資源運用形成貫穿 Run 的構築。

每回合的主要體驗為：

> **戰前配置有限資源 → 擲出自己養成的骰池 → 使用 Control 修正關鍵結果 → 看數字與連鎖迅速放大 → 骰子連續撞向敵人。**
