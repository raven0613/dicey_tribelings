# Dice Sticker Roguelite — Current Spec

> 版本：2026-09-08
>
> 定位：單人骰子構築 Roguelite
>
> 核心：養骰子、改骰面、追組合、有限 Control、快速結算

本文件為遊戲規格入口。[土人骰面設計](tribelings.md) 統一管理世界觀、角色與食物骰面、標籤、能力及回合結算順序；[裝備與構築](equipment.md) 管理裝備效果、槽位、取得流程與效果呈現；[怪物與關卡設計](monsters-and-regions.md) 管理區域路線、怪物、Intent、骰子里程碑與戰鬥成長目標，並提供對應 config 的修改入口。[特殊材質骰面](special-materials.md) 管理材質效果、取得與外觀。[地下篇與難度進程](progression-roadmap.md) 管理後續篇章、加工與完整通關解鎖。本文件管理骰子與貼紙的共通流程、戰鬥演出及介面資訊。

# 1. 遊戲定位

玩家沿著地圖逐格前進，經歷一般戰鬥、寶箱、商店、菁英與 Boss。每回合一次擲出整個骰池，玩家使用有限的 Control 修正少數結果，透過土人之間的支援、重骰連鎖、搶奪、儲糧與身分配合形成組合，再依技能與裝備效果完成結算。

骰子本身是 Build 主體。玩家透過固定進度取得更多骰子，使用永久貼紙持續改造骰面，並以裝備改變角色連鎖、操骰方式與資源價值。臨時貼紙則提供單場補組合，讓玩家能為困難戰鬥投入有限資源。

# 2. 核心體驗

每回合的主要決策是判斷目前結果是否值得消耗 Control。玩家能直接看懂每顆骰子的角色或食物、數字與已成立的關係，並從數字成長與連鎖結算中感受到 Build 的成果。每顆骰子的所有面都具有構築用途，玩家透過同骰配置、左右鄰骰、朝上組合與標籤建立角色之間的關係。

每個 Run 同時提供兩條清楚的成長軸。固定里程碑將三骰擴大至最多七骰，新骰使用低值角色面提供配置空間；高數值永久貼紙提高單顆骰子的品質與組合專精。普通戰展示成長成果，菁英與 Boss 讓玩家依前段威脅選擇保留組合、重骰或承受攻擊。

# 3. 核心循環

一個完整節點循環如下：

1. 玩家前進至下一個地圖節點。
2. 節點觸發一般戰鬥、寶箱、商店、菁英或 Boss。
3. 戰鬥節點顯示敵人與骰池；首次取得臨時貼紙後才顯示消耗品配置區，按下首次擲骰時消耗並鎖定配置。
4. 玩家擲出所有骰子；骰子落定後，系統預覽角色與裝備效果，玩家查看結果並決定是否使用 Control，依能力處理重骰連鎖。
5. 玩家完成重骰連鎖並鎖定結果，系統套用裝備對骰面結果與關係規則的改寫，依[回合結算順序](tribelings.md#回合結算順序)完成傷害、護盾與攻擊清單。
6. 系統依技能結算順序播放相關骰子的同步脈衝、技能名稱與數字變化，追加攻擊隨來源技能呈現；所有攻擊數字落定後，依攻擊清單撞向敵人。
7. 敵人存活時執行行動，接著開始下一回合；敵人被擊敗時進入獎勵流程。
8. 玩家處理永久貼紙、臨時貼紙、貼紙包或裝備，然後前往下一個節點。

# 4. 地圖與關卡進度

本次提供鱷魚人篇六區難度一；前三區為 Demo 邊界。完整 Run 規劃由鱷魚人與地下篇接續，完成兩篇才解鎖下一難度。進入每區即顯示完整地圖，各節點以圖示與名稱呈現，怪物名稱依階級上色；hover 或鍵盤聚焦的小窗提供獎勵與簡短機制名詞。每區在共同節點後選擇穩定路普通戰或挑戰路菁英，完成後在商店匯合，未選路線保留為已放棄。玩家沿節點連線前進，透過共同里程碑取得新骰，並在戰鬥與補給間調整構築。區域分工、骰池進度與終章路線見[怪物與關卡設計](monsters-and-regions.md#2-每區完整地圖與分岔)。

# 5. 骰子與骰面

骰子可以採用 d4、d6、d8、d10、d12 等面數，也可以具有不同的初始數值分布、角色與食物配置及外觀主題。開局骰數與新增進度由[骰子里程碑](monsters-and-regions.md#2-每區完整地圖與分岔)統一管理。

骰子的面數代表可擲出的骰面數量，骰面攻擊值採用獨立數值，因此任何骰面都能成長至高於骰子面數。每個骰面由角色或食物種類、基礎攻擊值與至多一種特殊材質組成，例如土人家族4、土人勇士7與好吃的10；種類決定標籤與能力，數字提供基礎傷害與效果取值。角色使用普通、戰士、職人、貴族與神秘等標籤，食物使用食物標籤，實際組合由[土人骰面角色與效果](tribelings.md#土人骰面角色與效果)統一管理；材質效果、取得與外觀見[特殊材質骰面](special-materials.md)。

骰子的所有有效面共同參與構築。「同骰」涵蓋該骰子的所有有效面，「同骰其他面」排除目前擲出的面；「左右鄰骰」指並排位置中直接位於左側或右側的骰子，兩端各有一顆鄰骰。各能力依[土人骰面設計](tribelings.md)指定的範圍，讀取朝上結果、同骰配置、鄰骰所有面或當回合事件。臨時貼紙附著期間，以覆蓋後的種類、標籤與基礎值參與判定。

戰鬥場上的正常骰子採用 2D 骰體與平面擲骰動畫，以骰型輪廓、角色或食物圖示及攻擊值呈現朝上結果，Control 階段直接點擊骰體重骰；追加攻擊維持同尺寸基準的 3D 透光骰。戰鬥區採固定高度分區，攻擊骰盤持續預留追傷槽位，並依視窗寬高同步調整兩類骰子的尺寸，追傷進出沿用固定定位。骰面檢視依[介面與資訊規則](#23-介面與資訊規則)，技能回饋、追傷進場與撞擊依[戰鬥結算與演出](#20-戰鬥結算與演出)呈現。

# 6. 骰面數值成長與稀有度

永久貼紙依取得地區提高基礎值，既有骰面保留取得時的值。六區加值、獎勵與里程碑由[骰池與獎勵成長](monsters-and-regions.md#3-構築與恢復)管理。

角色稀有度依能力對構築的影響、放大與堆疊能力設定。同角色在各區維持相同稀有度；一般提供常用零件，稀有提供構築放大與轉型，傳說提供特殊目標。完整分級見[土人骰面設計](tribelings.md#骰面稀有度)。介面以「一般／稀有／傳說」文字搭配顏色呈現，角色標籤「普通」維持獨立意義。

# 7. 永久貼紙

永久貼紙是長期骰面構築的主要來源。玩家取得永久貼紙後立即選擇一顆骰子與一個骰面，貼紙會永久覆蓋該面的角色或食物種類、基礎攻擊值與材質；玩家也可以放棄本次貼紙，放棄的貼紙立即銷毀。

永久貼紙採即時處理制，最終結果只有貼上或銷毀兩種。一般戰鬥獎勵、貼紙包與其他獎勵來源都使用相同流程，永久貼紙處理完成後才繼續後續獎勵或節點流程。

例如將「土人家族3」覆蓋為「土人家族8」，可以提高該面的基礎輸出；將同骰的一個家族面改為土人工匠，則會改變家族面數；工匠朝上時依相鄰 [職人] 面提供護盾。貼附同時影響單面品質與整骰配置，玩家依構築方向選擇替換位置。

戰利品選擇視窗提供「查看骰池」入口，開啟共用的骰面展開圖。檢視期間保留已選戰利品，骰池視窗顯示在最上層；關閉後回到原本的選擇位置。

# 8. 臨時貼紙與消耗品欄

臨時貼紙提供單場組合零件，持有時記錄角色或食物種類、標籤、能力與角色稀有度。套用時保留目標永久骰面的材質並沿用其有效基礎值，例如勇士 12 暫時變成姐妹花 12。消耗品欄固定三格，每張貼紙為獨立物件，同種類可持有多張。

取得貼紙時有空格便直接收納；滿格時選擇替換既有貼紙或放棄新貼紙。貼紙包按內容順序處理，空格收納自動完成。商店購買有空格時直接扣款入欄，滿格時於確認替換後扣款。

首版臨時內容集中於家族、姐妹花、雙胞胎、混混、孩子王、廚師、搬運工、跟班、勇士、毛賊、膽小土人、侍衛、工匠、農夫、好吃的與搗蛋鬼。單張售價初版 12 金幣，角色稀有度沿用永久版本。

# 9. 首次擲骰與臨時貼紙配置

玩家尚未取得過臨時貼紙時，每場戰前只顯示敵人、問號骰盤、生命與「擲骰」按鈕，隱藏消耗品欄、貼紙說明及骰面配置編輯器。首次實際取得臨時貼紙後永久解鎖配置介面，跨 Run 保留；庫存用完仍保留配置區。解鎖後，戰鬥畫面在首次擲骰前提供臨時貼紙配置區，三格貼紙欄集中顯示於配置區。玩家點選貼紙，再透過共用骰子展開圖選擇目標面；畫面呈現原面、覆蓋後角色、沿用基礎值與配置位置。貼附前可調整位置或撤回，每張貼紙配置一面，每面承載一張。庫存為空時仍可直接按下「開始擲骰」。

玩家按下「開始擲骰」時消耗已配置貼紙並鎖定整場配置。每回合的擲出結果、同骰配置、鄰骰支援與標籤能力，共用替換後種類及目標永久面的基礎值。戰鬥結束時移除單場覆蓋，恢復完整永久骰面；庫存中尚未使用的貼紙保留。

# 10. 貼紙包

貼紙包依家族、食物、戰術與貴族主題提供即時獎勵，先展示完整內容，再依序處理。永久貼紙立即貼附或放棄，臨時貼紙自動收進空格，滿格才選擇替換或放棄。

永久內容依開包所在地區取得基礎值，同角色稀有度固定。一般主題包三張、至少兩張永久與一張臨時；貴族包四張永久，依小公主專屬機率與 Run 上限發放。第六區固定補給包提供兩張永久貼紙，作為終盤調整資源。內容與張數由貼紙包設定管理。

# 11. 一般戰鬥獎勵

一般怪物提供穩定的永久骰面成長。戰鬥勝利後顯示三個永久貼紙選項，玩家選擇其中一張進行立即處理，也可以略過整組貼紙獎勵。

每次一般戰鬥結算有 5% 機率將其中一個永久貼紙選項替換成貼紙包，形成 Jackpot。這個機率以每次獎勵畫面為判定單位，並由獎勵設定檔管理；一般怪物的金幣獎勵也由相同類型的數值設定統一管理。

# 12. 寶箱獎勵

寶箱提供三個不同候選，玩家可選擇一項，或跳過整份獎勵。第一個候選從可取得裝備抽取，另外兩個候選依裝備 65%、貼紙包 35% 的權重抽取；裝備候選支援替換已滿的五格裝備。寶箱獎勵為所選品項。

選擇貼紙包立即開包；裝備依[裝備槽與效果呈現](equipment.md#1-裝備槽與效果呈現)完成入欄或替換及落槽演出，處理完畢後前進。

寶箱三選一及滿槽裝備替換畫面皆提供「跳過獎勵，繼續前進」。跳過時清除本次候選與待替換裝備，不取得寶箱獎勵，保留原有裝備及金幣，沿正常流程前進至下一節點。裝備移動演出期間停用跳過；替換畫面開啟時，底下的寶箱畫面不可操作。

# 13. 菁英與 Boss 獎勵

菁英與第一至第五區 Boss 提供五張永久貼紙，選取兩張後依序貼附或放棄；玩家亦可選擇略過整組獎勵。區域 Boss 勝利恢復 15 HP，完成獎勵後進入下一區；第六區 Boss 勝利救回王子，完成鱷魚人篇；地下篇與下一難度解鎖依後續進程規劃。首區共同寶箱處理完成後額外取得一張小公主，沿用整趟三張的特殊取得規則。

# 14. 裝備與裝備槽

裝備透過角色連鎖改寫、Control 操作、戰術效果與 Run 資源運用形成構築，與骰面配置共同決定玩家的作戰及成長方式。裝備的效果、槽位與取得流程統一記錄於[裝備與構築](equipment.md)。

# 15. 商店

普通商店販售裝備、回血、臨時貼紙與其他 Build 調整資源。骰子新增維持關卡里程碑制，永久貼紙成長維持戰鬥獎勵與貼紙包制，使商店專注於補給、戰術準備與裝備調整。

玩家購買臨時貼紙時，空格直接收納，滿格選擇取代；購買裝備時，依[裝備槽規則](equipment.md#1-裝備槽與效果呈現)確認收納或替換。交易在確認後扣除金幣，取消操作會回到商店並保留交易前狀態。

# 16. 基礎戰鬥流程

每場戰鬥最多 50 回合。準備階段顯示「回合 1／50」，正式擲骰後顯示當前回合；剩餘 10 回合（第 41 回合起）使用醒目警示。第 50 回合完成敵人行動後，敵人仍存活即判定戰鬥失敗；玩家在最後一回合擊敗敵人仍取得勝利。

每回合開始時，玩家一次擲出所有骰子。遊戲邏輯先決定每顆骰子的結果，演出系統再播放拋物線、旋轉、碰撞與落地微彈，並在約 0.6～1 秒內讓所有骰子穩定落地。骰子停止後會旋轉至清楚呈現預定結果的角度，系統接著顯示角色與裝備效果預覽並依角色能力處理重骰連鎖及 Control 操作。

首次擲骰前的準備階段，骰體保留骰型輪廓，朝上內容以問號呈現；不顯示角色、數字或骰面提示，也不接受 Hover、鍵盤聚焦與骰子操作。按下擲骰後才進入正式擲骰與結果顯示。

玩家完成 Control 操作與重骰連鎖後鎖定結果。傷害預覽與正式結算共同使用有效骰面及裝備改寫後的關係規則，依[角色結算順序](tribelings.md#回合結算順序)計算各步驟結果，並在對應步驟計入裝備效果。鎖定後正式套用一次儲糧等狀態變化，同時記錄每次技能的發動者、參與者、受影響數值及變化前後值。演出依這份技能事件順序播放脈衝、技能名稱與數字輪播，再依最終攻擊清單完成撞擊；數值計算使用各步驟的正式結果。敵人存活時保留剩餘生命與護盾，執行當前意圖及對應裝備效果後開始下一回合；玩家的剩餘護盾與 Control 延續至下一回合。任一方生命歸零時結束戰鬥。

# 17. Control 系統

每場戰鬥開始時，玩家取得基礎 3 點 Control，並計入裝備提供的起始加成。基礎操作為消耗 1 點 Control，選擇 1 顆骰子重新擲一次；Control 在整場戰鬥中共用，每場開戰時重新計算起始值。

Control 讓玩家修正骰面結果，並透過裝備提供的換位操作調整骰子排列。每次操作及其重骰連鎖完成後，系統依目前結果、位置與已記錄事件，重新預覽支援關係、搶奪對象、儲糧、追加攻擊、再攻擊、護盾及最終傷害；角色對重骰的反應依[回合結算順序](tribelings.md#回合結算順序)，裝備操作與效果見[Control、戰術與戰鬥資源](equipment.md#3-control戰術與戰鬥資源)。

所有重骰（Control、金幣、老師與搗蛋鬼連鎖）均排除當下朝上的面索引，從其餘面等機率抽取；六面骰每次抽其餘五面之一。不同面若有相同角色與數值，結果仍可能相同；連續重骰可以由 A 面到 B 面再回 A 面。回合初擲仍從全部骰面等機率抽取。

# 18. 角色能力與攻擊種類

角色能力以同骰配置、鄰骰關係、本輪角色與標籤數量、重骰事件及跨回合儲糧改變骰池結果。角色與食物的完整能力、計數範圍、身分轉換及觸發條件由[土人骰面角色與效果](tribelings.md#土人骰面角色與效果)統一管理，各效果按[回合結算順序](tribelings.md#回合結算順序)處理。

正常攻擊由本輪有效骰面承載，依技能結算後的攻擊值執行。角色技能與裝備產生的每筆追加攻擊，以透光骰子承載指定傷害，在來源技能的演出節拍進入預留槽位並呈現數值變化，再依其適用加成完成撞擊。小公主命令的再攻擊，則由符合條件的貴族按最終攻擊值再次執行普通攻擊，其作用限於該筆攻擊。追加骰槽位依各骰有效配置可產生的最大追加數預留，混混的各次追傷與祭司本輪保留的追傷各占一格。偽裝者以已鎖定角色參與能力與計數，結算時呈現身分轉換。各類對象的計數、能力與加成範圍均由[土人骰面設計](tribelings.md)定義。

高基礎值骰面提供直接輸出，功能骰面透過支援、追加攻擊、防禦與操骰效果提高構築價值。永久貼紙同時改變單面的攻擊品質及整顆骰子的關係配置，形成貼附與替換時的取捨。

# 19. 防禦與回血

防禦能力以角色配置、標籤與重骰事件提供護盾。土人侍衛依本輪普通或貴族土人提供護盾，膽小土人在被重骰時留下護盾，朝上的土人工匠依同骰相鄰 [職人] 面數提供護盾。巨盾土人讀取本回合全隊累計獲盾值產生追加攻擊，護盾完整保留。能力與取值範圍依[土人骰面設計](tribelings.md)，使防禦配置同時支援生存與反擊構築。

玩家最大生命 60；商店花 20 金幣恢復 25 HP，第一至第五區 Boss 勝利恢復 15 HP，皆以最大生命為上限。剩餘護盾跨回合保留，每場開戰重置。

# 20. 戰鬥結算與演出

結算演出以每次技能觸發為單位，依[角色結算順序](tribelings.md#回合結算順序)呈現「參與骰子同步脈衝 → 技能名稱淡入 → 數值立即變化」。玩家透過同一節拍中的聲光與數字，辨認發動者、受影響對象及各次技能的貢獻，看到本輪骰子如何互相支援、轉移數值並形成連鎖。

## 20.1 技能脈衝與名稱

技能觸發時，發動骰與本次能力實際涉及的其他朝上骰子，同步向上發出一次脈衝光。脈衝採與裝備發動相同亮度的金白色核心與外圍光暈，發動骰以較大的發光範圍突出，參與骰同步發亮，其餘骰子維持原樣。文字與數字位於光效上層，保持清晰。同骰背面提供的支援由受益骰承載回饋，發光範圍對應實際參與的骰子。

技能名稱與本次增減合併為一行，在發動者及受影響骰子上方淡入，例如「互相提攜 +3」、「搶奪 -10」。提示清楚可見後立即啟動受影響數字的輪播。名稱在固定位置停留一小段時間，再向上飄移並淡出。各骰上方預留文字空間；同骰連續技能的名稱依先後略微錯開高度，保留前一名稱的可讀時間。

同階段且互相獨立的技能可同步播放；具有前後依賴的技能按結算順序保留可辨識的節拍間隔。前一名稱的停留與淡出可和後續技能重疊，使連鎖持續推進。

## 20.2 數字輪播與中斷接續

攻擊、追加攻擊、護盾與儲糧的輪播中間值統一以整數呈現，由目前顯示值緩動至該技能的目標值。攻擊目標依正式傷害向上取整；護盾與儲糧的動畫起訖值取整數部分，落定時顯示正式數值的完整精度。輪播值維持在動畫起訖值之間，增加時的數字位數以目標值為上限，減少時則從原值逐步下降。玩家總護盾在獲盾輪播期間也以整數呈現，落定後顯示正式總量。

內部技能計算保留精度；每筆正常、追加與再攻擊在套用撞擊時倍率後，最終傷害無條件進位，預覽總傷害為逐筆取整後的總和。每次技能影響觸發一次數字放大，峰值為原尺寸的 1.05～1.1 倍，再以緩動縮回原尺寸。單位數與多位數均依實際位數清楚顯示。

同一數字在輪播途中受到新技能影響時，立即中斷舊輪播，從當下顯示值接續至新技能的目標值；縮放也由當下比例接續，峰值維持在 1.1 倍以內，最後回到原尺寸。例如 `10 → 20` 顯示至 `16` 時，新技能使正式結果成為 `30`，畫面立即接續 `16 → 30`；技能計算仍以正式的 `20` 為前一步結果。

增減值直接接在技能名稱後面，攻擊倍率換算成本次顯示攻擊值的差額，例如「接力 +10」。差額由該技能正式前後值各自向上取整後相減，即使前一段輪播被中斷也保持該次增減的正確性。護盾與儲糧以小圖示標示資源種類；身分轉換顯示新身分，公主命令顯示「再攻擊」。技能回饋集中於骰子上方同一行。

## 20.3 不同效果的回饋對象

攻擊加值與倍率作用於攻擊數字，獲盾作用於護盾數字，追加攻擊則由對應透光骰與預留槽位呈現。追加骰在來源技能的節拍進場，並隨後續適用效果更新數字。首次進場、待機漂浮與攻擊位移各由獨立容器承載，骰身從進場、撞擊、歸位到待機全程維持完整立體外觀。出生動畫只在該顆追加骰首次進場時播放一次，歸位後繼續原有漂浮。追加傷害只由骰身數字與上方技能提示呈現。

追加骰的透視與六面立體合成在內層完成，魚眼只作用於合成後的外層；不將濾鏡套在維持 `preserve-3d` 的骰身、出生或漂浮容器上。位移容器獨立承載蓄力、衝刺及歸位，避免啟用魚眼時破壞立體顯示。

搶奪同時呈現雙方的數值變化：目標的攻擊下降或快速歸零，發動者的攻擊同步成長。搬運工整段隊列同步脈衝，隊尾呈現倍率帶來的成長，其餘成員維持各自攻擊。號角手讓受影響的正常骰同步跳數字；小公主的命令在符合條件的貴族上呈現回應，並於攻擊階段執行已登記的再攻擊。

## 20.4 音效與演出節奏

每次技能節拍使用一個主要音效，參與骰子共用該次聲音回饋。數字輪播搭配輕微滾動音，落定時播放短促收尾音。所有技能脈衝維持與裝備一致的明亮程度；全隊強化與高價值追加攻擊透過發光範圍及聲音重音呈現強弱層次。

演出初始調校範圍如下，實際值依可讀性與整輪節奏驗證：

| 項目                       | 初始調校範圍                 |
| -------------------------- | ---------------------------- |
| 脈衝起始至技能名稱清楚可見 | 約 60～100 ms                |
| 單次數字輪播與放大縮回     | 約 180～280 ms               |
| 名稱淡入後的停留時間       | 約 400～600 ms，接著向上淡出 |
| 數字放大峰值               | 原尺寸的 1.05～1.1 倍        |

## 20.5 攻擊與收尾

所有技能事件播放完畢、攻擊數字穩定落定後，正常骰、透光追加骰及再攻擊依最終攻擊清單撞向敵人。攻擊歸零的正常骰留在原位呈現本輪狀態；已成立的追加攻擊依清單完成演出。敵人在攻擊序列中途被擊敗時，清單內的剩餘攻擊仍完成演出，剩餘撞擊保持相同的初始速度。

每個撞擊階段等待畫面套用該階段並完成骰體的實際過渡動畫，才進入下一階段；衝刺完成時才扣血與播放命中回饋。最後一顆骰子歸位完成後才進入勝利或敵人回合，不以相同長度的計時器推定動畫已完成。只等待骰子的有限撞擊動作，不等待持續漂浮、光圈或技能提示。切換場景或重開 Run 時中止舊場景等待；減少動態效果或沒有屬性差異的階段，在畫面套用後即可完成。

敵人攻擊由整個敵人盒子短促撞向骰盤盒子的上緣，依序蓄力 80 ms、衝刺 70 ms、命中 90 ms、返回 120 ms；位移取兩盒邊緣的間距並加入少量撞入距離，重擊加強短縮與受擊幅度。命中瞬間播放撞擊音效，骰盤短促下沉、震動與閃光，同步扣除吸收傷害的護盾與穿透護盾後的生命。生命與護盾損失分開顯示；全額格擋呈現護盾受擊。敵人返回後切換下一個意圖，接續下一回合或戰敗結果。防禦、蓄力、休息與已被阻止的攻擊依意圖結果呈現。

臨時貼紙在整場戰鬥中保持附著狀態，骰面檢視、關係預覽與擲出結果皆呈現其有效角色或食物種類與基礎攻擊值。戰鬥結束時播放貼紙移除回饋並恢復原本骰面。

結算技能間隔 110 ms，數字輪播 240 ms；普通撞擊依序為蓄力 25 ms、衝刺 50 ms、命中 70 ms、歸位 35 ms，再間隔 15 ms。正常、追加與再攻擊在最終攻擊清單完成後，一次依各筆傷害相對其他攻擊的強度及整批傷害占比計算突出程度；以傷害加權的比較基準避免大量小額追傷造成錯誤強調。最高兩筆傷害相近且一起明顯領先其餘攻擊時，以其餘攻擊作為共同基準，讓雙主力或主力的再攻擊都能被辨識。全批傷害相近時不強制挑主力。

突出程度低於 0.25 時維持普通撞擊節奏；達門檻的主力骰在撞擊前放大至原尺寸 1.5～1.9 倍，中央魚眼同步膨脹。蓄力約 130～160 ms，以持續加速長大的動作呈現，膨到最大即衝刺，不額外停留。衝刺承接蓄力尺寸再拉伸，命中短縮後才平順縮回原尺寸及形狀；突出程度越高，膨脹與命中回饋越強，數字保持可讀。演出強度只影響視覺與節拍，不改變傷害或攻擊順序，敵人死亡後也不重新比較。正常、追加與再攻擊共用判斷及動作參數。減少動態效果設定停用魚眼與膨脹，以亮框辨識突出骰。整輪長度隨技能及攻擊數量自然增加；同階段獨立技能同步播放，名稱淡出可重疊，具有前後因果的技能保留固定辨識節拍。

# 21. 敵人回合

每筆玩家攻擊先套用怪物減傷、連擊破防及反擊條件；玩家仍存活時繼續後續攻擊。玩家攻擊完成後，存活敵人依公開 Intent 逐段執行行動，再開始新一輪擲骰。Intent 文案、條件、結算順序與各怪物招式見[Intent 共通規則](monsters-and-regions.md#4-共通敵人結算)。玩家生命歸零時結束 Run；玩家存活且敵人生命歸零時進入勝利流程。

# 22. Build 方向

高數字 Build 集中取得高基礎值永久貼紙；同骰 Build 透過土人家族的面數加值、雙胞胎的最高基礎值取用、混混的相鄰面追傷與獨行俠的單面條件，決定每顆骰子的配置。鄰骰與隊列 Build 透過土人跟班讀取鄰骰土人勇士最高基礎值、土人勇士計算鄰骰土人跟班面數及土人搬運工放大隊尾攻擊，形成站位取捨。

群體與身分 Build 利用姐妹花、啦啦隊、耆老及偽裝者組織角色數量與種類，透過權威、禁衛軍與小公主串接貴族身分及再攻擊。搶奪 Build 由孩子王與惡霸集中攻擊，讓毛賊接續產生追加攻擊；號角手再將追加骰數量轉成全隊正常攻擊的加成。

重骰 Build 透過老師、搗蛋鬼、膽小土人與祭司，把骰面調整連結到攻擊及護盾收益。食物與儲糧 Build 透過農夫、好吃的、廚師與大胃王安排食物數量、數值及跨回合爆發；護盾 Build 以侍衛、工匠與膽小土人提高容錯，再由巨盾把本回合獲盾量轉為攻擊收益。各構築的能力與結算依[土人骰面設計](tribelings.md)。

裝備構築與上述角色組合交叉搭配，改變連鎖規則、Control 運用及金錢、食物與剩餘 Control 的價值。具體效果見[裝備與構築](equipment.md)。

# 23. 介面與資訊規則

戰鬥資訊集中在骰盤周圍，臨時貼紙欄於戰前配置時顯示，常駐資源與工具整合於底部。

臨時貼紙配置區顯示目標骰子、目標骰面、覆蓋前內容與覆蓋後內容。骰面檢視與永久貼紙改造共用單一全圖版面，以清楚字級呈現每面的角色或食物、有效基礎值、標籤、能力與覆蓋資訊，內容依[土人骰面設計](tribelings.md)。展開圖與戰鬥共用面索引及骰型幾何，hover 或鍵盤聚焦骰面時高亮所有實際共用邊的相鄰面，提供配置位置辨識。

戰鬥畫面由上至下排列地區進度、敵人、骰盤、玩家生命與護盾、Control 與結算操作。首場待擲骰時聚焦骰盤與擲骰操作；配置階段呈現敵人、玩家狀態與配置區。底部 Footbar 整合裝備槽、金幣、音量與骰池按鈕，裝備技能發光與提示沿用同一組槽位。商店於走到商店格子時顯示，補血選項旁呈現目前生命與最大生命。

擲骰與結算按鈕共用清楚的高對比主要操作樣式，並以一致樣式表達懸停、鍵盤聚焦與停用狀態。滑鼠移入或鍵盤聚焦骰子時，骰盤底部資訊區立即顯示角色、標籤與完整能力；追加骰顯示來源與追傷說明。資訊區預留穩定高度並支援完整文字換行。每骰下方的攻擊、護盾與儲糧分項排列，完整顯示數值；窄欄位允許換行，骰盤依資訊高度預留空間。Control 階段的 Hover 骰子上方顯示本輪已發動技能的完整單行名稱，依視窗邊緣調整位置。資訊查看與骰子操作可用性分別處理。戰場專用說明將基礎值、計數、儲糧及技能結果帶入當前數字，保留觸發條件；其他畫面沿用角色原始敘述。角色名稱使用完整設定名稱，以共用關鍵字配色呈現。朝上的土人工匠顯示相鄰 [職人] 面數與本次護盾量；混混顯示相鄰土人混混面數、追加次數及每次傷害。

技能說明共用關鍵字呈現：所有完整土人名稱沿用角色設定色，「搶奪」使用橘紅色，「護盾」使用淺藍色。顏色與 Hover 演出參數集中於 `src/configs/skillPresentationConfig.ts`，骰面、裝備、獎勵、貼紙、商店與提示共用文字元件。

Control 階段的 Hover 關係、技能名稱與結算演出共用本輪技能判定結果。達成條件的技能顯示名稱與參與者金框；所有技能皆未發動時，骰子保留普通 Hover 亮光。朝上角色技能與本輪留下的效果各自判定。土人廚師依本輪入庫後的可用儲糧判定「加菜」；土人混混與土人工匠各自在符合條件的同骰相鄰面數大於零時發動；土人大胃王的有食物與飢餓分支皆發動；土人號角手在追加攻擊骰數大於零時發動。

底部技能說明保留條件，帶入判定當下的數量、門檻、取值及實際結果；未達條件時明示當前數量與零收益。土人大胃王顯示食物份數與該技能前後攻擊值，土人號角手顯示追加攻擊骰數與每顆正常骰加值。所有角色引用使用完整名稱。預覽骰體與標籤維持擲出時身分，身分轉換於結算播放對應事件時呈現；傷害與連鎖預估依完整結算結果計算。

支援參與者使用同色金框；相鄰接力及身分轉換使用相鄰連線；搶奪與再攻擊命令使用弧線箭頭。搶奪箭頭由來源指向既定目標，目標顯示本次攻擊減少的整數差值。搬運工隊列可從任一參與者檢視完整連接。Hover 擲出的好吃的時，顯示自身儲糧、直接強化該食物的農夫，以及使用食物計數的大胃王關係；全隊加成的關係由其發動者提供檢視。Hover 土人農夫時，轉化與自身儲糧只亮自己，強化實體食物則亮自己與該食物。同骰能力以自身高亮呈現；跟班的關係記錄包含提供最高勇士基礎值的鄰骰配置。各技能依其實際效果選擇高亮形式，說明保持簡潔。

連線以較粗亮色核心與外發光呈現，位於骰體後方；光框及名稱位於骰體前方。支援連線由提供者流向受益者，土人搬運工由左向右接力至隊尾；身分轉換與命令由發動者指向目標。搶奪箭頭由搶奪者指向被搶目標，吸取流光反向回到搶奪者。Hover 光框淡入淡出、連線延伸、弧線與減值提示均使用緩動補間；快速切換時接續最新目標並清除舊動畫，移出時平順退場。進入重骰與結算階段時收起 Hover 關係演出，結算技能依原本節拍播放。系統減少動態效果設定以淡入淡出取代位移與流光。

永久貼紙改造平時顯示原面，hover 時呈現覆蓋後的種類、數值、標籤與能力，點擊後套用貼紙；滑鼠離開則恢復原面顯示。文字採正向閱讀並在骰面安全區域換行，原內容與預覽共用預留空間。全圖版面依視窗調整尺寸，較小視窗以捲動保持字級與資訊可讀性。

Control 階段以點擊骰子執行重骰，控制列顯示 Control、傷害預覽與結算按鈕，並為每位仍有資格的老師提供免費重骰入口。玩家主動啟動老師，唯一合法目標直接重骰；有多個合法目標時高亮候選骰並由玩家選擇。選取期間可取消，取消不消耗老師資格；選取完成或取消前不可結算。沒有合法目標時入口停用，Control 歸零仍可使用老師。每次重骰連鎖落定後重新判斷其他老師的資格與最低值目標。換位、保護及翻面保留底層操作介面，供裝備互動接入。戰鬥預覽呈現角色連動、有效標籤、搶奪對象、追加攻擊、再攻擊、儲糧、護盾及總傷害。永久貼紙、臨時貼紙、貼紙包與裝備替換都提供明確的套用與放棄操作；需要連續處理多張貼紙時，介面會顯示剩餘數量與目前處理項目。

## 23.1 主畫面與遊玩紀錄

進入遊戲先顯示主畫面，提供「開始遊戲」與「重置紀錄」。開始遊戲建立新 Run，依已讀紀錄播放尚未看過的開頭及教學。既有結算畫面的重新開始同樣沿用已讀及解鎖紀錄。

「重置紀錄」左鍵只清除此遊戲的劇情已讀與臨時貼紙解鎖紀錄，回到首次遊玩狀態並留在主畫面；紀錄以目前瀏覽器的 localStorage 保存。右鍵攔截預設選單，直接預覽[完整結尾](tribelings.md#結尾)，不執行重置。預覽沿用打字、換句及 Skip，結束後回主畫面，不修改已讀、通關、獎勵或解鎖紀錄。

劇情互動、首次取得判定與觸發順序以[對話呈現與流程](tribelings.md#對話呈現與流程)為準。一般對話期間暫停玩家對底層介面的操作；寶箱旁白使用不攔截操作的獨立空間。

# 24. 數值設定來源

所有可調整的遊戲數值集中放在 `src/configs`，由對應設定檔作為唯一來源。服務與介面讀取設定值並呈現結果，使機率、槽位、價格、里程碑與數值曲線保持一致。

主力骰的相對傷害與占比門檻、膨脹幅度及延長節拍見[attackPresentationConfig.ts](../src/configs/attackPresentationConfig.ts)。其中 `carryScale.min`／`carryScale.max` 是蓄力放大倍數下限／上限，`minimumStrength` 控制進入主力演出的門檻，`bulgeScale` 控制魚眼強度；衝刺與命中承接蓄力倍數，不需另外同步修改尺寸。

骰面種類、標籤、能力與取值規則以[土人骰面設計](tribelings.md)為準。骰面能力參數的設定入口為[creatureBalanceConfig.ts](../src/configs/creatures/creatureBalanceConfig.ts)，名稱、標籤與能力文案的設定入口為[creatureConfig.ts](../src/configs/creatures/creatureConfig.ts)；貼紙基礎值、階段成長與價格的設定入口為[creatureStickerConfig.ts](../src/configs/creatures/creatureStickerConfig.ts)。開局配置見[initialDiceConfig.ts](../src/configs/creatures/initialDiceConfig.ts)，新骰配置見[diceProgressionConfig.ts](../src/configs/diceProgressionConfig.ts)，貼紙包內容見[stickerPacksConfig.ts](../src/configs/stickerPacksConfig.ts)。裝備清單與參數見 [equipmentConfig.ts](../src/configs/equipment/equipmentConfig.ts)。戰鬥演出時序、技能音效與戰鬥金幣見[battleConfig.ts](../src/configs/battleConfig.ts)。

本次規格要求至少集中管理以下參數：

- 一般戰鬥貼紙包 Jackpot：5%。
- 寶箱裝備權重：65%。
- 寶箱貼紙包權重：35%。
- 寶箱候選數量：3。
- 消耗品欄容量：3。
- 裝備槽容量、效果加值、轉換比例、操作成本、機率與成長參數，依[裝備規格](equipment.md)集中管理。
- 每場基礎 Control：3。
- 各貼紙包的張數、內容池與混合規則。
- 角色與食物骰面的基礎值、能力加值、倍率、護盾量與觸發門檻。
- 技能演出的脈衝強度與時長、名稱淡入與停留及上移淡出時長、技能節拍間隔、數字輪播時長、縮放峰值與音效強度，依第 20 節集中管理。

怪物、地圖、骰子里程碑與區域成長的對應設定檔見[設定檔與修改入口](monsters-and-regions.md#6-驗證與設定來源)。

# 26. 核心驗證問題

核心系統透過實際遊玩回答以下問題；敵人強度、戰鬥回合、Intent 理解與骰池擴張另依[數值校準與驗證](monsters-and-regions.md#6-驗證與設定來源)檢查。

1. 玩家能否在首次取得臨時貼紙後的戰前準備中理解貼紙會持續整場並於戰後消失？
2. 三格消耗品欄是否能形成保存、使用、取代與放棄之間的有效取捨？
3. 玩家是否願意在菁英或 Boss 前投入多張臨時貼紙？
4. 高基礎值輸出面與依靠角色配置、標籤及連鎖的功能面是否都具有實際選擇價值？
5. 基礎 3 點 Control 與裝備加成是否能支撐重骰、換位及保留資源的取捨？
6. 裝備、永久貼紙與臨時貼紙是否各自具有清楚角色？
7. 寶箱的裝備保證候選與其餘隨機候選是否形成足夠的獎勵變化？
8. 一般戰鬥的 5% 貼紙包 Jackpot 是否稀有且值得期待？
9. 寶箱裝備的移動、落槽與滿槽替換回饋是否讓玩家清楚理解目標槽位與最終結果？
10. 玩家能否理解裝備的生效條件，並在重骰或換位後辨認預覽中的效果變化？
11. 後期大量骰子是否仍能快速讀懂並在主要結算時間內完成攻擊？
12. 玩家能否從同步脈衝、技能名稱與數值變化，辨認每次技能的發動者、參與者與增減原因？
13. 連續技能中斷同一數字的輪播時，畫面是否順暢接續、保留各次變化提示，並在撞擊前落定至正式結果？
14. 「姐妹花強化 → 孩子王搶奪 → 毛賊追加攻擊 → 號角手全隊加傷」在正常速度下是否順序清楚、文字各自可讀，且聲光強度具有層次？

# 27. 核心總結

本作的核心是把少量初始骰子一路養成具有高數字、土人角色配合、跨骰連鎖與裝備協同的強力骰池。固定進度里程碑帶來更多骰子，永久貼紙帶來單面長期成長，臨時貼紙帶來單場補組合，裝備透過連鎖改寫、操骰方式與資源運用形成貫穿 Run 的構築。

每回合的主要體驗為：

> **戰前配置有限資源 → 擲出自己養成的骰池 → 使用 Control 修正關鍵結果 → 看數字與連鎖迅速放大 → 骰子連續撞向敵人。**
