# 1. 遊戲定位

玩家沿著地圖逐格前進，經歷一般戰鬥、寶箱、商店、菁英與 Boss。每回合一次擲出整個骰池，玩家使用有限的 Control 修正少數結果，透過土人之間的支援、重骰連鎖、搶奪、存糧與身分配合形成組合，再依技能與裝備效果完成結算。

骰子本身是 Build 主體。玩家透過固定進度取得更多骰子，使用永久貼紙持續改造骰面，並以裝備改變角色連鎖、操骰方式與資源價值。臨時貼紙則提供單場補組合，讓玩家能為困難戰鬥投入有限資源。

# 2. 核心體驗

每回合的主要決策是判斷目前結果是否值得消耗 Control。玩家能直接看懂每顆骰子的角色或食物、數字與已成立的關係，並從數字成長與連鎖結算中感受到 Build 的成果。每顆骰子的所有面都具有構築用途，玩家透過同骰配置、左右鄰骰、朝上組合與標籤建立角色之間的關係。

每個 Run 同時提供兩條清楚的成長軸。區域 Boss 後固定取得全白板骰，三區依序由三骰擴大至六骰，新骰提供六個可配置貼紙的位置；永久貼紙替換白板、增加有效角色面並提高組合專精。普通戰展示成長成果，菁英與 Boss 讓玩家依前段威脅選擇保留組合、重骰或承受攻擊。

# 3. 核心循環

一個完整節點循環如下：

1. 玩家前進至下一個地圖節點。
2. 節點觸發一般戰鬥、寶箱、商店、菁英或 Boss。
3. 戰鬥節點顯示敵人與骰池；從第一場開啟滿版戰前面板，按「進入戰鬥」滑出後消耗並鎖定配置，接著自動首次擲骰。
4. 玩家擲出所有骰子；骰子落定後，系統預覽角色與裝備效果，玩家查看結果並決定是否使用 Control，依能力處理重骰連鎖。
5. 玩家完成重骰連鎖並鎖定結果，系統套用裝備對骰面結果與關係規則的改寫，依[回合結算順序](tribeling-resolution.md#結算順序)完成傷害、護盾與攻擊清單。
6. 系統依技能結算順序播放相關骰子的同步脈衝、技能名稱與數字變化，追加攻擊隨來源技能呈現，吸收與拆分依事件順序演出；所有攻擊數字落定後，依攻擊清單撞向敵人。
7. 敵人存活時執行行動，接著開始下一回合；敵人被擊敗時進入獎勵流程。
8. 玩家處理永久貼紙、臨時貼紙、貼紙包或裝備，然後前往下一個節點。

# 4. 地圖與關卡進度

本次提供鱷魚人篇三區難度一：沼澤泥道、沈水荒地、鱷魚人地城。每條路線經過 20 個節點、12–14 場戰鬥。完整 Run 規劃由鱷魚人與地下篇接續，完成兩篇才解鎖下一難度。進入每區即顯示完整地圖，導覽列各節點以清楚的類型圖示呈現，圖示保留隨可讀字級調整的最小尺寸；hover 或鍵盤聚焦的小窗顯示節點名稱、獎勵、敵人與簡短機制名詞，以及完成或放棄狀態。敵人名稱與特點依階級上色，商店、營火與寶箱名稱使用各自的主題色，獎勵與狀態使用次要文字色；目前位置、可選路線、已完成與已放棄狀態沿用節點外框、底色及透明度呈現。第二、三區入口先選擇營火或原有戰鬥，於下一節點匯合。每區在共同節點後選擇穩定路普通戰或挑戰路菁英，完成後在商店匯合，未選路線保留為已放棄。玩家沿節點連線前進，擊敗各區 Boss 後先取得並展示白板新骰，按「繼續」後再選主題包，並在戰鬥與補給間調整構築。區域分工、骰池進度與終章路線見[怪物與關卡設計](monsters-and-regions.md#2-每區完整地圖與分岔)。

# 5. 骰子與骰面

每顆骰子固定為 d6，六面各有一個 1～6 點。點數屬於骰面，永久與臨時角色貼紙沿用目標點數。骰面包含角色或食物、固定點數與至多一種特殊材質；能力、身份標籤與稀有度由角色決定，基礎攻擊力由點數、有效材質及加工中明定的基礎修正決定，結算後攻擊力可超過 6。特殊材質依[材質規則](special-materials.md)提供獨立效果。

白板土人照點數攻擊，能力與身份標籤皆為空。開局三骰各有兩面角色或食物、四面白板；Boss 後取得的新骰各有六面白板；配方骰設定與接口保留，具體配置見[出發骰與道中配方](dice-drafts.md)。白板與身份標籤「普通」分開判定，耆老與偽裝者依有身份的土人或食物處理。

「同骰」涵蓋全部有效面，「同骰其他面」排除朝上面；「同骰相鄰面」依幾何共邊判定。「左右鄰骰」指並排位置直接相鄰的骰子，兩端各一顆鄰骰。能力依文案讀取朝上結果、同骰配置、鄰骰配置或回合事件，臨時貼紙附著時採覆蓋後角色及標籤。

戰鬥正常骰採 2D 骰體與平面擲骰動畫，追加攻擊採 3D 透光骰；靜態骰體桌面為 87 × 87 設計單位，手機為 58 × 58 設計單位，追傷骰按投影後尺寸計算。場地保留追傷骰上排，依實際追加數量緊密排列，寬度不足時延伸並提供橫向捲動；正常骰保持單列及左右順序，位置與數值區固定。Control 階段點骰重骰，攻擊位移依捲動後實際位置計算。骰面外觀依[骰面呈現](dice-presentation.md)，技能及追傷演出依[戰鬥結算與演出](#20-戰鬥結算與演出)。

點數、基礎攻擊力、當前攻擊與外部加成的取值依[土人結算規則](tribeling-resolution.md)。展開圖以劍圖示與數字呈現有效基礎攻擊力，戰鬥技能與裝備使攻擊數字成長。

# 6. 骰面成長與稀有度

永久貼紙以角色能力、同名面數、身份搭配及跨骰連鎖提供成長；各區均沿用固定 1～6 點。角色稀有度依構築影響、放大與堆疊能力設定，同角色跨區維持一般／稀有／傳說分級，與身份標籤「普通」分開顯示。完整分級見[土人骰面設計](tribelings.md#骰面稀有度)。

骰池進度、白板比例與配方見[出發骰與道中配方](dice-drafts.md)；一般戰一明一蓋兩張、菁英／Boss 三張主題包及商店三張包見[貼紙獎勵與經濟](rewards-and-economy.md)。

# 7. 永久貼紙

永久貼紙是可保存、取下與重新配置的長期構築物品。取得時可選擇「收進背包」或「直接貼」，收納時飛入底部背包按鈕。永久區最多保存 60 張，已貼在骰面上的另計；身分、容量、滿格交換、排序與動畫依[貼紙背包與自由配置](backpack.md)統一管理。

從背包或戰利品貼附時沿用目標面的固定點數，角色與材質隨永久貼紙移動，原永久貼紙自動回背包。開局自帶的土人與食物也可取下，取下後恢復原點數的普通材質白板。戰鬥外可直接拖曳骰面貼紙到另一面移動或交換，也可拖回背包；角色、材質與取得身分跟著貼紙移動，點數留在原骰面。臨時與永久層的交換規則依[貼紙背包](backpack.md)。

戰利品先選定一組並公開完整內容，再依玩家決定的順序逐張收納、貼附或放棄。商店永久單張、貼紙包與特殊來源共用同一流程，全部處理完成才繼續節點。候選明牌仍可預覽覆蓋後角色、能力、材質、同名面數及連鎖條件；取得後使用共用編輯器配置，待處理貼紙位於上方方形卡片，可拖到骰面或背包。領取後繼續留在編輯器，按「完成配置」才返回剩餘戰利品或繼續流程。來源與補償依[獎勵流程](rewards-and-economy.md#戰鬥獎勵)。

# 8. 臨時貼紙與背包

臨時貼紙提供單場角色、食物與方向控制零件。臨時區固定三格，每張為獨立物品，同種類可持有多張。角色及食物貼紙保留目標永久骰面的材質與基礎攻擊力，例如勇士 6 暫時變成姐妹花 6。

取得後可收進背包或直接配置到下一場；預先配置仍占三格額度，商店與戰前共用配置。商店有空格時扣款取得貼紙，再選擇用途；滿格時確認替換才扣款，取消保留原有資源。配置可調整或撤回，開戰時才消耗，戰後恢復永久面。

臨時內容集中於家族、姐妹花、雙胞胎、混混、孩子王、廚師、搬運工、跟班、勇士、毛賊、膽小土人、侍衛、工匠、農夫、好吃的、水果拼盤與搗蛋鬼，每張 12 金幣，稀有度沿用永久版本。商店另以 config 設定的 60% 機率提供一張自由轉向貼紙，每張 24 金幣，占一格臨時區，配置時選擇方向；詳細規則見[方向貼紙](directional-stickers.md)。

# 9. 首次擲骰與貼紙配置

[滿版戰前面板](battle-preparation.md)從第一場開放。完成獎勵與劇情、確定敵人後，面板從右側滑入導覽列下方，集中呈現敵人摘要、裝備、骰面及右側背包。底部背包入口在其他非戰鬥畫面開啟相同編輯器，所有操作共用永久庫存及下一場臨時配置。每面可貼一張永久貼紙及一張臨時覆蓋，右鍵取下優先處理臨時層。

按「進入戰鬥」驗證配置後鎖定操作，面板向左滑出，動畫完成才消耗已配置的臨時貼紙、鎖定方向並首次擲骰。戰鬥期間背包提供查看功能；戰鬥結束後恢復永久面及自由配置。角色、食物與箭頭的生效依各自規則處理。

# 10. 貼紙包

主題包包含三張永久貼紙，供菁英、Boss 與商店使用。八種包為家族包、雙子包、混混包、勇武包、職人包、廚房包、壞壞包與貴族包，各張均由該包指定池產生。菁英與 Boss 各從八種主題包等機率抽取三種不同主題供選一，商店包按主題提供擴充；開包時打散揭曉順序，完整查看後自行決定貼附順序。內容池、抽取權重與特殊角色來源見[貼紙包規則](rewards-and-economy.md#相關內容與貼紙包)。

# 11. 一般戰鬥獎勵

勝利後提供三組獎勵選一，每組是一張明牌與一張蓋牌，共兩張永久貼紙。兩張正方形貼紙向右上延伸，明牌位於最左下及最上層，蓋牌向右上移動並順時針旋轉。蓋牌以 60% 從明牌的相關池、40% 從合法全池抽取，各池內按稀有度權重抽取，相關池中的角色種類各占一份權重。所有明牌共用這個規則。選定後揭曉蓋牌，完整查看兩張內容後再安排貼附。每場一般戰提供 15 金幣。相關池、領取與放棄流程見[貼紙獎勵與經濟](rewards-and-economy.md)。

# 12. 寶箱獎勵

寶箱提供三件可取得裝備供選擇一件；三選一及滿槽裝備替換畫面皆提供「放棄裝備，獲得 10 金幣」。放棄時清除本次候選與待替換裝備，保留原有裝備、加入補償金，沿正常流程前進至下一節點。領取裝備依[裝備槽與效果呈現](equipment.md#1-裝備槽與效果呈現)完成入欄或替換及落槽演出，處理完畢後前進。裝備移動演出期間停用放棄操作；替換畫面開啟時，操作集中於替換面板。

# 13. 菁英與 Boss 獎勵

菁英與 Boss 提供三種不同主題包選一，每包三張永久貼紙。選擇前公開包名、張數及主題說明，玩家可查看目前骰池；選定後展示包內全部貼紙，再自行安排貼附順序。菁英提供 25 金幣，Boss 提供 35 金幣。每個 Boss 勝利先把一顆六面白板骰加入骰池，獨立展示新骰與六面配置；玩家按「繼續」後才顯示主題包候選。第三區 Boss 獎勵完成後結束鱷魚人篇。配方骰的抽選、建立、選擇預覽與刷新接口保留。第三區共同寶箱完成後固定提供一張小公主，貴族包來源與上限見[貼紙包規則](rewards-and-economy.md#相關內容與貼紙包)。

# 14. 裝備與裝備槽

裝備透過角色連鎖改寫、Control 操作、戰術效果與 Run 資源運用形成構築，與骰面配置共同決定玩家的作戰及成長方式。裝備的效果、槽位與取得流程統一記錄於[裝備與構築](equipment.md)。Control 護盾、重骰落差追傷、首次重骰記憶及靜候蓄力提供操作收益；主動追加吸收與最高攻擊拆分依[追加骰批次、吸收與拆分](tribeling-resolution.md#追加骰批次吸收與拆分)轉換攻擊，保留外部加成與新追加骰的連鎖。

# 15. 商店

商店提供三個明牌永久單張商品與兩個主題包商品，單張 20 金幣、三張包 40 金幣；另沿用臨時貼紙、裝備與回血服務，回血一次花 10 金幣恢復 25 HP。購買永久貼紙或包後完成收納、貼附或放棄處理，再返回商店；臨時貼紙與裝備滿欄時先選替換，取消保留原有資源。商品與交易細節見[商店規格](rewards-and-economy.md#商店)。

起始金幣 10。第一間商店前完整保留戰鬥收入時，普通路 55、菁英路 65；一包加一次回血共 50，剩餘 5／15。金幣亦供付費重骰、刷新與營火補給使用，後續收支需隨實際構築驗證。配方骰接口、戰利品與商店的逐次加價刷新見[刷新規則](dice-drafts.md#付費刷新)。

# 16. 基礎戰鬥流程

每場戰鬥最多 50 回合。準備階段顯示「回合 1／50」，正式擲骰後顯示當前回合；剩餘 10 回合（第 41 回合起）使用醒目警示。第 50 回合完成敵人行動後，敵人仍存活即判定戰鬥失敗；玩家在最後一回合擊敗敵人仍取得勝利。

每回合開始時，玩家一次擲出所有骰子。遊戲邏輯先決定每顆骰子的結果，演出系統再播放拋物線、旋轉、碰撞與落地微彈，並在約 0.6～1 秒內讓所有骰子穩定落地。骰子停止後會旋轉至清楚呈現預定結果的角度，系統接著顯示角色與裝備效果預覽並依角色能力處理重骰連鎖及 Control 操作。

首次擲骰前的準備階段，骰體保留骰型輪廓，朝上內容以問號呈現；不顯示角色、數字或骰面提示，也不接受 Hover、鍵盤聚焦與骰子操作。按下擲骰後才進入正式擲骰與結果顯示。

每回合選擇一個主要敵人，點擊敵人圖像顯示準心；結算前可自由切換。攻擊依普通、追加、再攻擊順序逐筆結算，目標死亡時後續攻擊轉向畫面順序第一個存活敵人，單筆溢傷不轉移。敵人依畫面順序行動，共用玩家護盾。玩家完成 Control 操作與重骰連鎖後鎖定結果。傷害預覽與正式結算共同使用有效骰面及裝備改寫後的關係規則，依[角色結算順序](tribeling-resolution.md#結算順序)計算各步驟結果，並在對應步驟計入裝備效果。鎖定後正式套用一次存糧等狀態變化，同時記錄每次技能的發動者、參與者、受影響數值及變化前後值。演出依這份技能事件順序播放脈衝、技能名稱與數字輪播，再依最終攻擊清單完成撞擊；數值計算使用各步驟的正式結果。敵人存活時保留剩餘生命與護盾，執行當前意圖及對應裝備效果後開始下一回合；玩家 Control 延續至下一回合，剩餘護盾依保留裝備結算。玩家生命歸零即失敗；全部敵人生命歸零才勝利，同時歸零判定失敗。

玩家護盾有效至本回合敵人行動結束，下回合開始時依裝備保留剩餘護盾，預設歸零。保留量屬既有護盾，巨盾土人只讀取當回合新獲得的護盾。敵人護盾依招式跨回合保留。

總傷害顯示已包含敵人修正的結果；暴露弱點時，數字旁顯示弱點倍率標記，hover 說明增傷。敵人使用同款醒目弱點圖示。鉤索在新回合首次擲骰落定後，於朝上的目標顯示鉤子；封鎖重骰使用鎖頭。乾糧袋於首回合以圖示與數字顯示本場初始分配總量，各骰初始分配量使用「乾糧袋圖示 + X」，hover 說明來源與分配對象。

# 17. Control 系統

每場戰鬥開始時，玩家取得基礎 3 點免費 Control，並計入裝備提供的起始加成。點擊骰子優先消耗 1 點 Control 重骰，額度在整場戰鬥中共用；額度用完後，同一操作改為支付金幣。第 n 次付費重骰的原價為 10 × n 金幣，每場戰鬥重置付費次數。黃金秤錘使價格乘 0.6 並向上取整。每次玩家付費操作只收一次費用，老師與後續重骰連鎖保留原本的免費效果。重新取得 Control 時優先使用免費額度，本場付費次數繼續保留。換位、保護與翻面沿用各自的 Control 成本。

戰鬥外與首次擲骰前，可在骰面視窗直接拖曳整骰，放開立即保存排列。首次擲骰後至戰鬥結束鎖定自由排列；戰鬥中的土人隊形旗依裝備規則消耗 Control 換位。Control 讓玩家修正骰面結果。每次操作及其重骰連鎖完成後，系統依目前結果、位置與已記錄事件，重新預覽支援關係、搶奪對象、存糧、追加攻擊、再攻擊、護盾及最終傷害；角色對重骰的反應依[回合結算順序](tribeling-resolution.md#結算順序)，裝備操作與效果見[Control、戰術與戰鬥資源](equipment.md#3-control戰術與戰鬥資源)。

所有重骰（Control、金幣、老師與搗蛋鬼連鎖）均排除當下朝上的面索引，從其餘面等機率抽取；六面骰每次抽其餘五面之一。不同面若有相同角色與數值，結果仍可能相同；連續重骰可以由 A 面到 B 面再回 A 面。回合初擲仍從全部骰面等機率抽取。

# 18. 角色能力與攻擊種類

角色能力以同骰配置、鄰骰關係、本輪角色與標籤數量、重骰事件及跨回合存糧改變骰池結果。角色與食物的完整能力、計數範圍、身分轉換及觸發條件由[土人骰面角色與效果](tribelings.md#土人骰面角色與效果)統一管理，各效果按[回合結算順序](tribeling-resolution.md#結算順序)處理。

正常攻擊由本輪有效骰面承載，依技能結算後的攻擊值執行。角色技能與裝備產生的每筆追加攻擊，以透光骰子承載指定傷害，在來源技能的演出節拍進入預留槽位並呈現數值變化，再依其適用加成完成撞擊。小公主命令的再攻擊，則由符合條件的貴族按最終攻擊值再次執行普通攻擊，其作用限於該筆攻擊。追加骰槽位依本輪完整事件清單的生成順序安排，包含吸收前與拆分後的批次，位置在演出前確定。被吸收的追加骰飛入目標後退場，新生成的追加骰依其批次揭露；其餘可見骰的位置保持穩定。偽裝者以最新判定的角色參與能力與計數，結算時呈現身分轉換。各類對象的計數、能力與加成範圍均由[土人骰面設計](tribelings.md)定義。

高點數骰面提供直接輸出，功能骰面透過支援、追加攻擊、防禦與操骰效果提高構築價值。永久貼紙改變單面的能力與身份及整顆骰子的關係配置，形成貼附與替換時的取捨。

# 19. 防禦與回血

防禦能力以角色配置、標籤與重骰事件提供護盾。土人侍衛依本輪普通或貴族土人提供護盾，膽小土人在被重骰時留下護盾，朝上的土人工匠依同骰相鄰 [職人] 面數提供護盾。巨盾土人讀取本回合全隊新增護盾產生追加攻擊，原護盾繼續用於防禦。能力與取值範圍依[土人骰面設計](tribelings.md)，使防禦配置同時支援生存與反擊構築。

玩家最大生命 60；商店花 10 金幣恢復 25 HP，營火提供免費恢復 25 HP、20 金幣回滿或單場祝福三選一，皆以最大生命為上限。玩家護盾預設只限當回合，裝備可保留部分剩餘量，每場開戰歸零。

# 20. 戰鬥結算與演出

結算演出以每次技能觸發為單位，依[角色結算順序](tribeling-resolution.md#結算順序)呈現「參與骰子同步脈衝 → 技能名稱淡入 → 數值立即變化」。玩家透過同一節拍中的聲光與數字，辨認發動者、受影響對象及各次技能的貢獻，看到本輪骰子如何互相支援、轉移數值並形成連鎖。

## 20.1 技能脈衝與名稱

技能觸發時，發動骰與本次能力實際涉及的其他朝上骰子，同步向上發出一次脈衝光。脈衝採與裝備發動相同亮度的金白色核心與外圍光暈，發動骰以較大的發光範圍突出，參與骰同步發亮，其餘骰子維持原樣。血瓶採同亮度的紅白色脈衝，浮字使用「♥ +效果數值」，生命顯示與其發動同步。文字與數字位於光效上層，保持清晰。同骰背面提供的支援由受益骰承載回饋，發光範圍對應實際參與的骰子。

技能名稱與本次增減合併為一行，在發動者及受影響骰子上方淡入，例如「互相提攜 +3」、「搶奪 -10」。提示清楚可見後立即啟動受影響數字的輪播。名稱在固定位置停留一小段時間，再向上飄移並淡出。各骰上方預留文字空間；同骰連續技能的名稱依先後略微錯開高度，保留前一名稱的可讀時間。

同階段且互相獨立的技能可同步播放；具有前後依賴的技能按結算順序保留可辨識的節拍間隔。前一名稱的停留與淡出可和後續技能重疊，使連鎖持續推進。

## 20.2 數字輪播與中斷接續

攻擊、追加攻擊、護盾與存糧的輪播中間值統一以整數呈現，由目前顯示值緩動至該技能的目標值。攻擊目標依正式傷害向上取整；生命與護盾沿用正式整數值，存糧的動畫起訖與落定值使用正式整數。輪播值維持在動畫起訖值之間，增加時的數字位數以目標值為上限，減少時則從原值逐步下降。玩家總護盾在獲盾輪播期間也以整數呈現，落定後顯示正式總量。

玩家獲盾、回血及跨回合保留護盾向上取整，敵人每段攻擊套完所有倍率後向下取整，再扣除護盾與生命；生命、護盾及實際損失統一為整數。攻擊的內部技能計算保留精度，存糧維持整數；每筆正常、追加與再攻擊在套用撞擊時倍率後，最終傷害無條件進位，預覽總傷害為逐筆取整後的總和。正常骰與追加骰的攻擊數字依結果值使用逐漸放緩且有上限的字級曲線，120 的停留字級大於 30，相同結果使用相同字級。數字增加時先輪播到目標，再短促膨脹，結果越大，停留字級與額外膨脹幅度越大，接著緩動縮回該結果的字級。數字降低時平順縮至新結果的字級。護盾與存糧維持原有輕微脈衝。多位數沿用完整數字，優先調整橫向字寬以保留數值大小所代表的字級層次。

不同骰子的數字動畫獨立完成，所有存續動畫完成後才進入撞擊。同一數字在輪播途中受到新技能影響時，立即中斷舊輪播，從當下顯示值接續至新技能的目標值；字級與膨脹由當下可見尺寸接續，最後停在新結果的字級。例如 `10 → 20` 顯示至 `16` 時，新技能使正式結果成為 `30`，畫面立即接續 `16 → 30`；技能計算仍以正式的 `20` 為前一步結果。

增減值直接接在技能名稱後面，攻擊倍率換算成本次顯示攻擊值的差額，例如「接力 +10」。差額由該技能正式前後值各自向上取整後相減，即使前一段輪播被中斷也保持該次增減的正確性。護盾與存糧以小圖示標示資源種類；身分轉換顯示新身分，公主命令顯示「再攻擊」。每筆技能回饋以完整單行文字顯示於骰子上方，保留原字級，提示框依內容自然撐寬。同顆骰子同時出現多筆時各自占用獨立位置。每筆提示依自身實際寬度定位，左側超出畫面時左緣貼齊畫面，右側超出時右緣貼齊畫面；提示比整個畫面更寬時優先貼齊左緣，內容維持原寬度向右延伸。垂直位置依提示框實際高度、間距及完整上飄範圍配置，提示存續期間保留位置，結束後才釋放空間；字級或尺寸變更時重新計算排列。文字提示位於共用浮動圖層，完整呈現於骰盤裁切區外，脈衝維持在對應骰體。

## 20.3 不同效果的回饋對象

攻擊加值與倍率作用於攻擊數字，獲盾作用於護盾數字，追加攻擊則由對應透光骰與預留槽位呈現。追加骰在來源技能的節拍進場，並隨後續適用效果更新數字。啦啦隊加油時依每名戰士實際取得的加成產生一顆追加骰，先呈現來源與受益戰士，再顯示各顆正式傷害。首次進場、待機漂浮與攻擊位移各由獨立容器承載，骰身從進場、撞擊、歸位到待機全程維持完整立體外觀。出生動畫只在該顆追加骰首次進場時播放一次，歸位後繼續原有漂浮。追加傷害只由骰身數字與上方技能提示呈現。

追加骰的透視與六面立體合成在內層完成，透光質感由半透明色面、靜態高光及內陰影呈現。魚眼作用於合成後的外層，骰身、出生與漂浮容器維持 `preserve-3d`。位移容器獨立承載蓄力、衝刺及歸位，保持完整立體顯示。

搶奪同時呈現雙方的數值變化：目標的攻擊下降或快速歸零，發動者的攻擊同步成長。搬運工整段隊列同步脈衝，各成員依前方搬運工已完成的攻擊值呈現加成。號角手讓受影響的正常骰同步跳數字，並依朝上號角手人數強化追加骰；小公主的命令在符合條件的貴族上呈現回應，並於攻擊階段執行已登記的再攻擊。

## 20.4 音效與演出節奏

每次技能節拍使用一個主要音效，參與骰子共用該次聲音回饋。數字輪播搭配輕微滾動音，落定時播放短促收尾音。所有技能脈衝維持與裝備一致的明亮程度；全隊強化與高價值追加攻擊透過發光範圍及聲音重音呈現強弱層次。

演出初始調校範圍如下，實際值依可讀性與整輪節奏驗證：

| 項目                       | 初始調校範圍                 |
| -------------------------- | ---------------------------- |
| 脈衝起始至技能名稱清楚可見 | 約 60～100 ms                |
| 單次數字輪播與放大縮回     | 約 460 ms               |
| 名稱淡入後的停留時間       | 約 400～600 ms，接著向上淡出 |

## 20.5 攻擊與收尾

所有技能事件播放完畢、攻擊數字穩定落定後，正常骰、透光追加骰及再攻擊依最終攻擊清單撞向敵人。攻擊歸零的正常骰留在原位呈現本輪狀態；已成立的追加攻擊依清單完成演出。目標在攻擊序列中途被擊敗時，後續攻擊轉向畫面順序第一個存活敵人；最後一名敵人死亡後，清單內的剩餘攻擊繼續撞向最後擊敗的敵人，保持相同的初始速度。右下總攻擊加總整份清單的傷害，包含擊殺後的剩餘攻擊與溢傷；生命與護盾的實際扣除各自以剩餘量為上限。

敵人頭上的命中浮字顯示本次攻擊傷害值，包含打盾與超過剩餘生命的部分；打出 120、敵人剩餘 20 HP 時顯示 120。浮字只呈現純數字，正常、追加、再攻擊與反射沿用相同大小曲線。傷害越大，字級越大，命中時由小尺寸快速向上彈出並膨脹，短暫回縮後緩慢上飄並逐筆淡出；傷害越大，彈出距離與膨脹越強。每筆浮字具有獨立生命週期，後續命中保留仍在播放的舊浮字，並依文字尺寸、膨脹與上飄範圍安排錯開的位置。位置於出生時固定，存活浮字沿自己的軌跡移動。浮字由共用浮動圖層呈現，依遊戲視窗邊界安排位置；場景切換時清除該場浮字。減少動態效果保留數值字級及獨立淡出，停用膨脹與上飄。字級曲線、膨脹幅度、存續時間及錯位間距由數字演出 config 管理。

每個撞擊階段等待畫面套用該階段並完成骰體的實際過渡動畫，才進入下一階段；衝刺完成時才扣血與播放命中回饋。最後一顆骰子歸位完成後才進入勝利或敵人回合，不以相同長度的計時器推定動畫已完成。只等待骰子的有限撞擊動作，不等待持續漂浮、光圈或技能提示。切換場景或重開 Run 時中止舊場景等待；減少動態效果或沒有屬性差異的階段，在畫面套用後即可完成。

敵人攻擊由角色圖片本體短促撞向骰盤盒子的上緣，依序明顯向上後撤蓄力、快速向下拉伸衝撞、碰撞壓縮後微幅彈開，再平順退回原位。初始時序為蓄力 140 ms、衝刺 45 ms、碰撞微彈 85 ms、返回 240 ms，由敵人攻擊演出 config 管理。位移取角色圖片底部至骰盤上緣的間距並加入撞入距離；每擊結算傷害、主怪／小兵身分與重擊共同決定蓄力幅度、拉伸、撞入及殘影強度。力度使用吸盾前、扣除剩餘生命上限前的該次攻擊傷害，連擊各段分別計算。衝刺帶出短暫角色殘影與尖銳速度線，碰撞後迅速淡出。瀏覽器等待圖片本體的當段動畫完成後才推進，衝刺完成時同步命中。命中瞬間播放撞擊音效，骰盤短促下沉與震動，完整遊戲畫面的內側四邊呈現受擊亮框，同步扣除吸收傷害的護盾與穿透護盾後的生命。亮框包含頂部與底部介面，隨 1920 × 1080 場地縮放；生命受損為紅色，完全由護盾吸收為藍色，連擊即時追加亮度並接續淡出。骰盤保留撞擊圓環與傷害數字。生命與護盾損失分開顯示；全額格擋呈現護盾受擊。敵人返回後切換下一個意圖，接續下一回合或戰敗結果。防禦、蓄力、休息與已被阻止的攻擊依意圖結果呈現。

臨時貼紙在整場戰鬥中保持附著狀態，骰面檢視、關係預覽與擲出結果皆呈現其有效角色或食物種類與基礎攻擊力。戰鬥結束時播放貼紙移除回饋並恢復原本骰面。

結算技能間隔 110 ms，數字輪播 240 ms；普通撞擊依序為蓄力 25 ms、衝刺 50 ms、命中 70 ms、歸位 35 ms，再間隔 15 ms。正常、追加與再攻擊在最終攻擊清單完成後，一次依各筆傷害相對其他攻擊的強度及整批傷害占比計算突出程度；以傷害加權的比較基準避免大量小額追傷造成錯誤強調。最高兩筆傷害相近且一起明顯領先其餘攻擊時，以其餘攻擊作為共同基準，讓雙主力或主力的再攻擊都能被辨識。全批傷害相近時不強制挑主力。

突出程度低於 0.25 時維持普通撞擊節奏；達門檻的主力骰在撞擊前放大至原尺寸 1.5～1.9 倍，中央魚眼同步膨脹。蓄力約 130～160 ms，以持續加速長大的動作呈現，膨到最大即衝刺，不額外停留。衝刺承接蓄力尺寸再拉伸，命中短縮後才平順縮回原尺寸及形狀；突出程度越高，膨脹與命中回饋越強，數字保持可讀。演出強度只影響視覺與節拍，不改變傷害或攻擊順序，敵人死亡後也不重新比較。正常、追加與再攻擊共用判斷及動作參數。減少動態效果設定停用魚眼與膨脹，以亮框辨識突出骰。整輪長度隨技能及攻擊數量自然增加；同階段獨立技能同步播放，名稱淡出可重疊，具有前後因果的技能保留固定辨識節拍。

## 20.6 動畫更新與效能

擲骰的位移、旋轉與縮放由單顆骰子的局部動畫控制，以 `transform` 更新；React 在骰面切換與落定時更新內容。骰盤槽位保持固定，配置與技能說明依其輸入變動重新計算。技能數字依瀏覽器動畫幀的實際經過時間推進，中斷後從目前顯示值接續；同幀的事件及數字變化一次送出，已穩定的數字、身分與提示保留原資料參考。畫面元件只訂閱使用的狀態，逐幀數字更新集中於對應骰子及生命／護盾欄。

主力魚眼沿用既有強度與時間曲線，濾鏡只在強度變動期間更新。進入主選單時預先解碼角色分層圖片與位移貼圖，玩家按下開始遊戲時建立並恢復音效環境。撞擊共用預先生成的噪音資料，各次播放建立獨立聲源，聲音結束時釋放音訊節點連線。擲骰與魚眼完成後停止動畫幀排程，切換場景時清理局部動畫。技術分工及驗證方式見[戰鬥演出效能](battle-performance.md)。

# 21. 敵人回合

每筆玩家攻擊先套用怪物減傷、連擊破防及反擊條件；玩家仍存活時繼續後續攻擊。玩家攻擊完成後，存活敵人依公開 Intent 逐段執行行動，再開始新一輪擲骰。Intent 文案、條件、結算順序與各怪物招式見[Intent 共通規則](monsters-and-regions.md#1-敵人與回合規則)。玩家生命歸零時結束 Run；玩家存活且敵人生命歸零時進入勝利流程。

# 22. Build 方向

構築以產生、轉換、放大與複製串接。固定點數提供配置條件，土人貼紙增加有效角色面、啟動配合並提高穩定性；額外攻擊與再攻擊把小點數轉成可觀的總傷害。

家族利用同骰每面 +2 攻擊力與外部加成複製成長；雙胞胎以最高同名骰值和成對面數產生本體再攻擊。混混、啦啦隊及祭司產生追加骰，號角手把追加骰數量轉成全隊加攻，裝備再分裂、複製或增加追加傷害。

勇士依鄰骰跟班配置與朝上跟班放大攻擊，跟班取得勇士的部分攻擊；搬運工由左至右傳遞已完成的攻擊。姐妹花分享外部加成，耆老支援同名配置，權威、騎士、禁衛軍與小公主形成身份及本體再攻擊配合。

孩子王與惡霸集中攻擊並製造搶奪事件，毛賊依事件追加攻擊，警探各自取得共同沒收池的加成。老師與搗蛋鬼把重骰連結到攻擊、傳承與祭司犧牲；膽小土人提供重骰護盾。每次重骰實際新增膽小土人護盾時，右下護盾預覽同步顯示本次新增整數量的「+XX」浮字，向上移動後淡出；連鎖重骰依每一步的新增量各自呈現。浮字沿用重骰事件，正式結算維持既有護盾計算。

食物與農夫提供攻擊和存糧，廚師依面數把存糧拆成整數追加骰，大胃王讀取朝上食物所在骰的食物配置。侍衛、工匠及裝備產生護盾，巨盾依新增護盾量與獲盾事件轉為追加傷害。完整能力見[土人骰面](tribelings.md)，裝備的低傷分裂、本體連擊與同名數字連線見[裝備與構築](equipment.md)。

# 23. 介面與資訊規則

桌面與手機的觸控差異、1920 × 1080 固定場地與置中縮放、文字下限及浮動圖層座標依[畫面縮放與布局](viewport-layout.md)統一管理。場景素材、背景底色、置中構圖、底部基準線及怪物遮擋順序依[場景背景](backgrounds.md)管理，玩家命中時的前景變形、地面震動與石頭落地依[前景動態系統](foreground-motion.md)管理。

戰鬥資訊集中在骰盤周圍，臨時與永久貼紙集中於共用背包顯示。地區進度、金幣與音量位於頂部；玩家生命、護盾、Control、骰池入口及擲骰或結算操作整合於底部。

[滿版戰前面板](battle-preparation.md)顯示目標骰子、目標骰面、覆蓋前內容與覆蓋後內容。骰面檢視與永久貼紙改造共用單一全圖版面，以清楚字級呈現每面的角色或食物、基礎攻擊力、標籤、能力與覆蓋資訊，內容依[土人骰面設計](tribelings.md)。展開圖與戰鬥共用面索引及骰型幾何，一般檢視在 hover 或鍵盤聚焦骰面時高亮所有實際共用邊的相鄰面。方向貼紙預覽集中標示來源面、目的面與翻面連線，細節依[方向貼紙](directional-stickers.md)。

d6 展開圖在桌面與手機皆採用四欄三排的橫向十字，箭頭圖案及文字保持固定方向，空間以縮放與捲動適應；其他骰型沿用各自的展開排列。格內集中呈現角色、數值、能力、材質、標籤與覆蓋資訊，面索引保留於操作提示與無障礙名稱。狀態提示浮於展開圖視窗左上角，以半透明背景呈現並讓點擊穿透。展開圖依容器寬高配置尺寸，每面文字使用該面多邊形的安全區寬高自然換行，字級維持可讀下限；內容超出時顯示摘要與省略號，切換原面與覆蓋預覽時保持骰面位置穩定。桌面 hover 或鍵盤聚焦開啟半透明完整說明小窗，手機省略面內摘要，點獨立資訊入口開啟完整說明、點窗外或關閉鈕收起；技能基本效果與各門檻、材質及覆蓋資訊分段呈現，骰面說明與小窗皆使用完整排版。一般高度的完整彈窗以全圖可見、無捲軸為目標，戰前配置與極小視窗在到達可讀下限後使用區域捲動。

共用說明小窗在來源移出、失焦、隱藏、移除或所屬介面停用時收起；新的覆蓋面板開啟時清除背景小窗。關閉面板後需重新懸停或聚焦才顯示，當前面板內的說明仍可正常開啟。

敵人以透明角色圖片呈現，名字位於頭頂血條左上，護盾與階級標記整合於頭頂資訊；右側黑色切角意圖框以左側閃電尖角指向角色，常駐顯示技能圖示、名稱及傷害與段數。桌面滑入或鍵盤聚焦時顯示技能細節、破解條件、狀態及本輪預估，手機點擊開啟說明窗、點外側關閉。圖片受擊時先向上震退，再以上下交替衰減的短促震動為主，命中瞬間僅保留輕微壓縮及閃亮，左右位移與轉角保持小幅度，連擊從當下姿勢即時接續；血條與意圖框保持穩定。外觀與演出設定見[怪物與關卡設計](monsters-and-regions.md#敵人外觀與戰鬥介面)。

戰鬥畫面由上至下排列地區進度、敵人、骰盤與 Footbar。主區使用頂部與底列之間的剩餘高度，捲動由各內容區承接。骰盤的 board-body 寬度隨外框伸縮，高度由緊湊的固定骰列、數值區、橫向捲軸及裝備欄共同決定；整個遊戲依共用倍率縮放，場地固定為 1920 × 1080，頂部地圖與底部操作列包含在完整構圖內；外圍空間由目前場景的滿版背景填補。board-body 左側固定裝備欄，右側為骰盤及角色資訊。裝備欄在戰前、戰鬥、寶箱與商店共用同一組槽位，槽位尺寸保持固定，高度不足時在欄內上下捲動，技能發光、提示及飛入落槽沿用同一個目標。

每場首次擲骰前，獨立戰前面板顯示共用骰面與背包編輯器，臨時配置由共用庫存保存，提交由面板管理。面板滑出後恢復原有戰鬥畫面並首次擲骰。寶箱、商店及營火內容在裝備欄右側顯示並使用區域內捲動，補血選項旁呈現目前生命與最大生命。商店與營火的回血按鈕在滿血時保持正常亮度並顯示「生命已滿」，點擊保留金幣與當前選擇。

Footbar 的左側操作、老師免費重骰與右側結算維持同一行，老師按鈕過多時在自身區域水平捲動。擲骰與結算按鈕共用清楚的高對比主要操作樣式，並以一致樣式表達懸停、鍵盤聚焦與停用狀態。滑鼠移入或鍵盤聚焦骰子時，骰盤右側資訊區顯示 87 × 87 設計單位的靜態角色頭像，右側分兩行呈現名稱與標籤、劍圖示與當下骰面攻擊力；分隔線下方呈現完整能力與材質資訊。追加骰沿用相同頭像與攻擊力布局，保留來源與追傷說明。角色圖片及頭像設定見[骰面呈現](dice-presentation.md#角色圖層與資訊頭像)。資訊區預留穩定高度並支援完整文字換行。每骰下方固定預留攻擊、護盾、存糧與乾糧分配四行，各行依文字下限維持一致行高與位置；長數值在行內捲動並完整呈現，各行內容改變時沿用原有骰子座標。存糧前後值相同時顯示單一數值，有變化時顯示「原值→新值」。Control 階段的 Hover 骰子上方顯示本輪已發動技能的完整單行名稱，依視窗邊緣調整位置。資訊查看與骰子操作可用性分別處理。戰場專用說明將基礎攻擊力、計數、存糧及技能結果帶入當前數字，保留觸發條件；其他畫面沿用角色原始敘述。角色名稱使用完整設定名稱，以共用關鍵字配色呈現。朝上的土人工匠顯示相鄰 [職人] 面數與本次護盾量；混混顯示相鄰土人混混面數、追加次數及每次傷害。

技能說明由 creatureSkillConfig 管理玩家文案，內部結算依土人結算規則。戰鬥中階段性效果各占一行，符合當下條件的階段加勾，未達成階段稍微淡化；互斥區間只標示當前區間。

技能說明共用關鍵字呈現：所有完整土人名稱沿用角色設定色，「搶奪」使用橘紅色，「護盾」使用淺藍色。顏色與 Hover 演出參數集中於 `src/configs/skillPresentationConfig.ts`，骰面、裝備、獎勵、貼紙、商店與提示共用文字元件。

Control 階段的 Hover 關係、技能名稱與結算演出共用本輪技能判定結果。達成條件的技能顯示名稱與參與者金框；所有技能皆未發動時，骰子保留普通 Hover 亮光。朝上角色技能與本輪留下的效果各自判定。土人廚師依本輪入庫後的可用存糧判定「加菜」；土人混混與土人工匠各自在符合條件的同骰相鄰面數大於零時發動；土人大胃王於場上有食物時依食物骰配置發動；土人號角手依本回合追加骰生成紀錄判定發動。

骰子落定後，已成立關係以約 30% 亮度播放一次建立動畫，再保留靜態連線與參與骰微光。常駐呈現包含支援雙方、同骰能力、搬運工隊列及搶奪箭頭，重複關係合併為一層。常駐線與 Hover 共用路徑及骰子座標；Hover 沿用既有演出，覆在暗線上形成描摹感。重骰落定時，新骰面與本次成立或改變關係的參與者同步向上脈衝一次，失效關係淡出。進入結算時收起常駐提示，結算沿用既有技能節拍、連鎖動畫與數值變化。

右側技能說明保留條件，帶入判定當下的數量、門檻、取值及實際結果；未達條件時明示當前數量與零收益。土人大胃王顯示各份食物所屬骰的食物基礎攻擊總和與該技能前後攻擊值，土人號角手顯示各批追加骰生成數與累計全隊加值。所有角色引用使用完整名稱。預覽骰體與標籤維持擲出時身分，身分轉換於結算播放對應事件時呈現；傷害與連鎖預估依完整結算結果計算。

支援參與者使用同色金框；相鄰接力及身分轉換使用相鄰連線；搶奪與再攻擊命令使用弧線箭頭。搶奪箭頭由來源指向既定目標，目標顯示本次攻擊減少的整數差值。搬運工隊列可從任一參與者檢視完整連接。Hover 擲出的好吃的時，顯示自身存糧、直接強化該食物的農夫，以及使用食物計數的大胃王關係；全隊加成的關係由其發動者提供檢視。Hover 土人農夫時，轉化與自身存糧只亮自己，強化實體食物則亮自己與該食物。同骰能力以自身高亮呈現；跟班的關係記錄包含提供最高當前攻擊力的朝上鄰骰勇士。各技能依其實際效果選擇高亮形式，說明保持簡潔。

連線以較粗亮色核心與外發光呈現，位於骰體後方；光框及名稱位於骰體前方。連鎖框依骰體外緣向外偏移，圓角隨骰體實際尺寸、描邊、外擴距離及框線寬度換算。支援連線由提供者流向受益者，土人搬運工由左向右接力至隊尾；身分轉換與命令由發動者指向目標。搶奪箭頭由搶奪者指向被搶目標，吸取流光反向回到搶奪者。Hover 光框淡入淡出、連線延伸、弧線與減值提示均使用緩動補間；快速切換時接續最新目標並清除舊動畫，移出時平順退場。進入重骰與結算階段時收起 Hover 關係演出，結算技能依原本節拍播放。系統減少動態效果設定以淡入淡出取代位移與流光。

永久貼紙改造平時顯示原面，hover 或鍵盤聚焦時呈現覆蓋後的種類、數值、標籤與能力。候選明牌的六面圖供玩家預覽配置，點擊骰面保留該面的預覽，按「選擇」領取；已取得貼紙可收進背包，或拖曳、點擊骰面時套用，離開預覽目標恢復原面顯示。相同土人依覆蓋前的有效角色種類比對，數值及材質不同仍視為相同；比對結果在覆蓋預覽期間保持穩定，並與覆蓋預覽及相鄰面提示分別呈現。連鎖達成提示沿用共用技能預覽計算，依覆蓋後配置顯示成立條件。目標可用性依背包容量與方向配置驗證，原永久貼紙回到背包。文字採正向閱讀並在骰面安全區域換行，原內容與預覽共用預留空間。全圖版面依視窗調整尺寸，較小視窗以捲動保持字級與資訊可讀性。

獎勵、開包、商店與選骰畫面的主要及次要操作共用清楚的按鈕樣式，文字、底色與邊框維持可辨識對比，並呈現懸停、鍵盤聚焦及停用狀態。商店購買按鈕依實際可購買狀態切換外觀，金幣不足時保留可讀價格；放棄獎勵按鈕在候選及揭曉畫面沿用一致外觀。

Control 階段以點擊骰子執行重骰，控制列顯示 Control、傷害預覽與結算按鈕，並為每位仍有資格的老師提供免費重骰入口。玩家主動啟動老師，唯一合法目標直接重骰；有多個合法目標時高亮候選骰並由玩家選擇。選取期間可取消，取消不消耗老師資格；選取完成或取消前不可結算。沒有合法目標時入口停用，Control 歸零仍可使用老師。每次重骰連鎖落定後重新判斷其他老師的資格與最低值目標。裝備槽提供換位、保護、翻面與追加吸收的發動按鈕，最高攻擊拆分提供每回合預設關閉的切換按鈕，顯示費用及使用狀態；選取期間可取消，合法目標使用既有亮框。免費與付費重骰共用點骰操作，控制列顯示當前金幣價格，金幣不足時停用付費重骰。尚未勾選「不再顯示」時，每次付費重骰前皆顯示「免費 Control 已用完」、「此次重骰將花費 X 金幣」、勾選框「不再顯示」，以及「取消」與「X（金幣圖示）重骰」按鈕；確認直接重骰原先選定的骰子。取消保留金幣與付費次數，下次嘗試仍提示。勾選並完成確認後永久略過提示，跨戰鬥、開新局及重新整理保留；主選單的「重置紀錄」恢復提示。戰鬥預覽呈現角色連動、有效標籤、搶奪對象、追加攻擊、再攻擊、存糧、護盾及總傷害。永久與臨時貼紙提供收納、直接貼及放棄操作，貼紙包逐張處理，裝備替換提供套用與放棄操作；需要連續處理多張貼紙時，介面會顯示剩餘數量與目前處理項目。

## 23.1 主畫面與遊玩紀錄

進入遊戲先顯示主畫面，提供「開始遊戲」與「重置紀錄」。開始遊戲建立新 Run，依已讀紀錄播放尚未看過的開頭及教學。勝利與失敗結算只提供「回到主選單」；回到選單保留已讀及解鎖紀錄，玩家按「開始遊戲」才建立新 Run。

「重置紀錄」左鍵只清除此遊戲的劇情已讀紀錄，回到首次遊玩狀態並留在主畫面；紀錄以目前瀏覽器的 localStorage 保存。右鍵攔截預設選單，直接預覽[完整結尾](tribelings.md#結尾)，不執行重置。預覽沿用打字、換句及 Skip，結束後回主畫面，不修改已讀、通關、獎勵或解鎖紀錄。

劇情互動、首次取得判定與觸發順序以[對話呈現與流程](tribelings.md#對話呈現與流程)為準。一般對話期間暫停玩家對底層介面的操作；寶箱旁白使用不攔截操作的獨立空間。

# 24. 數值設定來源

新版技能內部順序與狀態見[土人結算規則](tribeling-resolution.md)。

所有可調整的遊戲數值集中放在 `src/configs`，由對應設定檔作為唯一來源。服務與介面讀取設定值並呈現結果，使機率、槽位、價格、里程碑與數值曲線保持一致。

主力骰的相對傷害與占比門檻、膨脹幅度及延長節拍見[attackPresentationConfig.ts](../src/configs/attackPresentationConfig.ts)。其中 `carryScale.min`／`carryScale.max` 是蓄力放大倍數下限／上限，`minimumStrength` 控制進入主力演出的門檻，`bulgeScale` 控制魚眼強度；衝刺與命中承接蓄力倍數，不需另外同步修改尺寸。

骰面種類、標籤、能力與取值規則以[土人骰面設計](tribelings.md)為準。骰面能力參數的設定入口為[creatureBalanceConfig.ts](../src/configs/creatures/creatureBalanceConfig.ts)，名稱、標籤的設定入口為[creatureConfig.ts](../src/configs/creatures/creatureConfig.ts)，玩家能力文案及階段說明見[creatureSkillConfig.ts](../src/configs/creatures/creatureSkillConfig.ts)；角色貼紙資料與價格的設定入口為[creatureStickerConfig.ts](../src/configs/creatures/creatureStickerConfig.ts)。開局配置見[initialDiceConfig.ts](../src/configs/creatures/initialDiceConfig.ts)，新骰配置見[diceRecipeConfig.ts](../src/configs/creatures/diceRecipeConfig.ts)，貼紙包內容見[stickerPacksConfig.ts](../src/configs/stickerPacksConfig.ts)。重骰價格與提示文字見 [controlConfig.ts](../src/configs/controlConfig.ts)。裝備清單與參數見 [equipmentConfig.ts](../src/configs/equipment/equipmentConfig.ts)。戰鬥演出時序、技能音效與戰鬥金幣見[battleConfig.ts](../src/configs/battleConfig.ts)。

本次規格要求至少集中管理以下參數：

- 一般戰三組選一、每組明牌一張與蓋牌一張；菁英及 Boss 三個主題包選一、每包三張永久貼紙。
- 起始金幣 10，一般／菁英／Boss 金幣 15／25／35；單張 20、三張包 40、回血 10，完整供給見獎勵與經濟文件。
- 付費刷新基礎價格：配方骰 8、戰利品 6、商店 8 金幣；依本次畫面刷新次數線性遞增。
- 寶箱候選數量：3。
- 臨時貼紙容量 3，永久貼紙背包容量 60；已貼永久面另計。
- 裝備槽容量、效果加值、轉換比例、操作成本、機率與成長參數，依[裝備規格](equipment.md)集中管理。
- 每場基礎免費 Control：3；付費重骰每次增加 10 金幣，開戰重置；黃金秤錘六折。
- 各貼紙包的張數、內容池、配套保證與抽取權重。
- 固定骰面點數、角色與食物能力加值、倍率、護盾量與觸發門檻。
- 技能演出的脈衝強度與時長、名稱淡入與停留及上移淡出時長、技能節拍間隔、數字輪播時長、縮放峰值與音效強度，依第 20 節集中管理。

怪物、地圖、Boss 後取得白板骰與區域成長的對應設定檔見[設定檔與修改入口](monsters-and-regions.md#4-設定入口)。

# 26. 核心驗證問題

核心系統透過實際遊玩回答以下問題；敵人強度、戰鬥回合、Intent 理解與骰池擴張另依[數值校準與驗證](monsters-and-regions.md#5-新版驗證)檢查。

1. 玩家能否在首次取得臨時貼紙後的戰前準備中理解貼紙會持續整場並於戰後消失？
2. 三格臨時區與永久背包是否能支援保存、配置、取下與放棄的構築選擇？
3. 玩家是否願意在菁英或 Boss 前投入多張臨時貼紙？
4. 固定高低點數上的角色配置、身份及連鎖是否都具有實際選擇價值？
5. 基礎 3 點 Control 與裝備加成是否能支撐重骰、換位及保留資源的取捨？
6. 裝備、永久貼紙與臨時貼紙是否各自具有清楚角色？
7. 寶箱的三件裝備能否形成值得取捨的構築方向？
8. 一般戰明牌與蓋牌組合是否提供啟動收益，菁英／Boss 貼紙包與商店購買是否仍值得期待？
9. 寶箱裝備的移動、落槽與滿槽替換回饋是否讓玩家清楚理解目標槽位與最終結果？
10. 玩家能否理解裝備的生效條件，並在重骰或換位後辨認預覽中的效果變化？
11. 後期大量骰子是否仍能快速讀懂並在主要結算時間內完成攻擊？
12. 玩家能否從同步脈衝、技能名稱與數值變化，辨認每次技能的發動者、參與者與增減原因？
13. 連續技能中斷同一數字的輪播時，畫面是否順暢接續、保留各次變化提示，並在撞擊前落定至正式結果？
14. 「姐妹花強化 → 孩子王搶奪 → 毛賊追加攻擊 → 號角手全隊加傷」在正常速度下是否順序清楚、文字各自可讀，且聲光強度具有層次？

# 27. 核心總結

本作的核心是把少量角色與大量白板的固定 1～6 點骰子，養成具有土人配合、跨骰連鎖與裝備協同的強力骰池。固定進度里程碑帶來更多骰子，永久貼紙帶來單面長期成長，臨時貼紙帶來單場補組合，裝備透過連鎖改寫、操骰方式與資源運用形成貫穿 Run 的構築。

每回合的主要體驗為：

> **戰前配置有限資源 → 擲出自己養成的骰池 → 使用 Control 修正關鍵結果 → 看數字與連鎖迅速放大 → 骰子連續撞向敵人。**
