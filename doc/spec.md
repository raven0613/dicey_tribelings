# Dice Sticker Roguelite — Current Spec

> 版本：2026-09-06
>
> 定位：單人骰子構築 Roguelite
>
> 核心：養骰子、改骰面、追組合、有限 Control、快速結算

本文件為遊戲規格入口。[土人骰面設計](tribelings.md) 統一管理世界觀、角色與食物骰面、標籤、能力及回合結算順序；[裝備與構築](equipment.md) 管理裝備效果、槽位、取得流程與效果呈現；[怪物與關卡設計](monsters-and-regions.md) 管理區域路線、怪物、Intent、骰子里程碑與戰鬥成長目標，並提供對應 config 的修改入口。本文件管理骰子與貼紙的共通流程、戰鬥演出及介面資訊。

# 1. 遊戲定位

玩家沿著地圖逐格前進，經歷一般戰鬥、寶箱、商店、菁英與 Boss。每回合一次擲出整個骰池，玩家使用有限的 Control 修正少數結果，透過土人之間的支援、重骰連鎖、搶奪、儲糧與身分配合形成組合，再依技能與裝備效果完成結算。

骰子本身是 Build 主體。玩家透過固定進度取得更多骰子，使用永久貼紙持續改造骰面，並以裝備改變角色連鎖、操骰方式與資源價值。一次性貼紙則提供戰前準備與單場爆發，讓玩家能為困難戰鬥投入有限資源。

# 2. 核心體驗

每回合的主要決策是判斷目前結果是否值得消耗 Control。玩家能直接看懂每顆骰子的角色或食物、數字與已成立的關係，並從數字成長與連鎖結算中感受到 Build 的成果。每顆骰子的所有面都具有構築用途，玩家透過同骰配置、左右鄰骰、朝上組合與標籤建立角色之間的關係。

每個 Run 同時提供兩條清楚的成長軸。固定里程碑擴大骰池規模，高數值永久貼紙提高單顆骰子的輸出上限。兩條成長軸共同支撐「骰子越來越多，每顆骰子也越養越強」的體驗。

# 3. 核心循環

一個完整節點循環如下：

1. 玩家前進至下一個地圖節點。
2. 節點觸發一般戰鬥、寶箱、商店、菁英或 Boss。
3. 戰鬥節點先進入戰前準備，玩家配置一次性貼紙並確認開戰。
4. 玩家擲出所有骰子；骰子落定後，系統預覽角色與裝備效果，玩家查看結果並決定是否使用 Control，依能力處理重骰連鎖。
5. 玩家完成重骰連鎖並鎖定結果，系統套用裝備對骰面結果與關係規則的改寫，依[回合結算順序](tribelings.md#回合結算順序)完成傷害、護盾與攻擊清單。
6. 系統依技能結算順序播放相關骰子的同步脈衝、技能名稱與數字變化，追加攻擊隨來源技能呈現；所有攻擊數字落定後，依攻擊清單撞向敵人。
7. 敵人存活時執行行動，接著開始下一回合；敵人被擊敗時進入獎勵流程。
8. 玩家處理永久貼紙、一次性貼紙、貼紙包或裝備，然後前往下一個節點。

# 4. 地圖與關卡進度

正式版以六區完成一個 Run，Demo 涵蓋前三區。玩家逐節點前進，透過固定里程碑取得新骰，並在戰鬥與補給間調整構築。區域分工、骰池進度與終章路線見[怪物與關卡設計](monsters-and-regions.md#2-六區進度與骰子里程碑)。

# 5. 骰子與骰面

骰子可以採用 d4、d6、d8、d10、d12 等面數，也可以具有不同的初始數值分布、角色與食物配置及外觀主題。開局骰數與新增進度由[骰子里程碑](monsters-and-regions.md#2-六區進度與骰子里程碑)統一管理。

骰子的面數代表可擲出的骰面數量，骰面攻擊值採用獨立數值，因此任何骰面都能成長至高於骰子面數。每個骰面由角色或食物種類與基礎攻擊值組成，例如土人家族4、土人勇士7與好吃的10；種類決定標籤與能力，數字提供基礎傷害與效果取值。角色使用普通、戰士、職人、貴族與神秘等標籤，食物使用食物標籤，實際組合由[土人骰面角色與效果](tribelings.md#土人骰面角色與效果)統一管理。

骰子的所有有效面共同參與構築。「同骰」涵蓋該骰子的所有有效面，「同骰其他面」排除目前擲出的面；「左右鄰骰」指並排位置中直接位於左側或右側的骰子，兩端各有一顆鄰骰。各能力依[土人骰面設計](tribelings.md)指定的範圍，讀取朝上結果、同骰配置、鄰骰所有面或當回合事件。一次性貼紙附著期間，以覆蓋後的種類、標籤與基礎值參與判定。

戰鬥場上的正常骰子採用 2D 骰體與平面擲骰動畫，以骰型輪廓、角色或食物圖示及攻擊值呈現朝上結果，Control 階段直接點擊骰體重骰；追加攻擊維持同尺寸基準的 3D 透光骰。戰鬥區採固定高度分區，骰盤從準備階段持續預留追傷槽位，並依視窗寬高同步調整兩類骰子的尺寸，追傷進出沿用固定定位。骰面檢視依[介面與資訊規則](#23-介面與資訊規則)，技能回饋、追傷進場與撞擊依[戰鬥結算與演出](#20-戰鬥結算與演出)呈現。

# 6. 骰面數值成長

永久貼紙隨區域進度提供更高品質的骰面，一次性貼紙提供單場強化，裝備與角色能力放大構築成果。新骰與各來源獎勵的成長關係、校準目標及設定入口見[骰池與獎勵成長](monsters-and-regions.md#3-骰池與獎勵成長)。

# 7. 永久貼紙

永久貼紙是長期骰面構築的主要來源。玩家取得永久貼紙後立即選擇一顆骰子與一個骰面，貼紙會永久覆蓋該面的角色或食物種類與基礎攻擊值；玩家也可以放棄本次貼紙，放棄的貼紙立即銷毀。

永久貼紙採即時處理制，最終結果只有貼上或銷毀兩種。一般戰鬥獎勵、貼紙包與其他獎勵來源都使用相同流程，永久貼紙處理完成後才繼續後續獎勵或節點流程。

例如將「土人家族3」覆蓋為「土人家族8」，可以提高該面的基礎輸出；將同骰的一個家族面改為土人工匠，則會改變家族面數，並加入依鄰骰朝上土人提供護盾的能力。貼附同時影響單面品質與整骰配置，玩家依構築方向選擇替換位置。

# 8. 一次性貼紙與消耗品欄

一次性貼紙是單場戰鬥消耗品，取得後存入獨立消耗品欄。消耗品欄固定為 3 格，並與裝備槽分開管理；每張貼紙是獨立物件，相同種類可以同時持有多張。

取得新一次性貼紙時，玩家可以將貼紙收進空槽，也可以放棄新貼紙。三格皆滿時，玩家可以選擇一張既有貼紙進行取代，也可以放棄新貼紙；每張新貼紙各自完成一次選擇，被取代或被放棄的貼紙立即銷毀。貼紙包一次開出多張一次性貼紙時，系統依序處理每一張。

商店購買一次性貼紙時，金幣會在玩家確認收納或取代後扣除。玩家取消購買時保留原有金幣與消耗品欄內容。

# 9. 戰前準備與一次性貼紙配置

每個戰鬥節點先進入戰前準備階段。玩家可以查看敵人、目前骰池與消耗品欄，並自由選擇零張至目前持有數量的一次性貼紙；消耗品欄最多持有三張，因此單場最多配置三張。

每張一次性貼紙覆蓋一個指定骰面，每個骰面同時承載一張一次性貼紙。玩家可以在確認開戰前調整或撤回配置；確認開戰後，已配置貼紙從消耗品欄移除並附著於指定骰面，整場戰鬥的配置隨即鎖定，接著開始第一次擲骰。

一次性貼紙在整場戰鬥的每個回合持續生效。擲出結果、同骰配置與鄰骰支援都使用貼紙上的角色或食物種類與基礎攻擊值，並依其標籤與能力判定關係。戰鬥結束後，所有一次性貼紙從骰面移除並銷毀，被覆蓋的永久骰面完整恢復；留在消耗品欄中的貼紙則保留至後續節點。

# 10. 貼紙包

貼紙包是高價值即時獎勵，內容可同時包含永久貼紙與一次性貼紙。每種貼紙包的張數、內容池、稀有度與混合規則由貼紙包設定檔管理。

玩家選擇貼紙包後立即開包，系統先展示完整內容，再逐張完成處理。永久貼紙依序進入立即貼附或銷毀流程；一次性貼紙依序進入收納、滿格取代或銷毀流程。所有內容處理完成後，開包流程結束並回到原本的獎勵或節點流程。

# 11. 一般戰鬥獎勵

一般怪物提供穩定的永久骰面成長。戰鬥勝利後顯示三個永久貼紙選項，玩家選擇其中一張進行立即處理，也可以略過整組貼紙獎勵。

每次一般戰鬥結算有 5% 機率將其中一個永久貼紙選項替換成貼紙包，形成 Jackpot。這個機率以每次獎勵畫面為判定單位，並由獎勵設定檔管理；一般怪物的金幣獎勵也由相同類型的數值設定統一管理。

# 12. 寶箱獎勵

寶箱提供三個高價值候選項目，玩家選擇其中一項。每個候選位置各自先依權重決定獎勵類型，再從對應獎勵池抽出具體品項；三個候選皆為不同品項。

寶箱類型的基準權重如下：

- 裝備：65%。
- 貼紙包：35%。

三個候選位置採用相同權重獨立判定，因此寶箱可能提供三件裝備、三個貼紙包或兩種類型的混合結果。權重由獎勵設定檔管理，寶箱同時可以提供設定檔指定的固定金幣獎勵。

玩家選擇貼紙包後立即進入開包流程；選擇裝備後，依[裝備槽與效果呈現](equipment.md#1-裝備槽與效果呈現)完成收納或替換及落槽演出，再結束寶箱獎勵流程。

# 13. 菁英與 Boss 獎勵

菁英提供高價值構築獎勵，區域 Boss 推進階段，版本終點的 Boss 完成 Run。各區獎勵角色、Demo 與正式版終點見[怪物與關卡設計](monsters-and-regions.md#2-六區進度與骰子里程碑)。

# 14. 裝備與裝備槽

裝備透過角色連鎖改寫、Control 操作、戰術效果與 Run 資源運用形成構築，與骰面配置共同決定玩家的作戰及成長方式。裝備的效果、槽位與取得流程統一記錄於[裝備與構築](equipment.md)。

# 15. 商店

普通商店販售裝備、回血、一次性貼紙與其他 Build 調整資源。骰子新增維持關卡里程碑制，永久貼紙成長維持戰鬥獎勵與貼紙包制，使商店專注於補給、戰術準備與裝備調整。

玩家購買一次性貼紙時，依消耗品欄規則確認收納或取代；購買裝備時，依[裝備槽規則](equipment.md#1-裝備槽與效果呈現)確認收納或替換。交易在確認後扣除金幣，取消操作會回到商店並保留交易前狀態。

# 16. 基礎戰鬥流程

每回合開始時，玩家一次擲出所有骰子。遊戲邏輯先決定每顆骰子的結果，演出系統再播放拋物線、旋轉、碰撞與落地微彈，並在約 0.6～1 秒內讓所有骰子穩定落地。骰子停止後會旋轉至清楚呈現預定結果的角度，系統接著顯示角色與裝備效果預覽並依角色能力處理重骰連鎖及 Control 操作。

玩家完成 Control 操作與重骰連鎖後鎖定結果。傷害預覽與正式結算共同使用有效骰面及裝備改寫後的關係規則，依[角色結算順序](tribelings.md#回合結算順序)計算各步驟結果，並在對應步驟計入裝備效果。鎖定後正式套用一次儲糧等狀態變化，同時記錄每次技能的發動者、參與者、受影響數值及變化前後值。演出依這份技能事件順序播放脈衝、技能名稱與數字輪播，再依最終攻擊清單完成撞擊；數值計算使用各步驟的正式結果。敵人存活時保留剩餘生命與護盾，執行當前意圖及對應裝備效果後開始下一回合；玩家的剩餘護盾與 Control 延續至下一回合。任一方生命歸零時結束戰鬥。

# 17. Control 系統

每場戰鬥開始時，玩家取得基礎 3 點 Control，並計入裝備提供的起始加成。基礎操作為消耗 1 點 Control，選擇 1 顆骰子重新擲一次；Control 在整場戰鬥中共用，每場開戰時重新計算起始值。

Control 讓玩家修正骰面結果，並透過裝備提供的換位操作調整骰子排列。每次操作及其重骰連鎖完成後，系統依目前結果、位置與已記錄事件，重新預覽支援關係、搶奪對象、儲糧、追加攻擊、再攻擊、護盾及最終傷害；角色對重骰的反應依[回合結算順序](tribelings.md#回合結算順序)，裝備操作與效果見[Control、戰術與戰鬥資源](equipment.md#3-control戰術與戰鬥資源)。

# 18. 角色能力與攻擊種類

角色能力以同骰配置、鄰骰關係、本輪角色與標籤數量、重骰事件及跨回合儲糧改變骰池結果。角色與食物的完整能力、計數範圍、身分轉換及觸發條件由[土人骰面角色與效果](tribelings.md#土人骰面角色與效果)統一管理，各效果按[回合結算順序](tribelings.md#回合結算順序)處理。

正常攻擊由本輪有效骰面承載，依技能結算後的攻擊值執行。角色技能與裝備產生的每筆追加攻擊，以透光骰子承載指定傷害，在來源技能的演出節拍進入預留槽位並呈現數值變化，再依其適用加成完成撞擊。小公主命令的再攻擊，則由符合條件的貴族按最終攻擊值再次執行普通攻擊，其作用限於該筆攻擊。偽裝者的虛擬面依角色規則參與計數。各類對象的計數、能力與加成範圍均由[土人骰面設計](tribelings.md)定義。

高基礎值骰面提供直接輸出，功能骰面透過支援、追加攻擊、防禦與操骰效果提高構築價值。永久貼紙同時改變單面的攻擊品質及整顆骰子的關係配置，形成貼附與替換時的取捨。

# 19. 防禦與回血

防禦能力以角色配置、標籤與重骰事件提供護盾。土人侍衛依本輪普通或貴族土人提供護盾，膽小土人在被重骰時留下護盾，土人工匠依鄰骰朝上的土人提供護盾。巨盾土人讀取本回合全隊累計獲盾值產生追加攻擊，護盾完整保留。能力與取值範圍依[土人骰面設計](tribelings.md)，使防禦配置同時支援生存與反擊構築。

回血效果採用較低出現率，並搭配每場觸發次數、回血上限、擊殺條件或其他限制。回血規則提供生存選擇，同時維持戰鬥向前推進的節奏。

# 20. 戰鬥結算與演出

結算演出以每次技能觸發為單位，依[角色結算順序](tribelings.md#回合結算順序)呈現「參與骰子同步脈衝 → 技能名稱淡入 → 數值立即變化」。玩家透過同一節拍中的聲光與數字，辨認發動者、受影響對象及各次技能的貢獻，看到本輪骰子如何互相支援、轉移數值並形成連鎖。

## 20.1 技能脈衝與名稱

技能觸發時，發動骰與本次能力實際涉及的其他朝上骰子，同步向上發出一次脈衝光。脈衝採與裝備發動相同亮度的金白色核心與外圍光暈，發動骰以較大的發光範圍突出，參與骰同步發亮，其餘骰子維持原樣。文字與數字位於光效上層，保持清晰。同骰背面提供的支援由受益骰承載回饋，發光範圍對應實際參與的骰子。

技能名稱與本次增減合併為一行，在發動者及受影響骰子上方淡入，例如「互相提攜 +3」、「搶奪 -10」。提示清楚可見後立即啟動受影響數字的輪播。名稱在固定位置停留一小段時間，再向上飄移並淡出。各骰上方預留文字空間；同骰連續技能的名稱依先後略微錯開高度，保留前一名稱的可讀時間。

同階段且互相獨立的技能可同步播放；具有前後依賴的技能按結算順序保留可辨識的節拍間隔。前一名稱的停留與淡出可和後續技能重疊，使連鎖持續推進。

## 20.2 數字輪播與中斷接續

攻擊數字以整數顯示，由目前顯示值快速輪播至該技能結算後向上取整的目標值。內部技能計算保留精度；每筆正常、追加與再攻擊在套用撞擊時倍率後，最終傷害無條件進位，預覽總傷害為逐筆取整後的總和。每次技能影響觸發一次數字放大，峰值為原尺寸的 1.05～1.1 倍，再以緩動縮回原尺寸。單位數與多位數均依實際位數清楚顯示。

同一數字在輪播途中受到新技能影響時，立即中斷舊輪播，從當下顯示值接續至新技能的目標值；縮放也由當下比例接續，峰值維持在 1.1 倍以內，最後回到原尺寸。例如 `10 → 20` 顯示至 `16` 時，新技能使正式結果成為 `30`，畫面立即接續 `16 → 30`；技能計算仍以正式的 `20` 為前一步結果。

增減值直接接在技能名稱後面，攻擊倍率換算成本次顯示攻擊值的差額，例如「接力 +10」。差額由該技能正式前後值各自向上取整後相減，即使前一段輪播被中斷也保持該次增減的正確性。護盾與儲糧以小圖示標示資源種類；身分轉換顯示新身分，公主命令顯示「再攻擊」。技能回饋集中於骰子上方同一行。

## 20.3 不同效果的回饋對象

攻擊加值與倍率作用於攻擊數字，獲盾作用於護盾數字，追加攻擊則由對應透光骰與預留槽位呈現。追加骰在來源技能的節拍進場，並隨後續適用效果更新數字。首次進場、待機漂浮與攻擊位移各由獨立容器承載，骰身從進場、撞擊、歸位到待機全程維持完整立體外觀。出生動畫只在該顆追加骰首次進場時播放一次，歸位後繼續原有漂浮。追加傷害只由骰身數字與上方技能提示呈現。

搶奪同時呈現雙方的數值變化：目標的攻擊下降或快速歸零，發動者的攻擊同步成長。搬運工整段隊列同步脈衝，隊尾呈現倍率帶來的成長，其餘成員維持各自攻擊。號角手讓受影響的正常骰同步跳數字；小公主的命令在符合條件的貴族上呈現回應，並於攻擊階段執行已登記的再攻擊。

## 20.4 音效與演出節奏

每次技能節拍使用一個主要音效，參與骰子共用該次聲音回饋。數字輪播搭配輕微滾動音，落定時播放短促收尾音。所有技能脈衝維持與裝備一致的明亮程度；全隊強化與高價值追加攻擊透過發光範圍及聲音重音呈現強弱層次。

演出初始調校範圍如下，實際值依可讀性與整輪節奏驗證：

| 項目 | 初始調校範圍 |
| --- | --- |
| 脈衝起始至技能名稱清楚可見 | 約 60～100 ms |
| 單次數字輪播與放大縮回 | 約 180～280 ms |
| 名稱淡入後的停留時間 | 約 400～600 ms，接著向上淡出 |
| 數字放大峰值 | 原尺寸的 1.05～1.1 倍 |

## 20.5 攻擊與收尾

所有技能事件播放完畢、攻擊數字穩定落定後，正常骰、透光追加骰及再攻擊依最終攻擊清單撞向敵人。攻擊歸零的正常骰留在原位呈現本輪狀態；已成立的追加攻擊依清單完成演出。敵人在攻擊序列中途被擊敗時，清單內的剩餘攻擊仍完成演出，剩餘撞擊保持相同的初始速度。

一次性貼紙在整場戰鬥中保持附著狀態，骰面檢視、關係預覽與擲出結果皆呈現其有效角色或食物種類與基礎攻擊值。戰鬥結束時播放貼紙移除回饋並恢復原本骰面。

結算採固定技能節拍與固定撞擊時長：技能間隔 110 ms，數字輪播 240 ms；每次撞擊依序為蓄力 25 ms、衝刺 50 ms、命中 70 ms、歸位 35 ms，再間隔 15 ms。正常、追加與再攻擊均使用同一套時序，敵人死亡後維持相同節奏。整輪長度隨技能及攻擊數量自然增加；同階段獨立技能同步播放，名稱淡出可重疊，具有前後因果的技能保留固定辨識節拍。

# 21. 敵人回合

玩家攻擊完成後，存活敵人依一行 Intent 判定並執行行動，再開始新一輪擲骰。Intent 文案、條件、結算順序與各怪物招式見[Intent 共通規則](monsters-and-regions.md#4-intent-共通規則)。玩家生命歸零時結束 Run，敵人生命歸零時進入勝利流程。

# 22. Build 方向

高數字 Build 集中取得高基礎值永久貼紙；同骰 Build 透過土人家族的面數加值、雙胞胎的最高基礎值取用、混混的面數門檻與獨行俠的單面條件，決定每顆骰子的配置。鄰骰與隊列 Build 透過跟班讀取鄰骰勇士、搬運工放大隊尾攻擊及工匠提供護盾，形成站位取捨。

群體與身分 Build 利用姐妹花、啦啦隊、耆老及偽裝者組織角色數量與種類，透過權威、禁衛軍與小公主串接貴族身分及再攻擊。搶奪 Build 由孩子王與惡霸集中攻擊，讓毛賊接續產生追加攻擊；號角手再將追加骰數量轉成全隊正常攻擊的加成。

重骰 Build 透過老師、搗蛋鬼、膽小土人與祭司，把骰面調整連結到攻擊及護盾收益。食物與儲糧 Build 透過農夫、好吃的、廚師與大胃王安排食物數量、數值及跨回合爆發；護盾 Build 以侍衛、工匠與膽小土人提高容錯，再由巨盾把本回合獲盾量轉為攻擊收益。各構築的能力與結算依[土人骰面設計](tribelings.md)。

裝備構築與上述角色組合交叉搭配，改變連鎖規則、Control 運用及金錢、食物與剩餘 Control 的價值。具體效果見[裝備與構築](equipment.md)。

# 23. 介面與資訊規則

戰鬥畫面持續顯示玩家生命、護盾、金幣、Control、地圖進度、骰池數量、裝備槽與三格消耗品欄。裝備槽與消耗品欄採用獨立區域，讓永久被動與單場資源保持清楚區別。

戰前準備會顯示一次性貼紙的目標骰子、目標骰面、覆蓋前內容與覆蓋後內容。骰面檢視與永久貼紙改造共用單一全圖版面，以清楚字級呈現每面的角色或食物、有效基礎值、標籤、能力與覆蓋資訊，內容依[土人骰面設計](tribelings.md)。展開圖與戰鬥共用面索引及骰型幾何，hover 或鍵盤聚焦骰面時高亮所有實際共用邊的相鄰面，提供配置位置辨識。

永久貼紙改造平時顯示原面，hover 時呈現覆蓋後的種類、數值、標籤與能力，點擊後套用貼紙；滑鼠離開則恢復原面顯示。文字採正向閱讀並在骰面安全區域換行，原內容與預覽共用預留空間。全圖版面依視窗調整尺寸，較小視窗以捲動保持字級與資訊可讀性。

Control 階段的骰子操作列提供重骰、老師與已持有裝備的操作，窄視窗可橫向捲動。戰鬥預覽呈現角色連動、有效標籤、搶奪對象、追加攻擊、再攻擊、儲糧、護盾及總傷害。永久貼紙、一次性貼紙、貼紙包與裝備替換都提供明確的套用與放棄操作；需要連續處理多張貼紙時，介面會顯示剩餘數量與目前處理項目。

# 24. 數值設定來源

所有可調整的遊戲數值集中放在 `src/configs`，由對應設定檔作為唯一來源。服務與介面讀取設定值並呈現結果，使機率、槽位、價格、里程碑與數值曲線保持一致。

本次規格要求至少集中管理以下參數：

- 一般戰鬥貼紙包 Jackpot：5%。
- 寶箱裝備權重：65%。
- 寶箱貼紙包權重：35%。
- 寶箱候選數量：3。
- 消耗品欄容量：3。
- 裝備槽容量、效果加值、轉換比例、操作成本、機率與成長參數，依[裝備規格](equipment.md)集中管理。
- 每場基礎 Control：3。
- 各貼紙包的張數、內容池與混合規則。
- 角色與食物骰面的基礎值、能力加值、倍率、護盾量與觸發門檻。
- 技能演出的脈衝強度與時長、名稱淡入與停留及上移淡出時長、技能節拍間隔、數字輪播時長、縮放峰值與音效強度，依第 20 節集中管理。

怪物、地圖、骰子里程碑與區域成長的對應設定檔見[設定檔與修改入口](monsters-and-regions.md#12-設定檔與修改入口)。

## 24.1 土人版程式重構

本次依土人骰面設計重構現有資料、結算與演出流程，依序完成：

1. 將角色、標籤、貼紙、貼紙包與骰池配置統一為土人版，能力參數集中在現有設定入口。
2. 由共用結算器產生各技能事件、有效身分、傷害、護盾、儲糧、追加攻擊及再攻擊，預覽與正式結算共用結果。
3. 將重骰連鎖、祭司目睹事件與隨機目標保留接入現有戰鬥狀態，按回合重置事件。
4. 依技能事件播放脈衝、名稱、數字輪播與聲音，支援數字動畫中斷接續及依清單攻擊。
5. 替換失效的動物及元素效果與資料引用，完成核心計算案例、TypeScript 檢查與正式建置。

初版能力數值採可調設定，以既有區域貼紙成長為起點，透過 3／6／10 顆骰池的代表組合驗證傷害、護盾與連鎖上限。自動測試集中於核心計算及狀態轉移；演出以事件與結果一致性、正常結束及節奏參數作為程式驗證依據。

# 26. 核心驗證問題

核心系統透過實際遊玩回答以下問題；敵人強度、戰鬥回合、Intent 理解與骰池擴張另依[數值校準與驗證](monsters-and-regions.md#11-數值校準與驗證)檢查。

1. 玩家能否在第一次戰前準備中理解一次性貼紙會持續整場並於戰後消失？
2. 三格消耗品欄是否能形成保存、使用、取代與放棄之間的有效取捨？
3. 玩家是否願意在菁英或 Boss 前投入多張一次性貼紙？
4. 高基礎值輸出面與依靠角色配置、標籤及連鎖的功能面是否都具有實際選擇價值？
5. 基礎 3 點 Control 與裝備加成是否能支撐重骰、換位及保留資源的取捨？
6. 裝備、永久貼紙與一次性貼紙是否各自具有清楚角色？
7. 寶箱的 65% 裝備與 35% 貼紙包權重是否形成足夠的獎勵變化？
8. 一般戰鬥的 5% 貼紙包 Jackpot 是否稀有且值得期待？
9. 寶箱裝備的移動、落槽與滿槽替換回饋是否讓玩家清楚理解目標槽位與最終結果？
10. 玩家能否理解裝備的生效條件，並在重骰或換位後辨認預覽中的效果變化？
11. 後期大量骰子是否仍能快速讀懂並在主要結算時間內完成攻擊？
12. 玩家能否從同步脈衝、技能名稱與數值變化，辨認每次技能的發動者、參與者與增減原因？
13. 連續技能中斷同一數字的輪播時，畫面是否順暢接續、保留各次變化提示，並在撞擊前落定至正式結果？
14. 「姐妹花強化 → 孩子王搶奪 → 毛賊追加攻擊 → 號角手全隊加傷」在正常速度下是否順序清楚、文字各自可讀，且聲光強度具有層次？

# 27. 核心總結

本作的核心是把少量初始骰子一路養成具有高數字、土人角色配合、跨骰連鎖與裝備協同的強力骰池。固定進度里程碑帶來更多骰子，永久貼紙帶來單面長期成長，一次性貼紙帶來戰前規劃與單場爆發，裝備透過連鎖改寫、操骰方式與資源運用形成貫穿 Run 的構築。

每回合的主要體驗為：

> **戰前配置有限資源 → 擲出自己養成的骰池 → 使用 Control 修正關鍵結果 → 看數字與連鎖迅速放大 → 骰子連續撞向敵人。**
