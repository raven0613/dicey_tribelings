# 畫面縮放與布局

本文件由 [介面與資訊規則](spec.md#23-介面與資訊規則)導流。網頁版與桌面版的遊戲場地固定為 1920 × 1080 設計單位，包含背景、頂部 nav、怪物、骰盤、底部 footer、彈窗及劇情。共用倍率取 viewport 寬度／1920 與高度／1080 的較小值；完整場地等比例縮放後水平、垂直置中，場地邊界裁切超出的演出。視窗長寬比改變時，場地設計寬高與背景構圖維持固定。1280 × 720 的倍率為 2/3，桌面 87 × 87 設計單位的骰子顯示為 58 × 58px。1280 × 800 的內容區同樣顯示 1280 × 720 遊戲，上下各 40px 由外圍背景填補。

viewport 外圍由目前場景的 `fullBackground` 圖片以 CSS cover 置中鋪滿，窄畫面裁切左右，扁畫面裁切上下。背景亮度與模糊程度由各場景設定，模糊圖片向外延伸三倍模糊半徑並在 viewport 邊界裁切。清晰遊戲場地位於外圍背景上方；場景內部的底色維持原設定。素材像素尺寸及螢幕密度負責清晰度，場地倍率負責布局。

粗指標裝置的內容區短邊符合 `VIEWPORT_PRESENTATION.mobileShortSide` 門檻時，沿用手機觸控說明入口與 58 設計單位骰體；手機同樣使用固定場地與共用倍率。桌面小視窗沿用桌面骰體設定。手機完整產品布局後續依實際觸控需求調整。

介面文字的最小靜態顯示字級由 `VIEWPORT_PRESENTATION.minimumFontSize` 管理，設計座標的下限為該值除以共用倍率。字級、行高與容器尺寸共同支援這個下限；骰下數字資訊維持固定行數，長內容使用行內捲動。骰面展開圖在共用倍率與內容縮放後仍維持文字下限，必要時使用既有區域捲動。骰面攻擊值依 SVG 顯示倍率校正最小字級，文字旁的 SVG 圖示、角色徽章圖示及獨立操作圖示以共用 `inlineIconSizeEm` 比例跟隨所在文字的字級，採用 `ui-icon` 樣式並保持尺寸；角色徽章額外指定的圖示尺寸作為基準下限。地圖、金幣、生命／護盾、技能狀態、商店價格、裝備提示及彈窗操作皆沿用此規則。裝備槽依圖示與操作文字所需空間增加列高，高度不足時沿用欄內捲動。骰體圖案、路線連接線、卡片主視覺與演出圖形按場地倍率縮放。短暫攻擊與數字動畫的變形屬演出。

主畫面、彈窗、骰子飛行、裝備飛入、提示及劇情使用相同場地倍率。浮動圖層由場地提供共用掛載點並避開骰盤裁切，螢幕座標透過場地邊界與倍率換算回設計座標。[場景背景](backgrounds.md)以場地底部距離定位 back 與草木基準線，ground 貼齊場地底部，vine 與 beard 以頂部距離對齊場地頂端。場地容器負責縮放，戰鬥局部演出由怪物與骰盤承載。視窗變更時更新倍率與相關目標位置；CSS 布局斷點依固定場地邏輯尺寸判斷。

設定入口為 `src/configs/viewportConfig.ts`，管理設計寬高、最小字級、文字旁圖示比例與手機短邊門檻。場地容器位於 `src/components/layout/`，純計算與座標轉換位於 `src/service/layout/`。驗證沿用既有核心計算測試、TypeScript 與正式建置；瀏覽器及封裝應用由使用者手動開啟檢視。
