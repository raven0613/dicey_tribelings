# 骰面呈現

本文件由 [遊戲規格](spec.md#5-骰子與骰面)導流，管理戰場骰體、貼紙、數字與角色出場。正常骰與追傷骰的靜態可見骰體總寬高在桌面皆為 75 × 75px，視窗寬度 600px 以下皆為 58 × 58px，陰影、光暈與攻擊放大屬額外演出。場地寬度不足時於骰盤內橫向捲動，正常骰沿單列保留左右鄰骰關係，追傷骰在上方預留單列槽位並向右延伸。骰體尺寸、槽距及留白使用同一份當前尺寸設定，追傷骰投影與攻擊座標同步更新。骰列依頂部留白與固定列距定位，下方數值區固定預留攻擊、護盾、儲糧與乾糧分配四行；各行維持固定行高，長數值在行內縮放以完整呈現。文字的出現、消失與數值變化沿用相同骰子座標。board-body 高度取骰盤內容加橫向捲軸空間與裝備欄高度的較大值，骰盤只做橫向捲動。矮視窗維持上下排列及 board 操作區高度，由敵人區承接高度縮減。

## 骰體與貼紙

正常骰由外至內分為骰體、倒角、骰面與貼紙。`battle-die-rim` 代表整顆骰體，骰體與骰面共用設定色，初版白色。骰面為置中的圓角方形；骰體至骰面的空間呈現倒角。骰面內再向內縮形成圓角方形貼紙，普通貼紙為白色，特殊材質的底色與紋理顯示在貼紙上。

圖層由底至頂為骰體與倒角、骰面、貼紙底色與紋理、角色底圖、角色前景、材質反光、數字。初版以鏡面試作低透明度反光，覆在角色上方並限制在貼紙範圍。材質反光的透明度可獨立調整，角色圖片保留原色。骰面只保留角色、數字及必要的狀態圖示，材質名稱與符號集中於 Hover 資訊。

常駐與 Hover 連鎖框沿骰體外緣向外偏移，圓角由骰體 SVG 半徑、描邊及實際顯示尺寸換算，再加上外擴距離與外框線寬。外框與骰體共用圓角來源，75px 與 58px 分別換算。

## 數字

數字位於右下角並覆蓋角色，外圍使用白色描邊。單 tag 使用對應設定色，雙 tag 以右上至左下的斜線分成兩個實色區域，淺色位於左上、深色位於右下，依色彩相對亮度排序。分界角度可調整。當回合有效身分具有全部 tag 時，數字使用明度適中且飽和的彩虹漸層；身分轉換與結算顯示沿用同一份當下標籤。數字字體、字重、字級、描邊、配色及漸層方向由 config 管理。

## 土人混混出場

`src/assets/dice/face/hood_face.png` 與 `hood_hand.png` 皆為 174 × 174px 透明圖片，兩層圖片都以完整畫布等比縮放、置中於 100 × 100 SVG 座標，顯示範圍隨當前骰體尺寸縮放。替換為 75 × 75px 圖片時維持相同構圖比例與透明留白，即可沿用中心、顯示範圍與動畫路徑。手持武器層覆在臉部層上。每次初擲或重骰落定且結果為土人混混時，臉部維持原位，手持武器從結果位置左下方沿曲線上拋，再加速落至結果位置稍微右下方，形成下壓。下壓後短暫定住，接著快速回彈至結果位置並收住。圖片角度固定，整段播放一次後停留在完整靜態構圖。Hover、數字更新與身分轉換沿用靜態構圖。減少動態效果設定直接呈現結果。

動畫由 `DICE_CHARACTER_PRESENTATION.gang` 管理：`start` 為左下起點、`control` 為曲線控制點、`press` 為右下下壓位置，皆使用 100 × 100 SVG 座標，桌面畫面位移為設定值的 0.75 倍，手機為 0.58 倍；x 正值向右，y 正值向下。`control.y` 小於起點與下壓位置的 y，形成中途制高點。系統在曲線實際最高點精確切分上拉與下壓，兩段沿用原曲線形狀。上拉起步快、接近最高點時減速，下壓由最高點開始加速；最高點保持連續移動，下壓位置才短暫定住。

上提、下壓、停頓與回彈共用一個動畫時間軸。路徑關鍵點按各段實際長度定位，時間關鍵點按 config 分配，各段分別套用自己的 easing。停頓期間保持下壓位置，最後回到原點並停住；每次落定只啟動一次完整動畫。

總時長 `durationMs` 包含曲線移動、下壓停頓 `pressHoldMs` 與回彈 `reboundMs`，曲線移動時間取總時長扣除後兩者。`riseFraction` 分配曲線移動時間給上拉，其餘時間用於下壓；數值介於 0 與 1，調小會加快上拉並延長下壓，調大則延長上拉並加快下壓。`riseEasing` 控制上拉，`pressEasing` 控制下壓，`reboundEasing` 控制回彈收尾。每組 easing 依序填入 `x1 y1 x2 y2`，值域為 0～1；其他值固定時，提高第二個數值可加快起步，提高第四個數值會降低終點速度。調整路徑位置使用 `start`、`control`、`press`，調整同一路徑的速度分配使用時間與 easing 設定，實際數值以 config 為準。

## 調整入口與驗證

外觀與場地參數集中於 [dicePresentationConfig.ts](../src/configs/dicePresentationConfig.ts)：`DICE_NUMBER_PRESENTATION` 管理數字字體、描邊、tag 色票與切分角度，`DICE_FACE_PRESENTATION` 管理骰體與貼紙，`DICE_CHARACTER_PRESENTATION` 管理混混分層與曲線動畫，`DICE_TRAY_PRESENTATION` 管理桌面與手機尺寸、斷點及間距，`DICE_RESULT_PRESENTATION` 管理固定數值行高、行數與留白，`PLAYER_BOARD_PRESENTATION` 管理裝備欄尺寸與捲軸預留，`PHANTOM_DICE_PRESENTATION` 管理追傷骰投影。材質反光由 [materialConfig.ts](../src/configs/materials/materialConfig.ts) 管理。

核心測試驗證固定尺寸、槽位排列及數字標籤配色計算；元件以型別檢查、建置與程式審查確認整合。
