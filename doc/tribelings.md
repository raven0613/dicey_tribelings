## 對話呈現與流程

- 開頭在獨立劇情畫面播放，完成或 Skip 後才顯示戰鬥畫面與戰鬥開場兩句。重骰教學的兩句等首次骰子落定、Control 控制列出現後播放，以 `public/arrow.png` 浮動指向實際 Control 位置。
- 每段一般對話點擊推進：打字中點擊立即補完本句，完整顯示後再點才進下一句；可連續快速點擊，不設等待鎖。打字初版每字 18 ms，按字素切分，保持 emoji 完整。
- 每個一般劇情段落提供 Skip，只跳過當前段落。完成與 Skip 都記為已讀，跨 Run 與重新整理保留；已讀段落不自動重播。Skip 不改變獎勵、貼附或節點推進。
- 框在畫面中央安全範圍內逐句隨機換位，每句顯示期間固定。框先依完整文字排版，再逐字顯示，不能隨打字改變大小。框、刺角與角色符號一併限制在可見 viewport 內，視窗縮放時重算；長文在框內捲動。
- 長圓框為白底黑框的長方形加大圓角；刺刺框沿圓角矩形的完整周長等距產生尖角，四角連續轉向；尖角深度受底寬與轉角半徑限制，避免角落擠成細線。一般句子切換時舊框消失；附和句保留前框、在附近輕微重疊，離開附和句時兩框一起移除，文字不可互相遮擋。
- 角色暫用現有骰面符號搭配說話者名稱；角色與結尾插圖可分別透過 `storyPresentationConfig.ts` 的 `STORY_VISUALS`、`STORY_ILLUSTRATIONS` 指定圖片。王子、玩家等尚無骰面角色使用既有符號代演，不新增遊戲角色；之後可在同一視覺設定改接圖片。結尾兩張插圖保留獨立圖像節拍，以符號暫代。
- 首個補給寶箱在按下開啟、獎勵選項出現（`chest-card opened`）後，才觸發對話及預留空間；未開啟時不播放、不計已讀。對話自動逐句播放、停留後消失，不設 Skip、不攔截滑鼠，專用空間依最大對話組合預留高度，避免換句或消失時移動寶箱按鈕及獎勵卡。玩家離開寶箱或開始處理所選獎勵時收起並記為已讀。
- 首次實際收納臨時貼紙時解鎖配置介面並播放介紹；商店購買與貼紙包共用此條件，僅看到商品或獎勵預覽不解鎖。解鎖紀錄跨 Run 保留，庫存用完也不重新隱藏。
- 小公主首次進入永久貼紙處理流程時播放登場段落。「已經把自己貼在潛水艇上」是台詞，仍由既有流程提供一張貼紙，玩家自行貼附或放棄；不額外送貼紙、不自動貼附。
- 第六區 Boss 勝利後先播放完整結尾（包括一周目後的敲門段落），再顯示通關結算。王冠與「得到土人王子 ×1」目前僅為劇情演出，不新增裝備、王子骰面或二周目玩法。

主畫面、重置與隱藏預覽操作見 [主畫面與遊玩紀錄](spec.md#231-主畫面與遊玩紀錄)。劇本與角色視覺由 `src/configs/story/` 管理，劇情狀態使用 `src/store/storyStore.ts`，排版與播放服務集中於 `src/service/story/`，元件集中於 `src/components/story/`。

# 骰面稀有度

稀有度由角色能力對構築的影響、放大收益與取得頻率決定，同一角色跨地區維持分級。區域提供新永久貼紙的數值品質；臨時貼紙沿用目標面的永久基礎值提供單場零件。標籤「普通」與稀有度「一般」各自管理。

| 稀有度 | 首版角色                                                                                                                             |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| 一般   | 家族、姐妹花、雙胞胎、混混、孩子王、獨行俠、廚師、搬運工、跟班、啦啦隊、毛賊、膽小土人、侍衛、勇士、工匠、騎士、搗蛋鬼、農夫、好吃的 |
| 稀有   | 耆老、祭司、老師、禁衛軍、權威、偽裝者、大胃王、巨盾、惡霸、號角手                                                                   |
| 傳說   | 小公主                                                                                                                               |

一般角色提供能通關的基本組合；稀有角色提供放大與轉型；小公主沿用首區菁英保證一張、貴族包每包 5% 且最多取得兩張的特殊來源。一般獎勵依角色權重抽取：一般 4、稀有 1，小公主由專屬來源發放。分類與權重均為可調整首版。

日文：入れ替わり

# 共通取值與初版參數

角色與食物的有效基礎值讀取永久骰面及本場覆蓋貼紙。加值與基礎倍率各自提供攻擊貢獻；搶奪取發動當下的正式攻擊值。內部各步計算四捨五入至小數點後兩位，倍率、搶奪與食物強化使用此精度。每筆正常、追加與再攻擊在套用撞擊倍率後，按內部精度正規化並無條件進位為整數傷害；預覽與正式扣血共用逐筆取整後的攻擊清單。土人農夫的固定強化完整給予最近的一份實體食物；只有虛擬食物時強化該份虛擬食物。

老師的操作資格取回合初擲結果，每位各可選一名最低有效基礎值的朝上土人免費重骰。控制列主動啟動後，唯一合法目標直接重骰；多個合法目標由玩家選擇，可取消且不消耗資格。Control 歸零仍可啟動。最低值取所有朝上土人，再排除受保護骰；老師自身符合條件也可被選取。每次連鎖落定後重新計算最低值；老師被改骰面即失去未用資格，重骰擲出的老師不新增資格。老師加值綁定該次重骰結果，目標再次改骰面時更新。所有重骰均排除當下朝上的面索引，從其餘面等機率抽取，初擲不受此限制。祭司每次目睹增加同一筆本回合追加攻擊的數值，於結算時釋放。廚師儲糧綁定骰子，跨回合累加至釋放，戰鬥結束時清空。

## 相鄰面能力的數值定位

同骰相鄰面依骰型幾何的共用邊判定，與展開圖高亮一致。自身面與其他骰子各自屬於不同取值範圍；本規則讀取相鄰實體面的有效角色與標籤。d4、d6、d8、d10、d12 每面相鄰數分別為 3、4、3、4、5。

混混定位為以貼紙位置建立多段追傷，前期取得固定收益，中後期搭配號角手與戰鼓共鳴箱。以一般獎勵及一回合結算為驗證範圍，初版每鄰面 2 點，目標是 1～2 個符合鄰面提供 2～4 點追傷，滿配置提供 6～10 點。工匠定位為朝上觸發的局部護盾配置，每個相鄰 [職人] 面 1 點，滿配置提供 3～5 點護盾，並供巨盾取值。

第一區滿配置 d6：土人混混基礎 4，四顆追傷各 2，共 12 傷害；土人家族基礎 5、五個其他家族各加 2，共 15。混混若採每鄰面 1／2／3 點，總傷害為 8／12／16；採 2 點保留家族的直接輸出優勢，混混則以多顆追傷取得連動價值。第六區同配置為混混 27、家族 30，固定追傷保持原值，成長由基礎值及組合提供。

在六顆正常骰、單一號角手與戰鼓共鳴箱的情境，每新增一個混混鄰面提供 2 直接追傷、2 裝備追傷及 6 全隊加值，共增加 10 傷害。多號角手與多混混的乘積是高敏感連動；驗證須包含零鄰面、單鄰面、滿配置、臨時覆蓋與不同骰型。追傷各占獨立槽位並按原節奏結算，混混本次產生的所有追傷由同一技能事件呈現。

# 回合結算順序

先完成所有重骰，再依下列順序結算。傷害預覽與正式結算使用相同順序；預覽不重複累積狀態，也不重新抽取已確定的隨機目標。

1. **擲骰與 Control：** 完成主動重骰、老師與搗蛋鬼連鎖。每位老師每回合只發動一次，因重骰而擲出的老師不再發動；同時擲出的多位老師各自發動。重骰發生時，記錄膽小土人的護盾，以及當時在場祭司目睹的重骰收益。祭司即使之後被骰掉，已記錄收益仍保留至本回合結算。
2. **鎖定與身分轉換：** 全部重骰完成後鎖定結果。所有農夫依同一份鎖定結果判斷：沒有食物時，同時變成各自基礎值的「好吃的」，連同標籤一起替換，食物照常攻擊；已有食物時，保留農夫身分。再處理權威的貴族標籤替換，原目標仍合法時維持，失效才重選。
3. **計數與基礎取值：** 偽裝者依尚未加入虛擬計數的同一份場面，複製數量最多的一種土人，平手隨機選一種；虛擬面只參與計數，不發動能力、攻擊或占據位置。雙胞胎取同骰最高雙胞胎的基礎值，作為自身本回合的基礎值。
4. **支援、食物強化與護盾：** 計算各角色的攻擊加值、倍率及護盾。搬運工只有隊尾依隊列人數放大自身基礎值，其餘照常攻擊。土人農夫各自優先強化最近的一份實體食物，等距選左；只有虛擬食物時強化其數值，強化可疊加。朝上的土人工匠依同骰相鄰 [職人] 面數，每面提供 1 護盾，每骰每回合結算一次；侍衛對具有普通或貴族任一標籤的土人計數。
5. **儲糧與一般追加攻擊：** 食物強化後，廚師將同骰擲出食物的有效基礎值累加存入儲糧，不消耗食物；擲出廚師時，將儲糧變成追加攻擊並清空。登記混混、啦啦隊、祭司等已成立的追加攻擊。
6. **搶奪：** 孩子王與惡霸依骰子由左至右處理。孩子王隨機選另一名攻擊大於 0、尚未被孩子王搶過的普通土人，取得對方當前攻擊值的 1.2 倍，並使對方歸零；孩子王可以互搶，每名目標每回合最多被孩子王搶一次，無合法目標則跳過。惡霸固定扣除相鄰目標當前攻擊的一半，取得扣除量的 1.1 倍；職人目標改為 2 倍。搶奪不撤銷先前已成立的支援、護盾與追加攻擊。
7. **毛賊：** 本回合有成功搶奪時，每名擲出的毛賊追加攻擊一次；本回合曾因搶奪而攻擊歸零的毛賊不發動，即使稍後恢復攻擊也不補發。
8. **巨盾：** 本回合獲得的護盾全部確定後，每名巨盾各讀取同一份全隊累計獲盾值，產生一次等值追加攻擊，不扣除護盾，也不計入前回合留下的護盾。
9. **號角手：** 統計已成立的追加攻擊骰數量，每名號角手各依該數量替全體正常骰加傷，多名效果疊加；追加骰不獲得此加傷，小公主可以因此取得攻擊力。
10. **小公主：** 多名公主依序命令當下攻擊不為 0 的其他貴族，各依最終攻擊值再攻擊一次。再攻擊不產生追加骰、不重算號角手，也不重新觸發角色能力。
11. **攻擊與收尾：** 依最終清單執行正常攻擊、追加攻擊及公主命令的再攻擊；正常骰攻擊為 0 時不參與撞擊。敵人存活則執行行動。回合結束後清除祭司累積、重骰觸發次數、搶奪記錄與臨時身分等本回合狀態；廚師尚未釋放的儲糧跨回合保留。
