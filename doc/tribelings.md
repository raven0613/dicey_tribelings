## 對話呈現與流程

- 開頭在獨立劇情畫面播放，完成或 Skip 後才顯示戰鬥畫面與戰鬥開場兩句。重骰教學的兩句等首次骰子落定、Control 控制列出現後播放，以 `public/arrow.png` 浮動指向實際 Control 位置。
- 每段一般對話點擊推進：打字中點擊立即補完本句，完整顯示後再點才進下一句；可連續快速點擊，不設等待鎖。打字初版每字 18 ms，按字素切分，保持 emoji 完整。
- 每個一般劇情段落提供 Skip，只跳過當前段落。完成與 Skip 都記為已讀，跨 Run 與重新整理保留；已讀段落不自動重播。Skip 不改變獎勵、貼附或節點推進。
- 框在畫面中央安全範圍內逐句隨機換位，每句顯示期間固定。框先依完整文字排版，再逐字顯示，不能隨打字改變大小。框、刺角與角色符號一併限制在可見 viewport 內，視窗縮放時重算；長文在框內捲動。
- 長圓框為白底黑框的長方形加大圓角；刺刺框沿圓角矩形的完整周長等距產生尖角，四角連續轉向；尖角深度受底寬與轉角半徑限制，避免角落擠成細線。一般句子切換時舊框消失；附和句保留前框、在附近輕微重疊，離開附和句時兩框一起移除，文字不可互相遮擋。
- 角色暫用現有骰面符號搭配說話者名稱；角色與結尾插圖可分別透過 `storyPresentationConfig.ts` 的 `STORY_VISUALS`、`STORY_ILLUSTRATIONS` 指定圖片。王子、玩家等尚無骰面角色使用既有符號代演，不新增遊戲角色；之後可在同一視覺設定改接圖片。結尾兩張插圖保留獨立圖像節拍，以符號暫代。
- 首個補給寶箱在按下開啟、獎勵選項出現（`chest-card opened`）後，才觸發對話及預留空間；未開啟時不播放、不計已讀。對話自動逐句播放、停留後消失，不設 Skip、不攔截滑鼠，專用空間依最大對話組合預留高度，避免換句或消失時移動寶箱按鈕及獎勵卡。玩家離開寶箱或開始處理所選獎勵時收起並記為已讀。
- 首次實際收納臨時貼紙時解鎖配置介面並播放介紹；商店購買與貼紙包共用此條件，僅看到商品或獎勵預覽不解鎖。解鎖紀錄跨 Run 保留，庫存用完也不重新隱藏。
- 小公主首次進入永久貼紙處理流程時播放登場段落。「已經把自己貼在潛水艇上」是台詞，仍由既有流程提供一張貼紙，玩家自行貼附或放棄；不額外送貼紙、不自動貼附。
- 第六區 Boss 勝利後先播放完整結尾（包括篇章結束後的敲門段落），再顯示鱷魚人篇完成結算。王冠與「得到土人王子 ×1」目前屬於劇情演出；地下篇與下一難度依[後續進程](progression-roadmap.md)開發。

主畫面、重置與隱藏預覽操作見 [主畫面與遊玩紀錄](spec.md#231-主畫面與遊玩紀錄)。劇本與角色視覺由 `src/configs/story/` 管理，劇情狀態使用 `src/store/storyStore.ts`，排版與播放服務集中於 `src/service/story/`，元件集中於 `src/components/story/`。

# 骰面稀有度

稀有度由角色能力對構築的影響、放大收益與取得頻率決定，同一角色跨地區維持分級。區域提供新永久貼紙的數值品質；臨時貼紙沿用目標面的永久基礎攻擊力提供單場零件。標籤「普通」與稀有度「一般」各自管理。

| 稀有度 | 角色                                                                                                                             |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| 一般   | 家族、姐妹花、雙胞胎、混混、孩子王、獨行俠、廚師、搬運工、跟班、啦啦隊、毛賊、膽小土人、侍衛、勇士、工匠、騎士、搗蛋鬼、農夫、好吃的、水果拼盤 |
| 稀有   | 耆老、祭司、老師、禁衛軍、權威、偽裝者、大胃王、巨盾、惡霸、號角手、警探                                                                   |
| 傳說   | 小公主                                                                                                                               |

一般角色提供能通關的基本組合；稀有角色提供放大與轉型；小公主沿用首區共同寶箱完成後保證一張、貴族包每包 5% 且最多取得兩張的特殊來源。一般獎勵依角色權重抽取：一般 4、稀有 1，小公主由專屬來源發放。角色權重由獎勵設定統一管理。

### 儲糧

朝上有效標籤包含 [食物]，且同骰有效面含有廚師時，將食物值存入該骰。全隊共用容量，鱷魚人區為 150，地底怪物區為 200；各骰分別持有及釋放自己的儲糧。食物從最左側依序入庫，剩餘空間不足時只存可容納的數值，滿額時照常攻擊。廚師釋放儲糧後騰出容量，戰鬥結束時清空。所有實體食物入庫後，再以剩餘容量將一份乾糧平均分給含廚師面的骰子，最後由朝上的廚師釋放儲糧。整數餘量從左至右各分一點，小數餘量交給下一顆。乾糧計入一份食物，該回合使用完畢；勝利只攜帶當輪實體食物值。

# 結算規則與操作

共通取值、階段順序、跨回合狀態、再攻擊與追加骰依[土人結算規則](tribeling-resolution.md)。角色效果以上述新版能力為準，數值與玩家文案分別由角色平衡設定及說明設定管理。

骰面視窗可在戰鬥外及首次擲骰前直接拖曳整顆骰子，放開立即保存新順序，關閉視窗後保留。首次擲骰後至戰鬥結束期間保持檢視功能並停用自由拖曳。拖動採插入排序，選取、永久面、材質、臨時覆蓋與印記均跟隨骰子。勇士骰的原工匠面由白值 2 的搗蛋鬼取代。

戰鬥技能說明保留玩家文案與內部結算規則的分工。階段性效果各占一行，符合當下條件的階段加勾，未達成階段降低亮度；互斥區間只勾目前所在區間。啦啦隊達四名戰士時先顯示只有土人圖的追加骰，最終取值階段才顯示數字。
