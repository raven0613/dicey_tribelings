## 對話呈現與流程

- 開頭在獨立劇情畫面播放，完成或 Skip 後才顯示戰鬥畫面與戰鬥開場兩句。重骰教學的兩句等首次骰子落定、Control 控制列出現後播放，以 `public/arrow.png` 浮動指向實際 Control 位置。
- 每段一般對話點擊推進：打字中點擊立即補完本句，完整顯示後再點才進下一句；可連續快速點擊，不設等待鎖。打字初版每字 18 ms，按字素切分，保持 emoji 完整。
- 每個一般劇情段落提供 Skip，只跳過當前段落。完成與 Skip 都記為已讀，跨 Run 與重新整理保留；已讀段落不自動重播。Skip 不改變獎勵、貼附或節點推進。
- 框在畫面中央安全範圍內逐句隨機換位，每句顯示期間固定。框先依完整文字排版，再逐字顯示，不能隨打字改變大小。框、刺角與角色符號一併限制在可見 viewport 內，視窗縮放時重算；長文在框內捲動。
- 長圓框為白底黑框的長方形加大圓角；刺刺框沿圓角矩形的完整周長等距產生尖角，四角連續轉向；尖角深度受底寬與轉角半徑限制，避免角落擠成細線。一般句子切換時舊框消失；附和句保留前框、在附近輕微重疊，離開附和句時兩框一起移除，文字不可互相遮擋。
- 角色暫用現有骰面符號搭配說話者名稱；角色與結尾插圖可分別透過 `storyPresentationConfig.ts` 的 `STORY_VISUALS`、`STORY_ILLUSTRATIONS` 指定圖片。王子、玩家等尚無骰面角色使用既有符號代演，不新增遊戲角色；之後可在同一視覺設定改接圖片。結尾兩張插圖保留獨立圖像節拍，以符號暫代。
- 首個補給寶箱在按下開啟、獎勵選項出現（`chest-card opened`）後，才觸發對話及預留空間；未開啟時不播放、不計已讀。對話自動逐句播放、停留後消失，不設 Skip、不攔截滑鼠，專用空間依最大對話組合預留高度，避免換句或消失時移動寶箱按鈕及獎勵卡。玩家離開寶箱或開始處理所選獎勵時收起並記為已讀。
- 戰前配置與背包從第一場開放。首次實際取得臨時貼紙時播放介紹，已讀紀錄跨 Run 保留；商品或獎勵預覽維持預覽流程。
- 小公主首次進入永久貼紙處理流程時播放登場段落。「已經把自己貼在潛水艇上」是台詞，仍由既有流程提供一張貼紙，玩家自行收納、貼附或放棄，發放一張獨立貼紙。
- 第三區 Boss 勝利並完成新骰展示與戰利品後播放完整結尾（包括篇章結束後的敲門段落），再顯示鱷魚人篇完成結算。王冠與「得到土人王子 ×1」目前屬於劇情演出；地下篇與下一難度依[後續進程](progression-roadmap.md)開發。

主畫面、重置與隱藏預覽操作見 [主畫面與遊玩紀錄](spec.md#231-主畫面與遊玩紀錄)。劇本與角色視覺由 `src/configs/story/` 管理，劇情狀態使用 `src/store/storyStore.ts`，排版與播放服務集中於 `src/service/story/`，元件集中於 `src/components/story/`。

# 骰面稀有度

稀有度由角色能力對構築的影響、放大收益與取得頻率決定，同一角色跨地區維持分級。永久貼紙提供角色與食物能力，貼附時沿用目標面的固定點數；臨時貼紙提供單場零件。標籤「普通」與稀有度「一般」各自管理。

| 稀有度 | 角色                                                                                                                                           |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 一般   | 家族、姐妹花、雙胞胎、混混、孩子王、獨行俠、廚師、搬運工、跟班、啦啦隊、毛賊、膽小土人、侍衛、勇士、工匠、騎士、搗蛋鬼、農夫、好吃的、水果拼盤 |
| 稀有   | 耆老、祭司、老師、禁衛軍、權威、偽裝者、大胃王、巨盾、惡霸、號角手、警探                                                                       |
| 傳說   | 小公主                                                                                                                                         |

一般角色提供能通關的基本組合；稀有角色提供放大與轉型；小公主沿用第三區共同寶箱完成後保證一張、貴族包每包 5% 且最多取得兩張的特殊來源。一般獎勵依角色權重抽取：一般 4、稀有 1，小公主由專屬來源發放。角色權重由獎勵設定統一管理。

# 土人骰面角色與效果

骰面點數固定為 1～6。白板土人照點數攻擊，能力與身份標籤皆為空；白板與標籤「普通」分開判定。角色及食物貼紙覆蓋白板或既有角色後，沿用該面的點數。角色稀有度、身份標籤與材質各自管理。

## 土人家族

tag：普通

同骰每有 1 個土人家族面，本面攻擊力 +2，包含朝上本面。
若本回合受到外部攻擊加成，同骰每個其他土人家族面額外複製一次該加成

日文：土人、集まれば強い
英文：Clays Together Strong

## 土人姐妹花

tag：普通

當一名朝上的土人姐妹花得到外部攻擊加成時，其他朝上的土人姐妹花各獲得相同加成。

日文：おそろコーデ
英文：Sisterhood

## 土人雙胞胎

tag：普通

本面攻擊值改為同骰所有土人雙胞胎面中的最高骰值。
同骰每 2 個土人雙胞胎面組成一對，每對使本面額外攻擊一次

日文：入れ替わり
英文：Switcheroo

（一個雙胞胎只能加入一對）

### 儲糧

存糧綁骰並跨回合保留，勝利時乾糧袋保留全隊未用完的存糧供下場分配，戰鬥內存糧於結束後清空。朝上有效面為食物且同骰含有廚師時，依食物能力入庫；好吃的以食物強化完成後的攻擊力兩倍入庫，水果拼盤以自身攻擊力入庫；兩者各按同骰每個廚師面額外增加 2 存糧。水果拼盤保留鄰骰支援能力。全隊共享容量於鱷魚人篇為 150、地下篇為 200，依左至右順序入庫，超出容量的部分以可容納量為限。

廚師依自己的面數拆分該骰存糧，使用整數商與餘數分配，產生顆數最多等於存糧量。存糧 3、四個廚師面時產生三顆 1；存糧 10、三個廚師面時產生 4／3／3；零存糧產生零顆。釋放後清空，裝備返還的 20% 向下取整。乾糧分配、入庫取值與內部精度見[存糧與整數拆分](tribeling-resolution.md#存糧與整數拆分)。

# 結算規則與操作

共通取值、階段順序、跨回合狀態、再攻擊與追加骰依[土人結算規則](tribeling-resolution.md)。角色效果以上述能力為準，數值與玩家文案分別由角色平衡設定及說明設定管理。

骰面視窗可在戰鬥外及首次擲骰前直接拖曳整顆骰子，放開立即保存新順序，關閉視窗後保留。首次擲骰後至戰鬥結束期間保持檢視功能並停用自由拖曳。拖動採插入排序，選取、永久面、材質、臨時覆蓋與印記均跟隨骰子。

戰鬥技能說明保留玩家文案與內部結算規則的分工。能力依角色顯示完整文案，並列出當下符合數量、攻擊力、護盾、追加與再攻擊結果。啦啦隊的加油與各受益戰士產生的追加攻擊在同一技能節拍呈現，傷害依實際取得的加油加成顯示。
