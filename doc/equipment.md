# 裝備與構築

規格入口：[spec.md](spec.md)。裝備搭配[土人骰面](tribelings.md)，提供操骰、身分轉換、追加攻擊及資源運用。裝備清單、成本、加值及倍率統一由 [equipmentConfig.ts](../src/configs/equipment/equipmentConfig.ts) 管理；以下數字為可調整初版。

## 1. 裝備槽與效果呈現

裝備槽容量為 5 格，位於 board-body 左側；戰前、戰鬥、寶箱及商店共用同一組槽位。槽位寬高固定，高度不足時由裝備欄內部捲動。取得裝備時，空槽直接收納；滿槽時，玩家選擇一件舊裝備進行替換，舊裝備在替換完成時銷毀。取消替換會回到原本的獎勵或購買畫面，商店金幣在確認收納或替換後扣除。

寶箱裝備先將目標槽位捲入可見範圍，再從候選卡移動至目標空槽，抵達後寫入槽位並播放落槽回饋；滿槽替換時，移動終點為玩家選定的槽位，抵達後完成替換與寶箱獎勵。「返回寶箱選擇」取消替換並返回原本的三選一畫面；「跳過獎勵，繼續前進」則放棄整份寶箱獎勵、清除候選與待替換裝備，保留原有裝備及金幣並前進。裝備移動期間停用返回與跳過操作；商店替換畫面維持取消購買流程。

裝備依各自的條件與時機生效，涵蓋戰前準備、Control 操作、回合結算、敵人行動、購物與戰後獎勵。戰鬥預覽呈現目前結果下的轉化、支援、傷害、護盾與 Control 變化；重骰或換位後同步更新。裝備槽以文字與亮框呈現生效狀態，實際觸發時播放脈衝；操作成本、持有金錢等效果依據顯示於裝備資訊。

裝備 hover 沿用土人的效果亮框，依實際事件標亮受影響骰子；巨骨護身壁使本輪護盾預覽的藍色數字與盾牌圖示發光，護盾保留裝備使既有護盾數字與圖示發光。乾糧袋使用圖示加數字顯示本輪食物值，各骰入庫提示使用「乾糧袋圖示 + X」，hover 顯示裝備名稱與入庫量。分配事件由裝備發出。固定寬度的槽位顯示裝備圖示與主動能力短按鈕，完整名稱、技能與消耗顯示於槽位提示及按鈕可存取名稱。

## 2. 裝備結算

身分階段依序處理權威與備用皇冠，再處理雙胞胎及哨子的攻擊加成。支援階段先由農夫強化食物，再處理老虎機與角色支援；巨骨護身壁的護盾計入巨盾取值。追加攻擊成立後套用戰鼓共鳴箱，號角手結算後套用蓄勢徽章與沉著徽章，再完成啦啦隊取值及本體再攻擊。每次撞擊依敵人當下護盾判斷土人大錘加傷。

同一份鎖定結果的隨機選擇保持一致；支援、搶奪與裝備造成的正式前後值共同組成技能事件。裝備發動時，裝備槽顯示名稱與脈衝，受影響骰子同步回饋。

| 老虎機         | 支援開始時，選朝上基礎攻擊力出現最多的點數；平手隨機選一個值。符合的正常骰額外取得一份自身基礎攻擊力。                                                                                                             |
| 沉著徽章       | 本回合 Control 支出為 0 且未付費重骰時，正常與追加攻擊傷害乘 1.1。返還 Control 仍保留原支出紀錄，老師及連鎖重骰維持免費。                                                                                          |
| 蓄勢徽章       | 每剩餘 1 Control，使目前最終攻擊最高的一顆正常骰 +2；平手取最左側。於號角手後、沉著徽章與公主命令前選定並加傷。                                                                                                    |

蓄勢徽章的收益集中於一顆骰子，使保留 Control 有價值，同時避免每次重骰都損失整個骰池的加傷；加傷可由沉著徽章與公主命令繼續作用。

食物面照常攻擊，廚師另存基礎攻擊力與農夫、共鳴提供的食物強化，大胃王依份數取值。乾糧袋的虛擬食物只在下一場首回合有效；土人農夫將固定強化給予最近的朝上實體食物，等距選左；只有虛擬食物時維持土人農夫身分並強化該份虛擬食物，強化可疊加；份數維持 1，強化後的虛擬食物值只供本輪分配存糧，實體食物值供勝利時乾糧袋記錄。戰鬥中的廚師存糧依[共享容量與入庫順序](tribelings.md#存糧)累加，各骰分別持有與釋放；乾糧袋同樣使用全隊剩餘容量，戰鬥結束時清空。
