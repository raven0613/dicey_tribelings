# 裝備與構築

規格入口：[spec.md](spec.md)。裝備搭配[土人骰面](tribelings.md)，提供操骰、身分轉換、追加攻擊及資源運用。裝備清單、成本、加值及倍率統一由 [equipmentConfig.ts](../src/configs/equipment/equipmentConfig.ts) 管理；以下數字為可調整初版。

## 1. 裝備槽與效果呈現

裝備槽容量為 5 格。取得裝備時，空槽直接收納；滿槽時，玩家選擇一件舊裝備進行替換，舊裝備在替換完成時銷毀。取消替換會回到原本的獎勵或購買畫面，商店金幣在確認收納或替換後扣除。

寶箱裝備從候選卡移動至目標空槽，抵達後寫入槽位並播放落槽回饋；滿槽替換時，移動終點為玩家選定的槽位，抵達後完成替換與寶箱獎勵。「返回寶箱選擇」取消替換並返回原本的三選一畫面；「跳過獎勵，繼續前進」則放棄整份寶箱獎勵、清除候選與待替換裝備，保留原有裝備及金幣並前進。裝備移動期間停用返回與跳過操作；商店替換畫面維持取消購買流程。

裝備依各自的條件與時機生效，涵蓋戰前準備、Control 操作、回合結算、敵人行動、購物與戰後獎勵。戰鬥預覽呈現目前結果下的轉化、支援、傷害、護盾與 Control 變化；重骰或換位後同步更新。裝備槽以文字與亮框呈現生效狀態，實際觸發時播放脈衝；操作成本、持有金錢等效果依據顯示於裝備資訊。

## 2. 裝備結算

身分階段依序處理權威與備用皇冠，再取得雙胞胎及哨子的有效基礎值。支援階段先由農夫強化食物，再處理老虎機與角色支援；巨骨護身壁的護盾計入巨盾取值。追加攻擊成立後套用戰鼓共鳴箱，號角手結算後套用蓄勢徽章與沉著徽章，再登記公主命令。每次撞擊依敵人當下護盾判斷土人大錘加傷。

同一份鎖定結果的隨機選擇保持一致；支援、搶奪與裝備造成的正式前後值共同組成技能事件。裝備發動時，裝備槽顯示名稱與脈衝，受影響骰子同步回饋。

| 裝備 | 初版效果 |
| --- | --- |
| 土人隊形旗 | 每回合花 1 Control，交換一對相鄰骰子一次，兩骰保留原擲出結果。 |
| 代理王子哨子 | 每回合花 1 Control，保護一顆骰子一次；本回合免疫老師與搗蛋鬼的強制重骰，有效基礎值 +2。玩家仍可主動重骰與翻面。 |
| 長老煙斗 | 每場起始 Control +1。主動重骰的基礎值持平或下降時返還 1 Control，每回合一次；比較本次主動重骰前後，連鎖各步另行處理。 |
| 強力探照燈透鏡 | 花 2 Control，翻至指定骰子的幾何相對面。適用具有相對面的骰型；翻面作為定向操作，更新朝上結果。 |
| 土人算盤 | 結算時具備至少三種土人標籤，回合結束取得 1 Control。Control 回補上限為本場起始值 +2。 |
| 王子的存錢筒 | 開戰時金幣嚴格大於 50、100，各提供 1 點起始 Control。 |
| 黃金秤錘 | Control 為 0 時，每花 20 金幣可主動重骰一次，以持有金幣支付。 |
| 巨骨護身壁 | 每回合獲得 3 點額外護盾；全隊剩餘護盾完整延續至下一回合。 |

## 4. 攻擊、身分與跨戰鬥資源

| 裝備 | 初版效果 |
| --- | --- |
| 戰鼓共鳴箱 | 每顆已成立的追加攻擊骰傷害 +2。 |
| 備用乾糧袋 | 勝利時記錄本輪實體食物與仍有效虛擬食物的基礎值總和。下一場首回合提供一份等值虛擬食物，計入全隊食物數量，並讓每顆含廚師面的骰子各自儲存其數值；虛擬食物的作用為計數與儲糧。 |
| 王子的備用皇冠 | 身分階段，將基礎值最高的普通土人之普通標籤替換為貴族，持續本回合；最高值平手取最左側。 |
| 鱷魚皮錢袋 | 本回合發生成功搶奪時，結算取得 3～5 金幣一次。 |
| 土人大錘 | 每筆正常、追加及再攻擊撞擊前，敵人有護盾時，該筆完整傷害乘 1.2，再依共通傷害規則無條件進位；擊破護盾後的餘傷照常扣生命。 |
| 老虎機 | 支援開始時，選朝上有效基礎值出現最多的點數；平手隨機選一個值。符合的正常骰額外取得一份自身基礎攻擊。 |
| 沉著徽章 | 本回合 Control 支出為 0 時，正常與追加攻擊傷害乘 1.1。返還 Control 仍保留原支出紀錄。 |
| 蓄勢徽章 | 每剩餘 1 Control，使目前最終攻擊最高的一顆正常骰 +2；平手取最左側。於號角手後、沉著徽章與公主命令前選定並加傷。 |

蓄勢徽章的收益集中於一顆骰子，使保留 Control 有價值，同時避免每次重骰都損失整個骰池的加傷；加傷可由沉著徽章與公主命令繼續作用。

食物面照常攻擊，廚師另存其有效基礎值，大胃王依份數取值。乾糧袋的虛擬食物只在下一場首回合有效；土人農夫將固定強化給予最近的朝上實體食物，等距選左；只有虛擬食物時維持土人農夫身分並強化該份虛擬食物，強化可疊加；份數維持 1，強化後數值供本輪儲糧與勝利時乾糧袋記錄使用。戰鬥中的廚師儲糧隨回合累加，戰鬥結束時清空。
