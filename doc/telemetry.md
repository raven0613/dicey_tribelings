# 本機遊玩紀錄與統計

遊玩紀錄以獨立 service 收集已提交的遊戲狀態，透過 Dexie.js 保存於目前網站的 IndexedDB。第一版供開發者與測試者在本機檢視及匯出 JSON；國家欄位保留空值。統計以單局 Run 為單位，使用隨機 Run ID 串接資料，包含遊戲、平衡設定與資料格式版本。流派辨識、隊伍評價與成就屬後續功能。

## 保存與管理

本機保留最近 10 局，包含進行中與未完成紀錄；建立新局時，以開始時間移除超額的最舊紀錄及其全部明細。紀錄於關鍵操作與回合結果提交後陸續保存，頁面切至背景時補存計時。重新整理或關閉後，已保存的進行中紀錄呈現為未完成；紀錄用途為分析，遊戲續玩由遊戲存檔功能另行管理。儲存失敗在統計 panel 顯示原因，遊戲繼續運作。

歷史列表支援多選、全選、刪除選取紀錄及匯出選取紀錄，也可匯出單局。刪除與容量清理以整局為單位完成。遊戲原有主選單「重置紀錄」維持劇情及偏好設定用途，統計紀錄由統計 panel 管理。

## 紀錄內容與口徑

每局保存開始時間、最後紀錄時間、總經過毫秒、前景遊玩毫秒、平台、難度、內容範圍、抵達節點、路線與結果。前景時間包含劇情、戰鬥演出、獎勵及商店思考，頁面背景與視窗失焦的時間另由總經過時間反映。結果區分通關、死亡、回合上限失敗、主動重新開始及未完成。

完整配置快照保存每顆骰子的固定 ID、骰型、排列，以及每面的 ID、索引、永久角色與名稱、數值、材質、臨時貼紙與當場有效角色／基礎攻擊力；同時保存裝備、消耗品、HP／上限、護盾、金幣、Control、朝上骰面與存糧、祭壇、負片衰減及迴響狀態。開局、構築變更、戰前準備、首次擲骰、戰鬥結束及各級完成時建立快照。戰鬥的進場配置使用首次擲骰時已鎖定臨時貼紙的快照；死亡使用戰後清理臨時貼紙與狀態之前的配置。

角色組成以永久角色面數除以全部骰子的實際總面數，保存角色 ID、當時名稱、面數、總面數與百分比。不同骰型以實際面數共同計算。panel 以由多至少的水平長條圖呈現，臨時覆蓋另於骰池明細顯示。

每場戰鬥保存區域／節點／路線、敵人身分、進出場配置、耗時、回合摘要與結果。回合摘要收集正式結算輸出、實際造成的 HP／盾損失、承受 HP 傷害、護盾吸收量、有效治療、技能與材質觸發、追加與再攻擊數，以及結算前後的戰鬥狀態。死亡另保存致死階段、傷害來源、敵方招式與剩餘 HP；回合上限失敗單獨分類。

每顆骰子實際重骰一次計一次，包含老師與連鎖；初擲與定向翻面沿用各自操作。保存每場及整局重骰次數，平均每場次數以已結束戰鬥（勝利與失敗）的總重骰數除以場數，未完成戰鬥另列。預覽與演出更新共用已提交資料，事件按實際狀態變化計入一次。

裝備保存取得節點、來源、離開節點、替換裝備、持有毫秒與參與戰鬥數，並標示局末持有狀態。構築歷程以快照呈現骰面改造、取得新骰、排列與臨時貼紙變更。區域、篇章與目前發行內容的整局通關各自建立完成紀錄，保存累計時間及當時配置；目前六區鱷魚人篇末戰同時完成本篇及本次內容範圍的 Run，後續完整兩篇規劃依進程文件擴充。

## 隱藏入口與 panel

統計 panel 為獨立元件，只於主選單提供入口。遊戲視窗右下角設置約 20 × 20 CSS px 的隱形按鈕，第一次點擊啟用入口，第二次點擊才開啟 panel；兩次點擊使用同一區域，啟用狀態維持至開啟 panel 或離開主選單。按鈕保持透明，游標沿用一般游標。關閉 panel 後入口回到需要兩次點擊的狀態。

主選單同時支援 Shift + S 直接開啟 panel；輸入欄位、輸入法組字與長按重複事件沿用原本輸入行為。Esc 或關閉按鈕關閉 panel。面板包含歷史列表及構築、本局表現、歷程三個分頁，資料顯示取自同一紀錄 service。構築頁顯示角色面數長條圖、裝備與可展開骰池；表現頁呈現時間、重骰、戰鬥與完成／死亡資料；歷程頁呈現配置變化與裝備持有歷程。

## JSON 與實作邊界

JSON 匯出包含格式版本、匯出時間、單位定義與選取局的全部資料；名稱與穩定 ID 一起保存，百分比附面數與分母。進行中或未完成紀錄保留結果狀態，分析者可自行篩選。時間使用毫秒，時間戳使用 Unix epoch 毫秒，百分比使用 0 至 100。

服務集中於 `src/service/telemetry/`，元件集中於 `src/components/telemetry/`，容量、版本、快捷鍵與入口尺寸集中於 `src/configs/telemetryConfig.ts`。測試涵蓋組成計算、時間累計、重骰平均、配置隔離、裝備持有、勝敗與各級完成、容量及批次刪除／匯出等核心邏輯；介面透過型別、建置與程式審查驗證。
