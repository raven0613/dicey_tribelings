# 營火與單場祝福

第二、三區入口各提供營火／原有戰鬥二選一路線，於原本第二節點匯合。Boss 勝利先選新骰，再領戰利品；回血由玩家選擇補給取得。營火可直接離開，或從下列三項選一項後離開。

| 選擇 | 效果 |
| --- | --- |
| 免費休息 | 恢復 25 HP，以最大生命為上限 |
| 充分休養 | 花 20 金幣恢復至最大生命 |
| 領取祝福 | 免費領取當前顯示的單場 buff |

滿血時兩個回血按鈕維持正常亮度並顯示「生命已滿」，點擊保留選擇與金幣。付費休養在缺血且金幣不足時停用。

進入營火即等機率抽出一個祝福，名稱與完整效果立即公開。付費刷新依次為 3、6、9、12…金幣，每次只排除當前顯示的祝福；更早出現的可再次抽到。刷新只改候選，玩家仍能選回血。刷新次數於每個新營火重置，領取時直接取得畫面上的祝福。

| 祝福 | 單場效果 |
| --- | --- |
| 磨刃 | 前兩回合，每顆具有正值普通攻擊的正常骰攻擊 +2 |
| 先攻 | 第一回合，每顆正常骰的普通攻擊 ×1.3 |
| 護身 | 前兩回合，每回合獲得 5 點團隊護盾 |
| 凝神 | 下一場戰鬥起始 Control 與對應上限 +2 |

磨刃與先攻在角色及裝備能力完成後、敵人修正前套用，保留已生成的追加與再攻擊數值；攻擊歸零的骰子保持歸零。護身在巨盾土人讀取新生護盾前套用，參與新生護盾條件與正常的護盾保留規則。凝神沿用手動重骰、盯防與怒氣的規則。

祝福保留至下一場戰鬥，途中經過寶箱或商店仍有效；勝利、死亡或回合上限失敗時清除。祝福使用獨立狀態，戰鬥畫面顯示名稱與效果。數值、名稱及說明由 `src/configs/campConfig.ts` 管理，刷新價格由 `src/configs/refreshConfig.ts` 管理，入口路線由 `src/configs/regions/mapConfig.ts` 管理。

強度以短戰鬥收益為基準：四／五骰的磨刃最多增加 16／20 點普通攻擊，護身最多提供 10 點護盾，先攻依構築輸出成長；這些是選擇成本的比較，實際承傷與減傷仍依敵人規則結算。放棄入口戰鬥同時放棄該戰鬥的金幣與戰利品，營火提供恢復或短期助力。
