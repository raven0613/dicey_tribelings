# 鱷魚人與區域路線

規格入口：[spec.md](spec.md)。本文件管理本次開發的鱷魚人篇難度一、每區二選一路線、敵人機制、骰子里程碑與數值驗證。[地下篇與難度進程](progression-roadmap.md) 記錄後續開發範圍。

## 1. 篇章與完整通關

同一趟 Run 先完成鱷魚人篇，再繼承骰池、貼紙、裝備、生命及金幣進入地下篇。完成兩篇才算該難度完整通關並解鎖下一難度；下一難度重新養成。本次提供鱷魚人難度一，擊敗鱷文後顯示鱷魚人篇完成與目前內容邊界。地下篇、加工與難度二、三尚待開發。

## 2. 每區完整地圖與分岔

每個區域入場即顯示完整節點、連線、分岔及匯合點。節點常態僅顯示圖示與名稱，怪物名稱依階級套用 config 的一般灰白、菁英紫、首領金與終戰紅。滑鼠停留或鍵盤聚焦時，以浮動小窗顯示獎勵內容及 config 指定的機制名詞，例如「次數甲」「吞盾療傷」「命中成長」；寶箱、商店及補給包顯示各自提供的內容。戰場 Intent 負責呈現當輪數值與條件。階級色與機制名稱由 `monsterPresentationConfig.ts` 管理，每隻怪物在 `monsterConfig.ts` 的 `mapFeatures` 指定展示項目；小窗獎勵文案由 `mapPresentationConfig.ts` 讀取正式獎勵設定。

玩家完成共同節點後直接點擊可選的怪物節點決定路線。當前節點以外框標示，完成與放棄的節點淡化，圖示維持節點類型。未選路線保留於地圖，狀態在小窗呈現。選路只作用於當前合法分支；檢視其他節點的小窗沿用資訊查看。地圖在選路時保留已完成節點與當前資源。

前五區共同路線為「普通戰 → 普通戰 → 寶箱 → 二選一戰鬥 → 商店 → 普通戰 → Boss」；第六區為「普通戰 → 補給包 → 二選一戰鬥 → 最後商店 → 鱷文」。二選一為穩定路普通怪與挑戰路菁英，沿用階級獎勵差異。兩路步數相同並在商店匯合，每趟走 40 節點、28 場戰鬥。節點圖另外包含各區六個未必走到的分支節點，推進依明確連線。

| 區域 | 名稱 | 重點 |
| --- | --- | --- |
| 1 | 沼澤邊 | 初步組合、打斷與攻勢後反攻 |
| 2 | 爛水草泥道 | 護盾、鉤索與吞盾回血 |
| 3 | 水寨 | 次數甲、連擊與特殊準備 |
| 4 | 沈水荒地 | 大單擊、持續攻勢與命中成長 |
| 5 | 鱷魚人地城 | 無盾追擊、處刑與低血量狂暴 |
| 6 | 暗湧深牢 | 完整七骰與霸主三階段 |

四骰與五骰分別在第一、二區第二場普通戰後取得；六骰在第三區共同商店完成後取得；七骰在第五區首戰後取得。首區小公主在共同寶箱處理完成後發放。固定成長與保證角色由共同流程提供，兩路都能取得。新骰維持低值角色面，由後續貼紙提高品質。

## 3. 構築與恢復

普通戰展示構築成果；菁英及 Boss 在前段提出威脅。合理構築可以使用 Control、護盾、臨時貼紙與 HP 應對不利敵人；完整爆發以同輪白質約四倍為方向，與敵人弱點乘區分開記錄。多段構築以命中數、追傷連動和拆甲效率取得價值。

貼紙區域加值、金幣與治療沿用各自 config。挑戰路的菁英五選二與穩定路普通三選一形成專精收益差異；普通構築亦需能完成本篇。商店可反覆購買治療至生命上限，難度由戰鬥及補給間的承傷校準。

姐妹花至少兩名時，每名增加固定值及「自身基礎值 × 其他姐妹數 × 比例」。搬運工連續隊列由隊尾取得線性加值及隨隊友數平方增加的基礎值加成。工匠提高每個相鄰職人面的護盾，祭司提高每次目睹重骰的追傷；所有比例及固定值由 creatureBalanceConfig 管理。

## 4. 共通敵人結算

正常、追加及再攻擊逐筆結算，攻擊清單與傷害預覽共用正式敵人傷害計算。每回合記錄實際扣除的 HP／盾、命中數、追加命中數及最大單擊。零傷害與敵人死亡後的演出不提供命中計數。反射造成的實際扣血與扣盾計入受傷門檻，攻擊命中數由骰子攻擊提供。敵人死亡後保留剩餘骰子的追擊演出，停止反擊與後續敵方行動；雙方同時死亡判玩家敗北。

次數甲依剩餘層數降低每筆傷害，每次有效攻擊消耗一層；護甲層與數值護盾分別呈現。連擊破防使同回合後續攻擊受到的傷害增加，回合結束歸零。反擊架勢在該輪達命中門檻後反擊一次，護盾可吸收。所有次數及倍率均由怪物 config 管理。

敵人條件包括累計受傷、最大單擊、實際破盾與土人標籤數。追加攻擊可依招式降低打斷門檻。玩家無盾加傷在每筆敵人攻擊前判斷；敵人持盾加傷在行動時判斷。多段攻擊逐次扣盾與生命，首擊完整格擋可削弱後手。狂戰士每次造成玩家 HP 損失後增加後續攻擊；典獄長按已損失 HP 比例分段提高攻擊。

鉤索標記一顆骰子，下一輪該骰額外重骰可解除；未解除則敵方行動附帶拉扯，護盾照常吸收。封鎖保留下一回合初擲，禁止該回合的主動、老師、連鎖重骰與定向翻面，回合結束解除。目標與剩餘狀態在戰場公開。

吞盾消耗敵人自己的有限護盾並等量回血，受缺失生命與單次上限限制。藥劑回血採有限次數。暴露弱點使下一玩家回合攻擊增傷，完整格擋亦可取得攻勢後弱點。暈眩在實際破盾時觸發，跳過接下來一次敵方行動並推進招式。所有條件與預覽皆讀取同一套結算。

## 6. 驗證與設定來源

核心測試涵蓋分支可達性、選路一次性、兩路共同里程碑、逐段護甲與反擊、護盾條件、多段格擋、狂戰士命中成長、典獄長低血量成長、封鎖期限、鱷文門檻與階段，以及角色公式。完整 Run 模擬沿正式路線與正式戰鬥結算，分別檢查穩定及挑戰路。既有線性路線與舊角色公式的歷史勝率已失去比較前提，驗證以本次實際執行結果為準。

怪物數字、名稱、招式及機制由 `src/configs/monsters/` 管理；區域、路線與流程文字由 `src/configs/regions/` 管理；骰子與固定角色里程碑由各自 config 管理。測試讀取正式設定，檢查規則與結果關係。

### 本次驗證結果

核心測試共 130 項通過，涵蓋正式戰鬥結算與兩路共同里程碑；TypeScript 檢查與正式建置通過。輸出包絡每怪每情境 512 次，普通、菁英、Boss 與鱷文的典型擊殺回合中位數落在設定的 1～3、3～4、4～5 與 5～6 回合。弱輸出仍持續取得進展，典獄長典型／弱輸出中位數為 5／6 回合，鱷文為 6／8 回合。包絡拆成各區骰數的等值攻擊，承傷用於量測壓力；Control、角色配合、有限生命與補給由沿途模擬處理。

沿途模擬使用 `RUN_SIMULATION_CONFIG` 的種子起點 20260907，各策略 24 趟，共 96 趟；每趟固定選擇同類路線。策略使用有限 Control、12 次抽樣的局部構築評估，生命低於 40 時在商店購買治療，保留正式骰子里程碑與裝備。一般獎勵策略只選一般稀有度永久角色，仍可形成連鎖；全角色策略允許各稀有度。這些結果量測策略可達性及路線取捨，玩家通關率與熟練構築上限仍需實際遊玩評估。

| 獎勵策略 | 路線 | 抵達鱷文 | 完成鱷魚人篇 | 終戰前攻擊期望中位數 |
| --- | --- | --- | --- | --- |
| 全角色 | 穩定路 | 20／24 | 11／24 | 150.5 |
| 全角色 | 挑戰路 | 16／24 | 12／24 | 158.4 |
| 一般角色 | 穩定路 | 20／24 | 11／24 | 136.8 |
| 一般角色 | 挑戰路 | 14／24 | 11／24 | 154.4 |

攻擊期望以實際抵達終戰的構築取樣，包含裝備，採場外敵人無盾基準；此欄同時受存活者構築差異影響。穩定路較容易抵達終戰，挑戰路提供更多永久成長，但第三區水寨雙煞是明顯風險節點。後續實玩重點是玩家能否提前理解連擊格擋，以及是否有足夠選路資訊。

完整專精另採七骰、無裝備、無怪物弱點，所有骰子同時擲出第六區同角色基礎值 20 的情境。相同白質總和為 140；七名搬運工合計 512，為 3.66 倍；七名姐妹花合計 455，為 3.25 倍。這是指定骰面全命中的爆發案例，與沿途模擬的平均骰況各自記錄，顯示隊列及群體專精也能提供顯著上限。
