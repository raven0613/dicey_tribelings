# 怪物與關卡設計

鱷魚人篇依外圍、中間地帶、中心劃分為沼澤泥道、沈水荒地、鱷魚人地城。每條路線經過 20 個節點、12–14 場戰鬥；三處普通／菁英分岔共用後續商店。第二、三區入口各提供營火／戰鬥分岔，於下一節點匯合。地圖完整顯示，複數敵人從難度一出現，普通戰也包含主將帶小兵。水寨雙煞屬沈水荒地。

## 1. 敵人與回合規則

每回合選定一個主要敵人，點選肖像顯示準心，結算前可切換。每筆普通、追加與再攻擊依序攻擊目標；死亡後轉向畫面順序第一個存活敵人，單筆溢傷不轉移。命中、傷害、護盾與次數甲各敵獨立；玩家護盾共用，敵人依畫面順序行動。全部敵人死亡後，剩餘攻擊在最後擊敗的敵人身上完成演出，再進入勝利；同時死亡判玩家失敗。總攻擊預覽使用正式結算器的完整攻擊清單，包含溢傷與擊殺後的攻擊。

小兵使用獨立的低生命／低傷害配置，整組遭遇共用生命與攻擊預算。轉階段在回合交界發生，保持本回合預告；死亡敵人失去行動與來源狀態。

號令於本輪敵人行動全部完成後賦予其他存活同伴，下一回合每擊先加上號令值，再套用持盾與削弱倍率；該同伴下一回合行動結束時清除，防守或被打斷也會清除。多個號令取最高值。玩家文案使用「其他同伴下一回合傷害 +X」。

## 3. 構築與恢復

三區戰鬥分別以三、四、五骰調整；第六骰在篇章完成前取得，供未來地下篇延續。永久貼紙地區加值為 +2／+5／+8；配方骰加值為 +0／+2／+4。普通戰三選一，菁英與 Boss 五選二，跨區恢復由入口[營火](camps.md)的選擇提供。出發骰與 18 種道中配方見[配方骰](dice-drafts.md)。

一般戰目標約 2–3 回合、菁英 3–4、Boss 4–5、鱷文 5–6；這是調校目標，策略與骰運仍影響長度。敵人強度以整組遭遇衡量。僅水草浪人使用暴露弱點。輕重 debuff 互斥、震地／追蹤、攻擊蓄積條與環境持續傷害留待地下篇規劃。

## 4. 設定入口

地圖與分岔：`src/configs/regions/mapConfig.ts`；地圖圖示尺寸、非戰鬥節點主題色與小窗次要文字色：`src/configs/regions/mapPresentationConfig.ts`；敵人階級色與機制名稱：`src/configs/monsters/monsterPresentationConfig.ts`；區域成長：`regionConfig.ts`；怪物數值與招式：`src/configs/monsters/monsterConfig.ts`；正式回合與預覽：`src/service/battle/enemies/`；骰子配方：`src/configs/creatures/diceRecipeConfig.ts`。

## 5. 首版驗證

初始三骰窮舉 216 種結果，無裝備、無額外重骰的平均攻擊為 15，範圍 9–21。17 種路線遭遇以弱／標準／強三種輸出各跑 512 次：標準輸出的一般遭遇中位數 2–3 回合、菁英 3–4、水路鱷霸與水寨雙煞 5、鱷文 6。輸出包絡用高玩家生命測量耐久與承傷需求，完整 Run 模型另以正式生命、金幣、獎勵與補給驗證。

完整 Run 模擬使用正式生命、金幣、獎勵與補給規則，分別驗證入口戰鬥與營火路線。策略固定優先攻擊顯示順序第一個存活敵人，以短期攻防收益選擇貼附、裝備與重骰，商店優先恢復生命與購買裝備。固定種子各 24 趟的挑戰路／一般獎勵穩定路，在兩處入口選戰鬥時分別通關 7／5 趟，選營火時分別通關 13／10 趟。營火策略缺血時選免費恢復，滿血時領取當前祝福；模型尚未使用付費刷新與臨時貼紙。這些結果用來排除無法推進與資源死鎖，通關率及篇章時長以真人遊玩紀錄確認。

## 敵人外觀與戰鬥介面

戰鬥與戰前預覽共用 `src/configs/monsters/enemyAppearanceConfig.ts` 的外觀表，以穩定外觀 ID 對應圖片資源及個別怪物定義；目前所有敵人使用 `src/assets/enemy/01.png`。替換檔名時更新資源匯入，新增怪物外觀時設定定義 ID 的對應。角色尺寸、頭頂資訊間距、意圖框間距及受擊強度由 `enemyPresentationConfig.ts` 管理。受擊遮罩的顏色、淡出時間與最高不透明度分別由 `hit.flashColor`、`hit.flashMs` 與 `hit.flashOpacity` 設定。

角色直接呈現於場景中，圖片保持原比例；頭頂顯示名字、生命條、生命數字、護盾與階級。右側黑色對話框以切角和左側閃電尖角呈現招式，攻擊格式為「技能名稱：每擊傷害 × 段數 hit」，防禦顯示護盾量，蓄力與休息顯示名稱。戰前敵人摘要、完整行動、Boss 階段與技能說明共用「攻擊 每擊傷害 × 段數 hit」格式，單段攻擊也標示 `1 hit`；傷害加成與減傷沿用倍率寫法。技能細節、破解條件、特殊狀態與當前回合預估集中於共用說明浮層，桌面滑入及鍵盤聚焦可查看，手機點擊開啟、點外側關閉。

骰子攻擊及傷害浮字以圖片本體作為錨點。圖片受擊第一拍先向上震退，再以上下交替衰減的短促震動搭配小幅左右位移及輕微轉角，僅命中第一拍使用輕微壓縮並短暫閃亮，後續震動保持原始比例；逐次命中從目前姿勢接續；出手使用外層位移帶動圖片後撤蓄力、快速向下撞向骰盤、碰撞壓縮並微幅反彈，最後退回原位。頭頂資訊與意圖框維持原位，角色待機與蓄力時位於 back_2 與 back_3 之間；衝刺、碰撞與返回期間提升至前景上方、介面下方，使撞下的身體能覆蓋 front_ground，返回完成後恢復原圖層。資訊位於介面層。減少動態效果保留輕微閃亮與傷害數字。

敵人出手參數集中於 `src/configs/monsters/enemyStrikeConfig.ts`。`roles.byDefinition` 明確標示現有三種小兵，其餘預設主怪，角色姓名、圖片檔名與當前站位均獨立於身分判定；主怪倍率稍高於小兵。傷害力度採有上下限的平方根曲線，輸入正式結算事件的單擊傷害，包含力量、持盾倍率與削弱後的結果，護盾吸收與致命溢傷維持相同視覺力度。蓄力位移、衝刺伸展、撞入距離、微彈幅度與殘影透明度隨力度調整，各階段時長及速度線外觀也由同一 config 管理。
