# 怪物與關卡設計

> 版本：2026-09-07
>
> 規格入口：[spec.md](spec.md)

本文件管理六區救援路線、鱷魚人敵人、Intent、骰子里程碑、獎勵與成長校準。數字為集中配置的初版參數，驗證結果與體驗目標分開記錄。

## 1. 體驗與節奏

土人隊伍乘潛艇深入沼澤水底的鱷魚人地城，救回關在深牢的王子。前段擴充骰池，中段補齊組合，後段提升穩定度與爆發。玩家看懂 Intent，再決定投入 Control、追求傷害門檻或承受攻擊。

前五區各七節點：`普通戰 → 普通戰 → 寶箱 → 菁英 → 商店 → 普通戰 → Boss`。菁英獎勵後有商店補給與普通戰試用，Boss 驗證區域成果。

第六區五節點：`普通戰 → 貼紙包 → 菁英 → 最後商店 → 鱷魚王`。整趟 40 節點、28 場戰鬥，45～65 分鐘為待實機驗證的時間目標。地圖逐區展示當區節點與全程區域進度。

## 4. Intent 共通規則

每回合整池攻擊後確認敵人存活，再判斷 Intent 條件及執行效果。本回合受傷量包含實際扣除的護盾與 HP，每回合重新計數；每段攻擊只計入一次。敵人生命歸零後結束戰鬥。

Intent 由普攻、重擊、防禦、蓄力與喘息組成，一招最多一個條件。達傷害門檻可取消或減半；破盾條件在執行時讀取剩餘護盾為零，削弱該招。減半傷害向上取整。蓄力預告下一招；喘息讓玩家保留一輪準備空間。

招式執行或取消都前進一格，循環結束回到第一招。起始護盾戰前一次提供；防禦招式依循環提供護盾。剩餘護盾跨回合保留。預覽呈現完整數字與距離門檻，所有攻擊種類均參與受傷累計。

## 5. 第一區・沼澤邊

巡邏兵以普攻、蓄力與喘息建立閱讀習慣；投石兵以可打斷重擊教學，巡邏老兵在起手重擊提供減半門檻。大塊頭預告重擊，巡邏隊長驗證接近門檻時的 Control 選擇。

Boss：84 HP，起始盾 0。循環 `普攻 4 → 重擊 8（本回合受傷達 22 取消）→ 喘息`。

## 6. 第二區・蘆葦水道

撐船兵連續攻擊後喘息，魚叉兵以起始護盾與盾撞提供破盾回饋。巨盾兵檢查持續輸出，水道頭目安排護盾與喘息窗口。

Boss：130 HP，起始盾 20。循環 `普攻 5 → 盾撞 10（破盾減半）→ 獲得 12 盾 → 喘息`。

## 7. 第三區・水底城門

鐵盾兵與長槍兵分別教學防禦與預告強攻，長槍老兵在第二回合以重擊施壓，重甲兵結合破盾與打斷。守門隊長要求玩家安排破盾與傷害門檻。

Boss：230 HP，起始盾 30。循環 `普攻 6 → 獲得 20 盾 → 盾撞 14（破盾減半）→ 重擊 16（本回合受傷達 70 取消）→ 喘息`。

## 8. 第四區・地下兵營

雙刀兵、斧頭兵與斧兵隊長提高攻勢密度，以防禦和穩定輸出檢查構築弱點。鱷魚將軍有全程較密集的承傷壓力。

Boss：330 HP，起始盾 30。循環 `普攻 8 → 重斬 18（本回合受傷達 96 減半）→ 普攻 8 → 喘息`。

## 9. 第五區・地牢

看守、鐵甲兵與行刑官提供熟悉的防禦、預告與喘息。玩家將第十顆骰子納入分工，典獄長提供明確的阻止防禦與破盾選擇。

Boss：415 HP，起始盾 50。循環 `普攻 9 → 獲得 25 盾（本回合受傷達 122 取消）→ 盾撞 22（破盾減半）→ 喘息`。

## 10. 第六區・深牢

黑甲兵讓完整骰池展示火力，王家近衛檢查決戰前資源。鱷魚王使用熟悉的招式組合，完成救援；玩家可依構築火力提前擊殺。

Boss：580 HP，起始盾 80。循環 `普攻 10 → 獲得 40 盾 → 盾撞 22（破盾減半）→ 蓄力 → 重擊 28（本回合受傷達 150 減半）→ 喘息`。

## 11. 數值校準與驗證

一般戰鬥目標 2～3 回合、菁英 3～4、區域 Boss 4～5、最終 Boss 5～6，含擊殺回合。偏弱合理構築中位回合可比上限多兩回合。普通敵人耐久依其前段或後段位置校準；攻擊依玩家 HP、護盾與沿途恢復校準。

| 區域 | 普通耐久範圍 | 菁英起始耐久 |
| ---- | ------------ | ------------ |
| 1    | 20～38       | 60           |
| 2    | 45～75       | 100          |
| 3    | 85～135      | 175          |
| 4    | 140～190     | 250          |
| 5    | 180～240     | 330          |
| 6    | 225～280     | 420          |

耐久為 HP 加起始護盾，循環防禦另計。輸出包絡測試使用正式敵人結算、每回合 0.7～1.3 倍隨機波動，以及偏弱 0.7、典型 1、偏強 1.4 三種情境。無限 HP 模型記錄承傷暴露，完整 Run 模型另追蹤實際生命與護盾、獎勵選擇、裝備、Control 與每區輸出。

驗收包含：一般角色組合的通關能力、實際獎勵可達輸出、弱構築回復機會、固定加值能力的後期貢獻、臨時補組合收益，以及護盾循環的持續削血能力。模擬與實機體驗分別記錄，UI 驗證關注選獎勵負擔與固定節奏下十骰的可讀性。

### 11.1 首版程式驗證結果

2026-09-07：28 隻敵人 × 3 種輸出情境 × 512 次，共 43,008 場包絡模擬，全部符合對應中位回合目標與偏弱延長上限，護盾循環均能持續削減 HP。首三骰枚舉 216 種結果，零 Control、空裝備的平均輸出 10.81，範圍 8～18。

完整 Run 使用種子 20260907～20260930，分成全角色獎勵與只選一般獎勵兩組，共 48 趟。策略每次用 12 個獨立樣本比較可見貼紙的有限候選位置，按傷害與護盾期望選擇；開戰先使用當輪老師，再評估至多一次主動重骰；生命低於 40 時依持有金幣購買治療，裝備從實際寶箱與商店選取。兩組都保留固定里程碑骰與裝備，評估永久構築的通關能力，選牌評估與實戰亂數分離。臨時貼紙的配置、沿用基礎值與戰後還原由獨立核心測試驗證。

| Boss 前  | 全角色獎勵輸出中位數 | 只選一般獎勵輸出中位數 |
| -------- | -------------------- | ---------------------- |
| 沼澤邊   | 25.9                 | 25.9                   |
| 蘆葦水道 | 50.7                 | 47.3                   |
| 水底城門 | 108.8                | 104.9                  |
| 地下兵營 | 145.1                | 145.3                  |
| 地牢     | 202.5                | 191.1                  |
| 深牢     | 226.5                | 216.5                  |

上述輸出使用固定 1 Control、空起始儲糧、零敵盾評估，代表構築比較樣本。兩組各 24／24 通關，平均剩餘 HP 約 57、金幣約 389。結果支持可達成長與合法通關路線，並指出最佳化攻防策略的後期承傷與金幣消耗偏低。里程碑骰含指定稀有面，因此一般獎勵組代表「依靠一般獎勵成長」，全骰面一般的限制構築另作驗證。

真人通關率、臨時貼紙的使用意願、45～65 分鐘節奏，以及固定加值能力在後期的選擇價值，皆保留為實際遊玩檢查項目。後續依實測調整既有成長、敵人攻勢與補給參數。
