# 土人版裝備設計

規格入口：[spec.md](spec.md)。裝備的完整效果、初版數值、結算時機與槽位流程見[裝備與構築](equipment.md)，角色連鎖見[土人骰面](tribelings.md)。

骰子與貼紙決定角色、基礎值與連鎖；裝備提供操骰選擇與全隊規則。隊形旗讓相鄰與搬運隊列成為可調整的戰術，哨子與透鏡提供保護及定向控制，煙斗與算盤提供有限資源回補。金幣裝備讓保留資源與立即修正擲骰結果形成取捨。

皇冠串接普通與貴族構築；戰鼓、巨骨護身壁與大錘分別強化追加攻擊、護盾及破盾。乾糧袋將戰鬥結束時的食物數值帶到下一場首回合。沉著徽章獎勵本回合保留 Control，蓄勢徽章將剩餘 Control 轉成攻擊。

驗證重點為：取得裝備後是否改變貼紙配置或 Control 決策，以及玩家是否能從預覽和技能脈衝辨認裝備的實際貢獻。數值採集中可調的初版設定，以核心計算檢查資源成本、結算順序、疊加與跨回合邊界，再透過遊玩調整強度及節奏。
