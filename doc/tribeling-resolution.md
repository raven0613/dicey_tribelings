# 土人結算規則

規格入口：[spec.md](spec.md)。玩家能力文案由[土人骰面](tribelings.md)管理，本文件管理取值、順序與狀態生命週期；內部說明與 UI 文案分開維護。

## 點數、基礎攻擊與外部加成

骰面點數是固定的 1～6，貼紙改變角色或食物，點數保持原值。基礎攻擊力由點數、有效材質及加工中明定的基礎修正決定；當前攻擊力包含本回合已完成的能力與裝備加成。能力明寫骰值時讀固定點數，明寫基礎攻擊力時讀取能力前的基礎值，明寫目前或最終攻擊力時讀取對應結算階段的結果。攻擊變化與固定點數分開呈現。

白板照點數攻擊，能力與身份標籤皆為空。普通、戰士、職人、貴族、神秘及食物的計數依有效身份判定。耆老作用於其他朝上且有身份的土人，計算受益骰內所有同名面，包含朝上本面；四面家族獲得 +8、兩面勇士獲得 +4。

家族依同骰家族面數取得每面 +2 攻擊力，包含朝上本面；每筆外部攻擊加成，再依其他家族面數各複製一次。禁衛軍每筆外部加成依同骰其他貴族面數額外取得相同份數，同一次加成一回合只因本技能重現一輪；其他貴族三面、外部 +2 時，原始及複製共 +8。自身能力所生的複製加成在這一輪完成。

姐妹花自身取得原始外部攻擊加成，再把該加成值的 3 倍分享給其他朝上姐妹花；全隊加成落到每名姐妹花時各分享一次。每筆外部加成完成一輪分享，分享所得直接計入本輪攻擊力，後續效果依其取值時機使用已完成結果。三名姐妹花各收到外部 +2 時，各取得原始 +2 與另外兩名分享的 +6，共 +14，合計 +42。

雙胞胎先以同骰最高雙胞胎骰值建立本體攻擊，後續加成照常作用。同骰每兩面組成一對，面數 2／4／6 分別提供 1／2／3 次本體再攻擊。獨行俠同骰只有一面時以骰值兩倍建立攻擊；本回合收到外部加成且攻擊為場上最高時再攻擊一次，並列最高成立。

搬運工由左至右接力，每名累加同一連線前方所有搬運工已完成的攻擊值。跟班保留自身骰值，再加入左右朝上勇士中目前攻擊最高者的指定比例；同骰其他跟班每面使比例增加 15%。勇士依鄰骰全部跟班面數取得固定加值，再依朝上跟班套倍率。支援完成後依序處理勇士、跟班及搬運工；勇士兩側各有朝上跟班時，兩份 +100% 相加為三倍。號角手在後段發放的加成直接作用於各骰。

## 精度與畫面

遊戲畫面上的攻擊、加成差值、護盾、生命與存糧均以整數呈現。攻擊倍率計算沿用內部小數點後兩位精度，每筆撞擊套完敵人修正後向上取整；顯示與總傷害使用正式取整結果。孩子王取得量先向上取整。玩家獲盾、回血及跨回合保留護盾向上取整；敵人每段攻擊套完加成與倍率後向下取整，再扣護盾與生命。

存糧、廚師拆分與裝備返還維持整數。拆分總量等於實際釋放量，返還 20% 向下取整；預覽與正式結算共用同一結果。食物完成入庫前攻擊加成及存糧倍率後，入庫總量向上取整一次。最高攻擊拆分同樣先將總量向上取整，再以整數商及餘數分配。

## 重骰、犧牲與身分

搗蛋鬼以真正重骰前的角色判定，發動時使左右所有合法鄰骰重骰；白板與食物沿合法目標規則處理，保護及封印保持有效。每顆骰子每回合最多發動一次搗蛋鬼能力，被其他搗蛋鬼影響的重骰次數另行記錄。第二顆發動後，第三顆若在被重骰前也是搗蛋鬼且尚未發動，可使第二、第四顆重骰；第二顆的技能使用紀錄保留。新擲出搗蛋鬼時，於之後再次被重骰才判定觸發。傳承讀取被影響者重骰前的基礎攻擊力 50%，加給新擲出的土人。

所有實際重骰排除當下朝上的骰面索引，從其餘五面等機率抽取；其他面可以具有同名角色。初擲使用全部六面。方向貼紙的翻動仍屬該次操作落定，依[方向規則](directional-stickers.md)處理。

含有效祭司配置的骰子保存自己的犧牲；每次實際重骰增加一次，初擲與定向翻面沿原計數規則處理。犧牲跨回合保留。結算時朝上祭司每次犧牲為每名朝上祭司產生一顆追加骰，每顆傷害取發動祭司本面的骰值；全部祭司依各自犧牲與骰值處理。祭司結算釋放後清空本骰犧牲，戰鬥結束清空剩餘犧牲。

老師成功重骰的加成依該次操作完成時全隊實際重骰累計次數計算，包含本次；目標再被改面時移除該次加成。老師資格於初擲建立，使用後消耗；偽裝者切換離開老師時暫停尚存資格，恢復老師身分時可使用剩餘資格，實際重骰或翻面該骰時清除資格。

偽裝者於初擲、每次實際重骰落定及定向翻面後，使用同一份未偽裝的有效朝上骰面重新判定。場上與自身骰內候選均由其他有身份土人或食物組成；最高數量大於一時取並列最多者，場上最高數量至多一時改看自身骰內，仍至多一時維持偽裝者。候選改變時等機率重選，相同時沿用結果；保留自身點數、材質及骰面版本。

身分變動更新當前能力與關係，重骰次數與犧牲由實際重骰累計。權威為相鄰普通土人增加貴族身份，原普通身份保留；騎士左右朝上鄰骰均有普通標籤時取得貴族身份。已使用的搗蛋鬼、膽小護盾、老師與迴響紀錄依各自生命週期保存。

## 存糧與整數拆分

食物強化先於存糧入庫。農夫沿同骰農夫與食物面總數增加最近食物攻擊，等距取左；多名農夫依序強化，可作用於同一份食物。好吃的以強化後攻擊的兩倍入庫，水果拼盤以自身攻擊力入庫，再各按同骰每個廚師面額外增加 2 存糧。例如好吃的基礎 4、農夫 +3、同骰一個廚師面，入庫 16。水果拼盤維持鄰骰支援。大胃王讀取朝上食物所屬骰子全部有效食物面的基礎攻擊力總和，農夫尚未轉成食物的面維持農夫身份。

存糧綁骰、跨回合保留並於戰鬥結束清空。全隊共享容量為鱷魚人篇 150、地下篇 200，各骰由左至右入庫至可容納量。乾糧袋於下一場首次擲骰前，依有效配置中含廚師面的骰子平均分配初始存糧；整數餘量由左至右分配，總量受本場共享容量限制。回合結算時食物先入庫，再由朝上的廚師釋放。勝利時乾糧袋保存釋放及返還完成後的剩餘存糧總量。

設存糧為 S、同骰廚師面數為 C。S 為零時產生零顆；S 為正時產生 min(S, C) 顆，以整數商均分，餘數依生成順序各加一點。例如 S=10、C=3，產生 4／3／3；S=3、C=4，產生 1／1／1。釋放全量後清空，有返還裝備時取得 floor(S×20%) 存糧；返還仍占共享容量。乾糧也以整數商與餘數由左至右分配。

## 搶奪、護盾與攻擊清單

孩子王依回合初擲種子、來源骰 ID 與面版本建立其他骰子的固定隨機優先順序，由左至右選擇另一名攻擊大於零、具有普通標籤且尚未被孩子王搶過的土人。來源重骰或定向翻面更新順序，其他骰子變動時沿原順序重判合法目標。孩子王可互搶，被搶歸零者仍可執行搶奪。第 n 次成功搶奪取得目標攻擊的 1＋0.2n 倍，次數包含本次。

惡霸依左右順序向鄰骰取走一半攻擊，對一般目標取得該份保護費 1.5 倍；職人目標取得 2.5 倍，且多計一次搶奪事件。對方均扣除原攻擊的一半。毛賊每次成功搶奪產生一顆追加骰，傷害為自身骰內全部毛賊基礎攻擊力總和，被搶歸零仍可發動。

警探對每名成功搶奪者共同沒收一次目前攻擊，形成一份沒收池；每名警探各取得該池的 1.2 倍。沒收屬獨立事件，搶奪計數保留原值。

侍衛依符合普通或貴族身份的人數提供護盾，同一人具有兩種身份時算一人。工匠依相鄰職人面提供護盾，相鄰工匠另加該面骰值。巨盾依全隊本回合新增護盾總量產生追加攻擊，再按獲盾事件數各加一次自身基礎攻擊；既有保留護盾屬前回合資源。一個獨立技能、角色或裝備的一次獲盾算一個事件，技能內逐面累加合併為該次獲盾。巨盾保留原護盾。

啦啦隊以同骰啦啦隊面數替各朝上戰士加攻，每名受益戰士產生一顆追加骰，傷害等於該次加油實際給他的攻擊加成，包含家族或禁衛軍等適用的加成放大。號角手按每批新生成的追加骰數量給全隊加攻，每顆對應 +1；每名朝上號角手另使各追加骰 +1 傷害。每顆追加骰對各號角手的兩種收益各計一次，多名號角手效果疊加。

雙胞胎、獨行俠與公主命令建立本體再攻擊，使用各自規則所取的攻擊快照；再攻擊只執行本體攻擊。小公主以零建立本體攻擊，之後照常取得外部加成；每名公主命令自己以外、當下攻擊大於零的貴族再攻擊一次。多名公主各自排除自己，其他公主符合條件時也接受命令。本體再攻擊與追加骰分開計數，只有追加骰參與號角手數量。

## 追加骰批次、吸收與拆分

追加骰以來源效果的生成批次建立，每顆保存來源、原始傷害、目前傷害、已套用增傷與吸收狀態。各批先完成適用的低傷分裂與首批追加複製，再各取得一次戰鼓及每名朝上號角手的追加增傷。號角手按該批新生成的顆數給全隊外部攻擊加成，並完成家族、姐妹花、禁衛軍等相關連鎖。低傷分裂只讀生成時原始傷害；首批追加複製使用每場首次來源批次紀錄，後續批次依剩餘可用效果處理。

主動追加吸收在原追加骰完成增傷後執行，讀取當時仍存在追加骰的目前傷害總和，以一筆外部攻擊加成交給玩家指定的正常骰，並消耗這批追加骰。先前已給出的號角手全隊加攻保留。吸收造成的外部加成放大與分享完成後，再執行最高攻擊拆分；尚保有本體攻擊的土人依最終結果判定再攻擊。

最高攻擊拆分讀取轉換時點的最高攻擊值，建立一批新的追加骰，原本體本回合的普通與再攻擊交由這批骰執行。新批次依自身原始傷害完成分裂與可用的首批複製，再套用戰鼓與號角手。號角手依新批次顆數發放新一輪全隊加攻，已轉換的本體維持零攻擊及已交出攻擊的狀態，其餘本體依各自能力取得加成。

吸收與最高攻擊拆分每回合各執行一次。每顆追加骰的戰鼓及各號角手增傷各套用一次，吸收後建立的新骰使用新的生成紀錄。轉換後完成的追加骰進入攻擊清單，正式撞擊時再套用敵人修正與撞擊裝備。

例如一位號角手與戰鼓在場，指定本體在本批號角手加成前為 20 攻擊，原批次為兩顆原始傷害 4 的追加骰，且其他效果收益為零：兩顆各取得戰鼓 +2、號角手 +1，成為 7／7；號角手使本體 20 → 22，吸收後 22 → 36；最高攻擊拆分產生 12／12／12，三顆新骰各取得 +2、+1，成為 15／15／15，號角手另向全隊發放 +3。該本體以轉換後的追加骰合計 45 傷害執行本回合攻擊，其餘本體取得各自適用的全隊加成。

## 結算順序

1. 完成初擲、Control、老師與搗蛋鬼連鎖，保存重骰次數、犧牲、護盾、首次重骰記憶、落差追傷、老師加成及傳承，並依實際重骰更新靜候蓄力層數。
2. 依最新結果處理偽裝、農夫轉化、權威、裝備身分與騎士資格，記錄實際身份變化供冊封禮炮使用。
3. 建立角色攻擊取值，處理支援、首次重骰記憶、靜候蓄力、食物強化、護盾、外部加成複製及同骰與鄰骰關係。搬運工接力與勇士／跟班依已完成的來源結果取值。
4. 食物入庫、廚師釋放及其他角色產生追加骰。每筆來源加成的放大先完成，再以正式取得量決定啦啦隊追加傷害。
5. 由左至右執行搶奪，毛賊依成功次數產生追加骰，警探共同沒收後各自取得加成。先前成立的護盾與追加攻擊保留。
6. 巨盾依本回合獲盾產生追加骰；原追加骰各批依生成規則完成分裂、複製、戰鼓及號角手增傷與全隊加攻，再套用後段本體裝備加成。
7. 有指定吸收目標時，將已加成的追加骰傷害總和轉入本體，完成外部加成放大與分享；最高攻擊拆分隨後選定目標，產生新追加骰並完成該批適用的分裂、複製與增傷。
8. 完成後段追加骰帶來的全隊加成與連鎖，依各骰的攻擊資格判定獨行俠及本體再攻擊，建立正常、追加、再攻擊清單。磨刃與先攻沿[營火規則](camps.md)於清單建立後修正普通攻擊。
9. 依攻擊清單執行，逐筆套用本體連擊、撞擊裝備與敵人修正後取整。提交存糧、犧牲與每場裝備狀態；回合結束依重骰紀錄累積靜候蓄力，再清除回合紀錄。戰鬥結束清空蓄力層數。

## 取值與生命週期

權威共用整輪冊封開始前的貴族名單，依其中其他貴族數加攻。農夫轉化開始時一次判斷朝上食物是否存在，當時缺少食物則全部農夫轉化。食物份數、農夫支援與大胃王加成以朝上的有效食物面判定；乾糧袋的初始存糧沿廚師釋放規則使用。

百分比外部加成先求出實際增加量，再交給家族、姐妹花及禁衛軍依單輪規則複製。共振屬外部加成，金箔與負片屬有效基礎值；磨刃與先攻沿營火規則於清單建立後作用於普通攻擊。迴響重現當次技能的同一份取值，每次重現各自完成適用的外部連鎖。權威迴響以相同冊封前名單再次加攻；搗蛋鬼迴響在原連鎖完成後，對原合法鄰骰再重骰一輪，來源能力的本回合使用紀錄持續有效。

搗蛋鬼傳承、老師加成與首次重骰記憶綁定該次落定面；再次重骰或定向翻面先清除舊加成，再依當次操作取得新加成。首次重骰的裝備使用紀錄保存至回合結束。沉著徽章在吸收、拆分與再攻擊清單建立後，對每筆最終攻擊套用一次倍率。

本體未攻擊追傷於原追加骰批次開始前判定當時攻擊為零的本體，每骰產生一次追加骰。冊封禮炮記錄初擲落定後的有效身份變動，每次實際重骰、翻面與能力造成的標籤集合變化各觸發一次；同一集合保持原值時沿用原紀錄。

最高攻擊拆分由玩家每回合免費切換啟用，回合開始為關閉。結算時選取吸收及相關加成完成後攻擊最高的本體，平手取最左側。操作階段可切換並即時預覽，正式結算後鎖定。

## 驗證

核心驗證涵蓋固定點數與基礎值分離、白板身份、各角色新能力、同名面數、外部加成單輪重現、姐妹花分享、警探各取完整沒收池、搗蛋鬼每來源骰一次與可重複受影響、犧牲跨回合、整數存糧拆分／返還、追加與再攻擊分流，Control 支付與獲盾事件、材質及加工基礎值的重骰差額、首次重骰記憶、蓄力層數生命週期、吸收外部加成、吸收後再攻擊、拆分者攻擊資格、兩批追加骰的增傷各計一次，以及預覽純計算、正式結算提交一次。構築強度連同取得成本、自然骰到機率與 Control 決策驗證，完整 Run 結果集中於[怪物與關卡設計](monsters-and-regions.md#5-新版驗證)。

## 複數敵人與手動操作

敵人以獨立實例保存 HP、護盾、次數甲、命中數、當輪傷害、Intent 與階段。每輪選定主要目標；普通、追加、再攻擊逐筆執行，目標死亡後轉向顯示順序第一個存活敵人，溢傷留在原命中。最後一名敵人死亡後，後續攻擊沿用最後擊敗的目標及其防禦倍率計算傷害並完成演出，敵人生命、護盾、次數甲與命中紀錄維持擊殺時的結果；總攻擊包含整份清單的傷害。敵人依顯示順序共用玩家剩餘護盾，命中及傷害門檻各自累計；新生護盾條件讀取當輪玩家收益快照，與敵方扣盾順序無關。

手動重骰次數與實際骰子重骰次數分開記錄。玩家選擇的 Control、金幣與老師操作各記一次手動重骰；後續搗蛋鬼連鎖僅增加實際重骰數。盯防在每回合初擲選取朝上基礎值最高的骰子，隨後轉移到玩家剛主動重骰的骰子；重骰原目標時繼續盯防該骰，自動連鎖維持手動操作選定的目標。盯防僅減半該骰普通攻擊，當輪結束清除；典獄長將手動次數累計至跨輪怒氣，達標後排定下一輪猛攻，猛攻輪不重複累積，結束後歸零。封骰與鉤索綁定來源敵人；來源死亡即停止作用。
