# 出發骰、道中配方與刷新

規格入口：[spec.md](spec.md)。每顆骰子使用各一面的固定 1～6 點 d6，角色配置與幾何位置共同形成配方。角色、食物與白板均保留其所在面的點數；各區的成長由新增骰子、貼紙配置與連鎖提供。

## 出發骰

第一版身份沿用「護衛遠征隊」，三顆骰子依同伴、前鋒、援護順序排列。每顆出發骰有兩面角色或食物、四面白板，合計六面既有角色與十二面白板。白板照點數攻擊，能力與身份標籤皆為空。同伴骰在 3 點配置家族、4 點配置混混；前鋒骰在 1 點配置水果拼盤、4 點配置勇士；援護骰在 2 點配置跟班、3 點配置膽小土人。相對面為 1／6、2／5、3／4。

起始少數角色面應提供可理解的啟動方向，戰利品再提高配合、穩定性與上限。起始金幣及早期供給見[貼紙獎勵與經濟](rewards-and-economy.md)。

## Boss 白板骰

每次 Boss 勝利固定取得一顆六面白板骰，六面點數各為 1～6，初始材質為普通材質。新骰立即加入骰池，先以獨立畫面展示「獲得新骰子」與六面配置，玩家按「繼續」後才顯示三張主題包的三選一。第一區戰鬥使用三骰、第二區四骰、第三區五骰；第三區 Boss 後取得第六骰，供地下篇延續。新骰的六個面均可在後續貼紙流程中配置。

白板骰與配方骰共用骰子建立及固定點數規則，每顆新骰建立獨立骰子與骰面 ID。Boss 白板骰展示與配方骰選擇共用先取得新骰、再處理貼紙的順序。

## 道中配方

配方設定、抽選、建立骰子、選擇預覽與付費刷新接口保留，供配方骰來源使用。每顆配方骰有三面角色或食物與三面白板；候選顯示完整六面，可開啟共用展開圖檢視能力及相鄰關係。已取得的配方仍可再次出現。

## 付費刷新

每次刷新只排除刷新前仍顯示的候選種類。初次抽取使用完整合法池，第二次刷新可回到初次的選項；已持有、曾顯示與曾領取的種類在後續合法抽取中保持可用。同一畫面的配方種類、一般戰明牌角色、主題包種類或裝備各自唯一。

配方骰、戰利品、商店各自記錄本次畫面刷新次數，每次新獎勵或新商店歸零。第 n 次價格：配方骰 8n、戰利品 6n、商店 8n 金幣，皆由 config 管理。付款與換頁同時成立；金幣不足維持原狀。戰利品在選定組合前可刷新整組候選，選定後依領取內容完成貼附。黑市額外稀有獎勵獨立領取，不參與一般刷新。商店刷新永久單張、貼紙包、臨時貼紙與裝備，回血服務保持固定。

配方骰、戰利品、商店與[營火祝福](camps.md)共用付費刷新計價與按鈕，以刷新圖示、高對比底色與邊框顯示本次金幣價格，旁邊呈現持有金幣。金幣不足時保留按鈕與價格，以停用樣式及「金幣不足」文字說明原因；可用時提供懸停與鍵盤聚焦回饋。商店刷新位於固定頂部操作列，戰利品與選骰刷新位於固定底部操作列，候選內容在各自區域內捲動，操作列依可用寬度換行。

## 驗證範圍

檢查每骰點數恰為 1～6、出發兩個角色／食物面、Boss 六面白板、配方三個角色／食物面、白板身份、幾何關係、重複取得的獨立性、Boss 新骰展示先於貼紙選擇與刷新交易。以白板新骰及新版貼紙供給驗證啟動機率、半成形收益、Control 使用及完整 Run 資源；25～30 分鐘為鱷魚人篇遊玩目標，待真人遊玩驗證。
