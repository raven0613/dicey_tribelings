# 前景動態系統

本文件由 [介面與資訊規則](spec.md#23-介面與資訊規則)與[場景背景](backgrounds.md)導流。系統只承接玩家受到敵人的實際命中，護盾吸收亦觸發，零傷害事件保持靜止。Zustand 直接訂閱逐次 impact，讓同一幀的連續命中都能注入衝擊；recoil、其他狀態更新及玩家打怪物的事件保留既有前景狀態。

## 配置與單位

`src/configs/backgrounds/foregroundMotionConfig.ts` 定義模擬步長、停止門檻、重擊倍率、ground 彈簧、石頭重力與碰撞、網格密度及畫布解析度上限。`swampMotionConfig.ts` 定義每叢草與每張懸掛素材的參數，`swampConfig.ts` 在對應素材上引用。其他場景沿用同一套型別、計算與渲染器。

彈簧 frequency 使用 Hz，dampingRatio 介於 0 與 1，impulse 使用設計單位／秒，maxDisplacement 使用設計單位。草叢 gain 控制受力大小，direction 指定彎曲方向向量，rootX 與 rootRadius 使用相對於草叢左側的設計單位；rootBand 是底部固定帶的高度比例，spread 控制向側方伸展的葉片對根部距離的敏感度。草的頂部及側方共用整叢變形場，每片保留原圖與目前 localX。每張 vine、beard 的 pivotX 使用原始 PNG 左緣起算的像素，固定點 y 為頂部 0，swing 控制整體擺動與柔性彎曲的比例。

stone 由 props 的 motion 設為 stone 啟用。向下為正，ground 動態位移視為石頭的接觸面偏移；地面下沉時石頭自然離地，受重力下落，接觸地面後依相對速度做微小回彈。最大離地距離限制石頭與地面的分離幅度。回到靜止後 transform 歸零，原有 x 與基準線保持原值。地面圖片底部以原圖底列延伸震動範圍，向上回彈時仍覆蓋場地底邊。

## 計算與生命週期

前景的數值狀態屬於獨立控制器，React 負責掛載與清理，每幀沿用現有陣列與 DOM 參考。阻尼彈簧使用解析解推進，新命中先推進至當下時間再注入速度，依能量上限限制位移。石頭以有限小步長處理移動地面的接觸。長時間背景分頁後從靜止姿勢恢復，避免補播過期效果。

草與懸掛素材使用單一 WebGL 畫布，材質建立一次，網格保留 UV 與靜止座標，只有頂點位置在動畫時更新。繪製順序為懸掛素材、由後至前的草叢、株內葉片原有順序；DOM ground 位於畫布前方，props 位於後方。資源失效時回到既有靜態圖片，恢復時重新載入，卸載釋放動畫、訂閱、紋理及緩衝區。

核心測試涵蓋固定根部與懸掛點、曲線及側向變形、連擊位置連續和速度追加、能量與落地距離限制、逐步收斂與重設，以及命中事件去重。UI 與畫面效果由使用者手動開啟遊戲檢視。
