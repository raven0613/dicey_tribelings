# 特殊材質骰面

每面最多一種材質，與角色稀有度分開顯示。材質附著於永久骰面；永久貼紙完整替換角色、基礎攻擊力與材質。戰前臨時貼紙只更換角色，沿用原材質與基礎攻擊力。新增骰子的初始面使用普通材質。骰子加工與工坊保留於後續開發範圍。

## 效果與時機

材質原則上在該面朝上時生效。[箭頭貼紙](directional-stickers.md)覆蓋期間暫停來源面的材質，翻面後使用目的面的材質，戰後恢復來源永久面。亮金箔與負片直接修正該面的基礎攻擊力，供自身攻擊與其他角色讀取同骰、鄰骰配置使用。共鳴在角色結算前提供相鄰朝上骰的攻擊加成，食物同時增加可儲存的食物值；震盪與漣漪在號角手與巨盾取值前結算。血瓶在回合結算時回復生命；發動骰同步播放紅白色向上脈衝與「♥ +效果數值」上飄淡出，亮度沿用結算技能脈衝。生命顯示配合血瓶演出更新並受生命上限限制，浮字始終顯示設定的效果量。

| 材質           | 效果                                                                                                                         |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 鏡面           | 每次敵人攻擊造成實際生命損失後，反射 3 傷害；完全由護盾吸收時收益為零。                                                      |
| 共鳴           | 左右鄰骰的朝上面本回合攻擊力各 +2。                                                                                          |
| 震盪           | 結算產生一顆 2 點追加攻擊骰，參與追加攻擊加成與號角手計數。                                                                  |
| 血瓶           | 朝上結算回復 2 HP，最高為生命上限。                                                                                          |
| 漣漪           | 朝上結算獲得 4 護盾，計入本回合全隊獲盾。                                                                                    |
| 金色脆閃       | 本場朝上結算過的每個來源面，勝利額外獲得 3 金幣，每面每場一次。                                                              |
| 亮金箔         | 該面有效基礎攻擊力 +3。                                                                                                      |
| 負片           | 平時基礎攻擊力 +5；每次朝上結算後扣 2，可扣至原始基礎攻擊力歸零，下場恢復原始值 +5。例如原始 4：9 → 7 → 5 → 3 → 1 → 0。      |
| 虹彩（超稀有） | 本面角色擁有全部標籤，身分轉換後仍保有所有標籤，包含食物與存糧判定。                                                         |
| 迴響（超稀有） | 每面每場首次成功發動自身角色能力時，額外重現一次效果，資源支付一次。額外效果沿用該次已確定的效果與來源，迴響本身只使用一次。 |

迴響以同一來源面的一次完整角色能力為單位，跨階段加攻、倍率、所有合法目標、存糧、追加與再攻擊皆於對應階段重現；重現事件獨立顯示「迴響：技能名」。同面每場消耗一次，預覽保留純計算，正式操作或結算才提交。

好吃的首次成功存糧再存一次，水果拼盤的鄰骰強化與自身存糧同屬一次能力，各次入庫沿用全隊剩餘容量。農夫轉為食物時，迴響另加一份自身基礎值至攻擊與食物值，食物數量仍算一份，之後依強化後食物值入庫；強化已有食物時對同一目標強化兩次。權威首次有合法目標即一次用完迴響，另一名合法鄰骰存在時追加冊封；兩次冊封皆沿用發動前貴族數判定加攻門檻。

廚師釋放只結算一次存糧消耗與保留量。老師實際使用後提供第二次免費重骰機會，第一次結果落定後可重新選擇合法目標；搗蛋鬼額外觸發一次鄰骰重骰。額外操作完成後，角色維持原本的次數限制。身分改變與重骰沿用來源面本場已消耗的迴響紀錄。祭司以釋放時朝上的來源面判定迴響，重現該次追加攻擊並只清空一次祭壇；尚未釋放的祭壇綁骰保存。

## 取得流程

一般戰鬥三選一、菁英與 Boss 五選二，以及每個貼紙包，都先以整組為單位抽取：95% 普通、4% 一般材質、1% 超稀有材質，再產生內容。特殊組別在其中一張永久貼紙上附加該組別的一種材質，其餘維持普通。角色稀有度、貼紙包 Jackpot 與小公主取得規則沿用既有設定；材質僅附加於該組實際保留的永久貼紙。

## 外觀與資訊

戰場骰面、獎勵、貼紙包與骰面展開圖共用材質名稱、專屬符號與表面紋理。鏡面為銀色切面、共鳴為紫色環紋、震盪為橙色斜紋、血瓶為紅色滴紋、漣漪為藍色波紋、金色脆閃為金色星芒、亮金箔為金色箔紋、負片為黑白反相、虹彩為多色光譜、迴響為青綠雙環。戰場骰面的材質底色與紋理位於角色下方的貼紙層，初版鏡面另加角色上方、數字下方的淡反光；材質名稱、符號與效果集中在 Hover 資訊。圖層與設定入口見[骰面呈現](dice-presentation.md)。其他介面保留材質文字與符號，戰前問號骰維持原有隱藏朝上結果規則。

重骰與結算階段的骰面說明各顯示一份材質效果文案，材質事件的數值變化供技能動畫與關係提示使用。迴響顯示「每場首次成功發動角色能力，額外重現一次效果。」並在同一行接上來源面本場的使用狀態：「尚未發動」以青綠色呈現，「已發動」以灰色呈現。固定文案描述效果，狀態由實際使用紀錄決定。

## 實作與驗證

材質設定與共享存糧容量集中於 configs；骰面有效值、身分與來源面狀態由既有骰面與戰鬥服務管理。預覽純計算，正式結算提交一次存糧、衰減、迴響與勝利金幣紀錄。驗證覆蓋取得機率邊界、貼紙覆蓋、偽裝鎖定及重骰能力、存糧容量、來源隔離、各材質互動、預覽冪等性與最後回合勝敗。外觀使用共用 SCSS 與材質標記元件。

設定見 [materialConfig.ts](../src/configs/materials/materialConfig.ts)。
