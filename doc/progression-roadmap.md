# 地下篇與難度進程規劃

規格入口：[spec.md](spec.md)。本文件記錄後續開發內容；本次實作範圍為鱷魚人難度一。

## 完整 Run 與難度解鎖

每趟 Run 由鱷魚人六區接續地下三區，構築與資源跨篇繼承。完整完成兩篇才解鎖下一難度；難度二及三重新建立骰池、裝備與資源，各自完成兩篇。鱷魚人篇結束屬於篇章里程碑。不同難度沿用七骰里程碑與加工開放時點，教學只需首次播放。

## 地下三區

第一區供玩家使用加工與適應新怪物；第二區依構築選擇具有不同 Intent 類型的菁英路線；第三區完成最終調整、菁英檢驗與地下 Boss。兩條路線提供相近等級的獎勵，各自具有不同威脅；不利構築仍能靠 Control、防禦及 HP 付出代價通過。每區入場即展示完整地圖、敵人類型、寶箱與補給。總節點與遊玩時間以兩篇合計重新校準。

## 加工

鱷魚人篇已取得七骰，交界工坊提供首次加工與補給。地下篇維持七骰，以有限次跨骰交換與整骰印記重整構築。交換搬移完整角色、基礎值與材質；每骰一枚印記，可付出成本替換。先鋒、黃金與堅毅依 [骰子加工](tribelings.md#骰子加工) 設計；加工價格、使用次數與取得頻率於地下篇開發前校準。

## 三難度的機制發展

難度一已有完整招牌機制，條件寬鬆並保留補救。難度二提高連續回合的攻防要求；難度三縮小容錯並組合熟悉機制。狂戰士由單擊命中成長，進展為連擊耗盾與強攻；典獄長由 HP 分段加傷，進展為低血量變招與決戰攻勢；次數甲由有限層數，進展為整備補甲及接續強攻；處刑由明確倒數，進展為準備期間受壓及後續循環強化。鱷文保留追傷、標籤與破盾等解法，各難度改變招式銜接與資源要求。隨機詛咒屬於額外挑戰規劃。
