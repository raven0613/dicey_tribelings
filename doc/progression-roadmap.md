# 地下篇與難度進程規劃

規格入口：[spec.md](spec.md)。本文件記錄後續開發內容；本次實作範圍為鱷魚人難度一。

## 完整 Run 與難度解鎖

每趟 Run 由鱷魚人三區接續地下三區，構築與資源跨篇繼承。完整完成兩篇才解鎖下一難度；難度二及三重新建立骰池、裝備與資源，各自完成兩篇。鱷魚人篇結束屬於篇章里程碑。各難度沿用三骰出發與鱷魚人各區 Boss 後取得白板骰的主幹，教學只需首次播放。

## 地下三區

第一區供玩家使用加工與適應新怪物；第二區依構築選擇具有不同 Intent 類型的菁英路線；第三區完成最終調整、菁英檢驗與地下 Boss。兩條路線提供相近等級的獎勵，各自具有不同威脅；不利構築仍能靠 Control、防禦及 HP 付出代價通過。每區入場即展示完整地圖、敵人類型、寶箱與補給。總節點與遊玩時間以兩篇合計重新校準。

## 加工

鱷魚人篇完成後持有六骰，交界工坊規劃提供首次加工與補給。第七骰的取得時點在地下篇設計時決定，以有限次跨骰交換與整骰印記重整構築。交換搬移完整角色與材質，兩個目標面各自保留固定點數；每骰一枚印記，可付出成本替換。先鋒、黃金與堅毅依 [骰子加工](tribelings.md#骰子加工) 設計；加工價格、使用次數與取得頻率於地下篇開發前校準。

## 三難度的機制發展

難度一已包含單敵、雙敵與主將帶小兵，以及命中／護盾雙條件、次數甲、格擋露隙、手動重骰蓄怒與限時額外獎勵。難度二、三的變化需連同地下篇驗證；機制升級與環境 debuff 的比例待後續規劃。輕重 debuff 互斥、震地／追蹤、攻擊蓄積條與持續傷害可作為地下篇的候選機制。
